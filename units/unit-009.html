UNIT 9

Present perfect continuous (I have been doing)

Unit 9　現在完了進行形

このユニットでは、続いている活動や、ついさっき終わった活動を表す現在完了進行形（I have been doing）を学びます。

現在完了（have done）の「今とのつながり」と、進行形（-ing）の「途中・活動」を合わせた形です。2つの部品の意味が分かれば、使い方も自然に分かります。

セクションの地図

Section扱う内容
Aついさっき終わった活動（結果が今に見える）
Bhow long / for / since（続いている活動）と、繰り返しの動作
C現在進行形（I am doing）との比較

色の対応

現在完了進行形＝青、現在進行形＝紫、期間（for / since）＝橙、今の様子（結果）＝緑、誤り＝赤。

Unit 9　Section A

An activity that has recently stopped

今回の学習範囲：Section A

Unit 7・8 では、現在完了（have done）を学びました。

このユニットでは、活動そのものに目を向ける現在完了進行形を学びます。

今回のテーマついさっきまでしていた活動を、have been + -ing で言う

1. ついさっき終わった活動を言う

まず、教科書の例を見てみましょう。雨はやんでいますが、地面がぬれています。

Study this example situation
Is it raining? No, but the ground is wet.It's been raining.雨は降っている？いや、でも地面はぬれている。
雨が降っていたんだ。教科書の注記：(= It has been …)

ここでのポイントは次の2つです。

  • 今、雨は降っていない（活動は終わっている）
  • でも、地面がぬれている（活動の跡が今に残っている）

このように、ついさっきまで続いていた活動を、今の様子から説明するときに使います。

2. なぜ have been + -ing なの？

形を部品に分けると、意味が見えてきます。

2つの部品
have been（現在完了）今とつながっている過去から今までの時間に目を向ける
-ing（進行形）活動・途中結果ではなく、続いていた活動そのものに目を向ける

合わせると、「今までの時間に続いていた活動」という意味になります。

話し手が注目しているのは、「何をしていたか」という活動です。だから、息切れや疲れ、ぬれた地面のように、今の様子の理由を説明するのにぴったりです。

3. 基本の形

have/has been + -ing is the present perfect continuous

つまり、have / has been に動詞の -ing 形を付けた形が、現在完了進行形です。

have / has been + 動詞の -ing 形
主語形例
I / we / they / youhave (= I've etc.) beendoing / working / learning etc.
he / she / ithas (= he's etc.) beendoing / working / learning etc.
疑問Have / Has + 主語 + been + -ing?Have you been running?

教科書は doing / working / learning などの -ing 形を挙げています。疑問の行は教科書外です。

We use the present perfect continuous for an activity that has recently stopped or just stopped

教科書の説明どおり、活動が最近、またはついさっき終わったときに使います。

4. 教科書の例文

① 息切れの理由を聞く

Why are you out of breath? Have you been running?

どうして息を切らしているの？走っていたの？

息切れという今の様子から、「さっきまで走っていたのでは？」と推測して聞いています。

② 疲れの理由を説明する

Paul is very tired. He's been working hard.

ポールはとても疲れている。一生懸命働いていたのだ。

疲れという今の様子の理由が、働いていたという活動です。

③ 何をしていたかを聞く

Why are you so tired? What have you been doing?

どうしてそんなに疲れているの？何をしていたの？

疲れた原因の活動を聞いています。What have you done? だと「何をしてしまったの？（結果）」という別の意味に近づきます。

④ 話していた活動を伝える

I've been talking to Amanda and she agrees with me.

アマンダと話していたのだけれど、彼女は私に賛成してくれた。

ついさっきまで話していたことを伝え、その結果（賛成してくれた）につなげています。

⑤ 探していた活動を伝える

Where have you been? I've been looking for you.

どこにいたの？あなたを探していたのよ。

探すという活動が、今見つかるまで続いていました。少しの非難の気持ちもこもっています。

5. 補足（教科書外）

補足　日本語の「〜していたんだ」は、この形にぴったり当たることが多いです。「泣いていたの？」は Have you been crying? です。

補足　Where have you been? は、「どこに行っていたの？（ずっと探していたのに）」という、待たされた気持ちを表す決まり文句です。

6. 追加例文で練習する

追加例文（教科書外）
様子の理由Your eyes are red. Have you been crying?目が赤いよ。泣いていたの？
様子の理由The kitchen smells great. I've been baking cookies.台所がいいにおい。クッキーを焼いていたの。
様子の理由Sorry I'm late. I've been waiting for a taxi.遅れてごめん。タクシーを待っていたんだ。
様子の理由Your hands are dirty. What have you been doing?手が汚れているよ。何をしていたの？

日常会話での使用例

A: You're covered in flour. What have you been doing?

小麦粉だらけだね。何をしていたの？

B: I've been baking bread.

パンを焼いていたんだ。

7. Section A のまとめ

状況使う表現例文
ついさっき終わった活動（今の様子の理由）have / has been + -ingHe's been working hard.

覚えておきたいのは、現在完了進行形は活動そのものに目を向け、今の様子の理由を説明するときに使うということです。

今の様子 ← have been + -ing（さっきまでの活動）

Unit 9　Section B

How long, for and since

今回の学習範囲：Section B

Section A では、ついさっき終わった活動を見ました。

今回は、今も続いている活動を、how long / for / since といっしょに言う使い方です。

今回のテーマ「どのくらい続けているか」は現在完了進行形で言う

1. 続いている活動の長さを言う

教科書は、雨が2時間降り続いている例を挙げています。

Study this example situation
It's been raining for two hours.How long has it been raining?2時間雨が降り続いている。
どのくらいの間、雨が降っているの？教科書の注記：(= It has been …) It began raining two hours ago and it is still raining.

We use the present perfect continuous in this way, especially with how long, for … and since … . The activity is still happening (as in this example) or has just stopped.

つまり、how long / for / since と合わせて、活動が今も続いていること、またはついさっき終わったことを言います。

2. なぜ「長さ」を言うときに使うの？

現在完了進行形は、「過去のある時点から今まで」の時間をまるごと見る形です。その時間の長さを測るのが、for（期間）と since（始まり）です。

時間の見え方
for two hours2時間前 ―――――― now期間の長さ
since 8 o'clock8時 ―――――― now始まった時点

「2時間前に降り始めて、今も降っている」という、過去から今までつながる時間なので、現在完了進行形がぴったりです。

日本語の「2時間降っている」につられて It is raining for two hours. としがちですが、これは誤りです。現在進行形は「今」だけを見る形で、過去からの長さを表せません。

3. 教科書の例文

① 今も勉強を続けている長さを聞く

How long have you been learning English?

どのくらい英語を勉強していますか？

教科書の補足：(= you're still learning English)

今も勉強を続けているので、始めてから今までの長さを聞いています。

② 一日中続いている

Ben is watching TV. He's been watching TV all day.

ベンはテレビを見ている。一日中見ている。

前の文は今の様子（現在進行形）、後の文は今までの長さ（現在完了進行形）です。2つの形が並んでいます。

③ 30分間ずっと探していた

Where have you been? I've been looking for you for the last half hour.

どこにいたの？この30分間、あなたを探していたよ。

探すのを始めてから今までの30分間です。見つかったので、ちょうど活動が終わったところです。

④ 最近ずっと

Chris hasn't been feeling well recently.

クリスは最近、体調がよくない。

最近から今まで続いている体調です。否定は hasn't been + -ing になります。

4. 繰り返しの動作にも使える

You can use the present perfect continuous for repeated actions

教科書は、何度も繰り返してきた動作にも使えると言っています。

Silvia is a very good tennis player. She's been playing since she was eight.

シルビアはとても上手なテニス選手だ。8歳のときからプレーしている。

Every morning they meet in the same cafe. They've been going there for years.

毎朝、彼らは同じカフェで会う。何年もそこへ通っている。

ずっと休みなくテニスをしているわけではありません。8歳から今まで、何度も繰り返してきた、という意味です。

5. 補足（教科書外）

補足　How long have you been …? への答えは、For three years. / Since April. のように、for / since の語句だけで答えるのが自然です。

補足　面接や自己紹介では、I've been working in marketing for five years.（マーケティングの仕事を5年間しています）のように、経歴の長さを言うのによく使います。

6. 追加例文で練習する

追加例文（教科書外）
forI've been studying Spanish for six months.スペイン語を6か月勉強している。
sinceWe've been waiting here since 9 o'clock.9時からここで待っている。
how longHow long have you been working here?ここで働いてどのくらいですか？
繰り返しHe's been going to the gym every week since January.彼は1月から毎週ジムに通っている。

日常会話での使用例

A: How long have you been working here?

ここで働いてどのくらい？

B: For about three years.

3年くらいだよ。

7. Section B のまとめ

状況使う表現例文
続いている活動の長さhave / has been + -ing + for / sinceIt's been raining for two hours.
長さを聞くHow long + have / has been + -ing?How long have you been learning English?
誤り現在進行形 + for× It is raining for two hours.

覚えておきたいのは、for / since / how longといっしょに、今も続いている活動を現在完了進行形で言うということです。

have been + -ing ＋ for（期間） / since（始まり）

確認テスト

Unit 9　Section C

Compare: I am doing and I have been doing

今回の学習範囲：Section C

Section B では、続いている活動を現在完了進行形で言うことを見ました。

今回は、現在進行形（I am doing）との比較です。

今回のテーマ「今している」と「今までしていた」の違い

1. 今している活動と、今までしていた活動

教科書は、2つの形を並べて比べています。

Compare
I am doing (present continuous)Don't disturb me now. I'm working.今は邪魔しないで。仕事をしているんだ。
I have been doing (present perfect continuous)I've been working hard. Now I'm going to have a break.一生懸命働いていた。今から休憩をとるところだ。
I am doingWe need an umbrella. It's raining.傘が必要だ。雨が降っている。
I have been doingThe ground is wet. It's been raining.地面がぬれている。雨が降っていたのだ。
I am doingHurry up! We're waiting.急いで！私たちは待っているんだ。
I have been doingWe've been waiting for an hour.1時間待っている。

2. なぜ形で意味が変わるの？

2つの形は、見ている時間の範囲が違います。

見ている時間
現在進行形[ now ]「今」という一点の様子だけを見る
現在完了進行形―――――→ now過去から今までの時間の流れを見る

だから、「今、仕事中」は現在進行形、「（さっきまで）ずっと働いていた」は現在完了進行形です。

雨の例も同じです。「傘が必要だ。雨が降っている。」は今も降っているので現在進行形、「地面がぬれている。雨が降っていた。」は今までの時間を振り返っているので現在完了進行形です。

待っている例では、「急いで！待っているんだ」は今の様子、「1時間待っている」は今までの長さです。長さ（for an hour）があると、現在完了進行形になります。

3. 補足（教科書外）

補足　迷ったら、「今の一点」か「今までの流れ」かを考えましょう。for や since、how long があれば、ほぼ現在完了進行形です。

補足　I've been working hard. は、まだ働いている場合にも、ちょうど終わった場合にも使えます。どちらかは、文脈（Now I'm going to have a break. など）で決まります。

4. 追加例文で練習する

追加例文（教科書外）
今の様子Please be quiet. The baby is sleeping.静かにして。赤ちゃんが寝ているの。
今までの流れThe baby has been sleeping for three hours.赤ちゃんは3時間眠っている。
今の様子I'm studying in the library now.今、図書館で勉強している。
今までの流れI've been studying all afternoon. I need a break.午後ずっと勉強していた。休憩が必要だ。

日常会話での使用例

A: Why are your eyes red?

どうして目が赤いの？

B: I've been crying.

泣いていたんだ。

5. Section C のまとめ

見方使う表現例文
今、まさにしている（一点）現在進行形I'm working.
ついさっきまで／ずっと（流れ）現在完了進行形I've been working hard.

覚えておきたいのは、今しているなら現在進行形、今までしていたなら現在完了進行形だということです。

今の一点 → am / is / are + -ing　／　今までの流れ → have been + -ing
