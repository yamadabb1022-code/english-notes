Unit 18　used to

このユニットでは、「昔はよく〜していた（今はしていない）」を表す used to を学びます。

used to のいちばんの特徴は、「昔」と「今」の対比を含むことです。過去形がただ過去の出来事を言うのに対し、used to は「今はもう違う」という気持ちまで伝えます。

セクションの地図

Section扱う内容
Aused to の基本の意味
B昔よくしていたこと・昔は本当だったこと
Cused to は過去だけ（現在は現在形）
D疑問文と否定文（did … use to / didn't use to）
Eused to と過去進行形（was doing）の違い
Fused to do と be used to doing の違い

色の対応

used to ＝青、現在形（今のこと）＝紫、過去進行形＝緑、be used to ＝橙、誤り＝赤。

Unit 18　Section A

used to

今回の学習範囲：Section A

Unit 5 では過去形を学びました。

このユニットでは、「昔はよく〜していたが、今はしていない」を表す used to を学びます。

今回のテーマ昔はよくしていて、今はしていないことを used to で言う

1. used to は、何を表すの？

まず、教科書の例を見てみましょう。ニコラの旅行の話です。

Study this example situation
Nicola doesn't travel much these days. She prefers to stay at home.But she used to travel a lot. She used to go away two or three times a year.ニコラは最近あまり旅行しない。家にいるほうが好きだ。
でも、昔はよく旅行していた。年に2、3回は出かけていた。

She used to travel a lot = she travelled often in the past, but she doesn't do this any more.

つまり、used to は、過去によくしていたが、今はもうしていないことを言う形です。

ここでのポイントは次の2つです。

  • 過去：よく旅行していた（年に2、3回）
  • 今：あまり旅行しない（these days）

2. なぜ過去形ではなく used to を使うの？

過去形の She travelled a lot. でも「よく旅行した」とは言えます。でも、過去形は過去の事実を言うだけで、今どうなっているかは伝えません。

2つの形が伝えること
She travelled a lot.過去によく旅行した（今もしているかもしれない）
used toShe used to travel a lot.過去によく旅行していた ＋ 今はもうしていない

used to を使うと、「昔はそうだったが、今は違う」という対比がはっきり伝わります。昔をなつかしむ気持ちや、変わったことへの驚きを表すのに向いています。

used to + 動詞の原形

主語が何でも used to の形は変わりません（he used to / they used to）。

3. 補足（教科書外）

補足　used to の発音は「ユーストゥ」[ˈjuːstə] です。use（使う）の過去形 used（ユーズド）とは発音が違うので注意しましょう。

補足　日本語の「昔は〜したものだ」「以前は〜していた」が、used to にぴったり当たります。

4. 追加例文で練習する

追加例文（教科書外）
習慣I used to walk to school every day.昔は毎日歩いて通学していた。
習慣My father used to smoke, but he stopped ten years ago.父は昔たばこを吸っていたが、10年前にやめた。
習慣We used to go camping every summer.昔は毎年夏にキャンプに行っていた。
習慣She used to work in a bank.彼女は以前、銀行で働いていた。

日常会話での使用例

A: Do you still play the piano?

まだピアノを弾いているの？

B: No, but I used to play every day.

ううん、でも昔は毎日弾いていたよ。

5. Section A のまとめ

状況使う表現例文
昔よくしていた（今はしていない）used to + 原形She used to travel a lot.
今の様子現在形She doesn't travel much these days.

覚えておきたいのは、used to は昔と今の違いを表す形だということです。

used to ＝ 昔はそうだった ＋ 今は違う

Unit 18　Section B

Things we did often / things that were true

今回の学習範囲：Section B

Section A では、used to の基本の意味を見ました。

今回は、used to の2つの使い方を、例文で確かめます。

今回のテーマよくしていたことにも、本当だったことにも used to を使う

1. 昔よくしていたこと

I used to do something = I did it often in the past, but not any more

① 昔はよくしていた運動

I used to play tennis a lot, but I don't play very much now.

昔はよくテニスをしたが、今はあまりしない。

but のあとで「今は」と対比しています。used to の文は、このように今の様子とセットで使われることがよくあります。

② 昔のお金の使い方

David used to spend a lot of money on clothes. These days he can't afford it.

デイビッドは昔、服にたくさんお金を使っていた。最近はその余裕がない。

These days（最近は）が、今との対比を示しています。

③ used to だけで終える

'Do you go to the cinema much?' 'Not now, but I used to.'

「映画館にはよく行く？」「今は行かないけど、昔はよく行っていたよ。」

教科書の注記：(= I used to go)

同じ動詞のくり返しを避けて、used to だけで文を終えることができます。to のあとの go は省略されています。

2. なぜ状態の動詞にも使えるの？

We also use used to … for things that were true, but are not true any more

used to は「よくしていた習慣」だけでなく、「昔は本当だった状態」にも使えます。

習慣も状態も、「昔はそうだったが、今は違う」という点では同じです。used to が表すのは、動作かどうかではなく、昔と今の対比だからです。

④ 建物が昔は映画館だった

This building is now a furniture shop. It used to be a cinema.

この建物は今は家具屋だ。昔は映画館だった。

be（〜である）という状態です。「今は家具屋」と対比しています。

⑤ 昔はそう思っていた

I used to think Mark was unfriendly, but now I realise he's a very nice person.

マークは無愛想だと思っていたが、今はとてもいい人だと分かる。

think（思う）という状態です。考えが変わったことを伝えています。

⑥ 昔は好きではなかった

I've started drinking coffee recently. I never used to like it before.

最近コーヒーを飲むようになった。以前は好きではなかった。

never used to で「昔は〜しなかった」という意味になります。

⑦ 子どものころの見た目

Lisa used to have very long hair when she was a child.

リサは子どものころ、とても長い髪をしていた。

have（持っている）という状態です。今は髪が短いことが分かります。

3. 補足（教科書外）

補足　There used to be …（昔は〜があった）は、町の変化を話すときによく使います。There used to be a big park here.（昔ここに大きな公園があった）。

補足　used to は「何回したか」は言えません。I used to go to Paris three times. とは言わず、I went to Paris three times. と過去形で言います。used to は回数ではなく、昔の習慣や状態を表す形だからです。

4. 追加例文で練習する

追加例文（教科書外）
習慣I used to stay up late playing games.昔はゲームをして夜ふかししていた。
状態This town used to be very quiet.この町は昔はとても静かだった。
状態There used to be a bookshop on this corner.この角には昔、本屋があった。
状態I used to hate vegetables, but now I love them.昔は野菜が大嫌いだったが、今は大好きだ。

日常会話での使用例

A: Is there a bank on this street?

この通りに銀行はある？

B: There used to be one, but it closed last year.

昔はあったけど、去年閉まったよ。

5. Section B のまとめ

状況使う表現例文
昔よくしていたこと（習慣）used toI used to play tennis a lot.
昔は本当だったこと（状態）used toIt used to be a cinema.

覚えておきたいのは、used to は昔の習慣にも昔の状態にも使えるということです。

used to ＋ 動作（習慣）／ 状態 ＝ 昔はそうだった

確認テスト

Unit 18　Section C

used to is past only

今回の学習範囲：Section C

Section B では、used to の2つの使い方を見ました。

今回は、used to には現在の形がないという点です。

今回のテーマused to は過去だけ。今のことは現在形で言う

1. used to には現在の形がない

'I used to do something' is past. There is no present. You cannot say 'I use to do'. To talk about the present, we use the present simple (I do).

つまり、used to は過去の形だけです。「今よくする」は、現在形で言います。

2. なぜ現在の形がないの？

used to の意味は、「昔はそうだったが、今は違う」でした。「今」と対比する形なので、今のことを表す形は必要ありません。

今の習慣は、Unit 2 で学んだ現在形が表します。だから、used to と現在形で、「昔」と「今」の役割を分けているのです。

Compare
過去he used to play / we used to live / there used to be彼はよくプレーしていた／私たちは住んでいた／〜があった
現在he plays / we live / there is彼はプレーする／私たちは住んでいる／〜がある

3. 教科書の例文

① 昔は村、今は都会

We used to live in a small village, but now we live in a city.

私たちは昔、小さな村に住んでいたが、今は都会に住んでいる。

1つの文の中で、昔は used to live、今は live と使い分けています。

② 昔は4つ、今は1つ

There used to be four cinemas in the town. Now there is only one.

昔、町には映画館が4つあった。今は1つしかない。

There used to be … と There is … で、町の変化を表しています。

4. 補足（教科書外）

補足　日本語話者は「今もよく〜する」のつもりで I use to … と言ってしまうことがあります。今の習慣は、I usually … / I often … のように現在形で言いましょう。

補足　「〜するのに使う」の意味の use（I use this pen to write.）は、まったく別の動詞です。used to（昔は〜していた）と混同しないようにしましょう。

5. 追加例文で練習する

追加例文（教科書外）
昔I used to take the bus to work.昔はバスで通勤していた。
今Now I ride my bike.今は自転車に乗っている。
昔There used to be a lot of shops here.昔はここにたくさんの店があった。
今Now there are only a few.今は数軒しかない。

日常会話での使用例

A: Where do you live now?

今はどこに住んでいるの？

B: In Tokyo. I used to live in Sapporo.

東京だよ。昔は札幌に住んでいた。

6. Section C のまとめ

時使う表現例文
過去used to + 原形We used to live in a small village.
現在現在形Now we live in a city.
誤りuse to（現在）× I use to live in Tokyo.

覚えておきたいのは、used to は過去だけで、今のことは現在形で言うということです。

昔 → used to　／　今 → 現在形（use to という形はない）

Unit 18　Section D

Questions and negatives

今回の学習範囲：Section D

Section C では、used to が過去だけの形だと見ました。

今回は、疑問文と否定文の形です。

今回のテーマ疑問文は did … use to、否定文は didn't use to

1. did … use to と didn't use to

The normal question form is did (you) use to … ?

Did you use to eat a lot of sweets when you were a child?

子どものころ、お菓子をよく食べていましたか？

教科書の補足：(= did you do this often?)

The negative form is didn't use to … (used not to … is also possible)

I didn't use to like him. (or I used not to like him.)

昔は彼が好きではなかった。

2. なぜ did のあとは use to になるの？

Unit 5C で見たとおり、did / didn't を使うと、「過去」の意味は did が引き受けます。あとの動詞は原形に戻るのでした。

used to の used は、もともと過去形です。did があると過去を2回表すことになるので、-d を取って use to にします。Did you go?（went ではない）と同じ考え方です。

形の比べ方
肯定I used to like him.used（過去形）
疑問Did you use to like him?did が過去を表す → use（原形）
否定I didn't use to like him.didn't が過去を表す → use（原形）

used not to … は、少し古風で、書き言葉に多い形です。会話では didn't use to … がふつうです。

3. 補足（教科書外）

補足　発音はどれも同じ「ユーストゥ」なので、話し言葉ではつづりの違いを気にする必要はありません。書くときにだけ注意しましょう。

補足　否定の気持ちを強めたいときは、never used to …（一度も〜しなかった）もよく使います。I never used to eat breakfast.（昔は朝食を食べなかった）。

4. 追加例文で練習する

追加例文（教科書外）
疑問Did you use to have long hair?昔は髪が長かったの？
疑問Where did you use to live?昔はどこに住んでいたの？
否定I didn't use to like spicy food.昔は辛い食べ物が好きではなかった。
否定We didn't use to have a car.昔は車を持っていなかった。

日常会話での使用例

A: Did you use to play sports at school?

学生のころ、スポーツをしていた？

B: Yes, I used to play basketball.

うん、バスケをしていたよ。

5. Section D のまとめ

文の種類使う表現例文
疑問Did + 主語 + use to + 原形?Did you use to eat a lot of sweets?
否定didn't use to + 原形（used not to も可）I didn't use to like him.

覚えておきたいのは、did / didn't のあとはuse to（-d なし）になるということです。

did / didn't ＋ use to（did が過去を引き受ける）

Unit 18　Section E

used to and was doing

今回の学習範囲：Section E

Section D では、used to の疑問文と否定文を見ました。

今回は、used to と過去進行形の違いです。

今回のテーマ昔の習慣は used to、ある時点の途中は過去進行形

1. 昔の習慣か、その時の途中か

Compare I used to do and I was doing
昔の習慣I used to watch TV a lot.昔はよくテレビを見ていた。(= I watched TV often in the past, but I don't do this any more)
その時の途中I was watching TV when Rob called.ロブが電話してきたとき、テレビを見ていた。(= I was in the middle of watching TV)

2. なぜ同じ「見ていた」で形が違うの？

日本語ではどちらも「見ていた」になりますが、見ている時間の範囲がまったく違います。

時間の見え方
used to―×――×――×――×―（昔、何度も） | now（今はしない）長い期間に何度も繰り返した習慣
was watching―――― [ ロブの電話 ] ――――ある1つの瞬間の途中の様子

used to は、長い期間にわたる「習慣」を言います。過去進行形は、Unit 6 で学んだように、ある1つの時点を写真のように切り取って、「その瞬間、何の途中だったか」を言います。

だから、「〜したとき、…していた」という場面には過去進行形、「昔はよく…していた」という習慣には used to を使います。

3. 補足（教科書外）

補足　昔の習慣は、would でも言えることがあります（When I was a child, we would go to the beach every summer.）。これは Unit 36 で学びます。ただし、would は状態（be / have / like など）には使えません。

補足　when …（〜したとき）があれば、まず過去進行形を考えましょう。every day / often / a lot など習慣の言葉があり、今との対比があるなら used to です。

4. 追加例文で練習する

追加例文（教科書外）
習慣I used to read comics every night.昔は毎晩マンガを読んでいた。
途中I was reading a comic when my mum came in.母が入ってきたとき、マンガを読んでいた。
習慣She used to run in the park every morning.彼女は昔、毎朝公園を走っていた。
途中She was running in the park when she saw the accident.事故を見たとき、彼女は公園を走っていた。

日常会話での使用例

A: What were you doing at nine last night?

昨夜9時は何をしていた？

B: I was reading. I used to watch TV every night, but not any more.

本を読んでいたよ。昔は毎晩テレビを見ていたけど、今は見ないんだ。

5. Section E のまとめ

意味使う表現例文
昔の習慣（何度も）used toI used to watch TV a lot.
その時に途中だった（1回）was + -ingI was watching TV when Rob called.

覚えておきたいのは、昔の習慣は used to、ある時点の途中は過去進行形で言うということです。

長い期間の習慣 → used to　／　1つの瞬間の途中 → was / were + -ing

確認テスト

Unit 18　Section F

used to do and be used to doing

今回の学習範囲：Section F

Section E では、used to と過去進行形を比べました。

今回は、形の似ている I am used to doing と混同しないための注意です。

今回のテーマused to do（昔は〜していた）と be used to doing（〜に慣れている）は別物

1. used to do と be used to doing

Do not confuse I used to do and I am used to doing (see Unit 61). The structures and meanings are different

Compare
used to doI used to live alone.私は昔、一人暮らしをしていた。(= I lived alone in the past, but I no longer live alone.)
be used to doingI am used to living alone.私は一人暮らしに慣れている。(= I live alone, and it's not a problem for me because I've lived alone for some time.)

2. なぜ形が似ているのに意味が違うの？

2つは、まったく別の成り立ちの表現です。

2つの表現の正体
used to doused to が1つの助動詞のような働きto は不定詞の to → あとは原形
be used to doingbe used（慣れている）＋ to（〜に）to は前置詞の to → あとは名詞か -ing

be used to の used は、「慣れた」という形容詞です。to は「〜に」という前置詞なので、あとには名詞（I'm used to the noise.）か、動詞の -ing 形が来ます。

見分けるポイントは、前に be 動詞があるかどうかと、あとが原形か -ing かの2つです。

3. 補足（教科書外）

補足　「慣れていく」と変化を言いたいときは、get used to を使います。I'm getting used to my new job.（新しい仕事に慣れてきている）。これも Unit 61 で詳しく学びます。

補足　be used to のあとに原形を置く誤り（I'm used to live alone.）がとても多いです。「be used to のあとは -ing」と、セットで覚えましょう。

4. 追加例文で練習する

追加例文（教科書外）
used to doI used to get up at noon.昔は昼に起きていた。
be used to doingI'm used to getting up early now.今は早起きに慣れている。
be used to + 名詞She's used to the cold weather.彼女は寒い気候に慣れている。
get used toI'm getting used to working from home.在宅勤務に慣れてきている。

日常会話での使用例

A: Is it hard to get up early?

早起きはつらい？

B: Not really. I'm used to getting up at six.

そうでもないよ。6時に起きるのに慣れているんだ。

5. Section F のまとめ

形意味例文
used to + 原形昔は〜していたI used to live alone.
be used to + -ing〜に慣れているI am used to living alone.

覚えておきたいのは、used to + 原形とbe used to + -ingは、形も意味も違うということです。

be 動詞なし ＋ 原形 → 昔は〜していた　／　be 動詞あり ＋ -ing → 〜に慣れている

教科書の参照：be/get used to (doing something) ➜ Unit 61、would (= used to) ➜ Unit 36
