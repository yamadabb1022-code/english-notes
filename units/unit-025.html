UNIT 25

when I do and when I've done / if and when

Unit 25　when と if のあとの時制

「着いたら電話するね」。この「着いたら」を、英語で when I will arrive とは言えません。when I arrive、つまり現在形です。未来のことなのに、will を使わない。これが今日のルールです。

日本語話者には自然な感覚ですが、「未来だから will」と考えすぎると、間違いやすいところです。

セクションの地図

Section扱う内容
Awhen / before / until などのあとは、未来でも現在形
Bwhen / after / until などのあとの現在完了（先に終わること）
Cif と when の違い（起こるかどうか分からないか、必ず起こるか）

色の対応

when などのあとの現在形・現在完了＝青、主節の will など＝橙、if ＝紫、誤り＝赤。

Unit 25　Section A

when I do (not when I will do)

今回の学習範囲：Section A

Unit 21〜24 は、will で未来を言う方法でした。

例外が1つあります。それが、when / if のあとです。

今回のテーマwhen のあとは、未来のことでも現在形で言う

① when のあとは、未来のことでも現在形で言う

まず、教科書の例を見てみましょう。エイミーが電車の中から友達に電話しています。

Study this example
Amy is on a train. She's calling a friend.I'll call you again later when I arrive.エイミーは電車に乗っていて、友達に電話している。
着いたら、また電話するね。

教科書は、次のように説明しています。

'I'll call you again later when I arrive' is a sentence with two parts: the main part: I'll call you again later and when … : when I arrive

この文は、2つの部分でできています。

  • 主な部分：I'll call you again later（あとでまた電話する）
  • when の部分：when I arrive（着いたら）

教科書の説明を見てみましょう。

The time is future ('later'), but Amy says: … when I arrive (not when I will arrive)

時間は未来（later）ですが、エイミーは when I will arrive ではなく、when I arrive と現在形で言っています。

② 未来であることは主な部分が示しているので、when の部分は現在形でよい

文全体で「未来の話だ」ということは、主な部分の will（I'll call）がもう示しています。

when の部分は、「いつ電話するか」という時を表しているだけです。未来であることは主な部分で分かっているので、when の部分ではもう will を使わず、現在形で済ませるのです。

文の役割分担
主な部分I'll call you again later未来を表す（will）
when の部分when I arriveいつかを表す（現在形のまま）

教科書には、次の説明があります。

We say when I do something (not will do) / when something happens (not will happen)

日本語でも、「着いたら電話する」と言い、「着くだろうときに電話する」とは言いません。この感覚は、日本語と英語で同じです。

教科書の例文

③ 「〜したら」の部分は、現在形で言う

We'll go out when it stops raining. (not when it will stop)

雨がやんだら出かけよう。

主な部分の We'll go out が未来を示しているので、when のあとは stops と現在形です。

④ when の部分が文の前に来ても、現在形で言う

When you are here again, you must come and see us. (not When you will be)

またここに来たら、ぜひ私たちのところに寄ってね。

when の部分が文の前に来ても、ルールは同じです。are と現在形です。

⑤ 主な部分が命令文でも、when のあとは現在形で言う

Don't forget to lock the door when you go out. (not will go)

出かけるときは、ドアに鍵をかけるのを忘れないでね。

主な部分は命令文（Don't forget）ですが、未来の話なので、when のあとは現在形です。

⑥ while / before / after / as soon as / until のあとも、現在形で言う

教科書は、次のように説明しています。

The same thing happens after while / before / after / as soon as / until

「時」を表すほかの言葉のあとでも、同じルールです。

What are you going to do while I'm away? (not while I will be)

私がいない間、何をするつもり？

Before you go, there's something I want to ask you.

行く前に、聞きたいことがあるんだ。

Wait here until I come back. or … till I come back.

私が戻るまで、ここで待っていて。

until は、話し言葉では till と短く言うこともあります。

補足（教科書外）

補足　このルールは、「時」を表す when のときだけです。「いつ〜するか」と聞く疑問文の when には、will を使えます。When will you arrive?（いつ着くの？）は正しい英語です。

補足　as soon as（〜したらすぐに）は、ビジネスメールでよく使います。I'll send it to you as soon as I get the data.（データが届き次第お送りします）。

when のあとは、メッセージ・連絡・待ち時間など、日常の約束の言葉にも使えます。

I'll text you when I get home.

家に着いたらメッセージを送るね。

Call me as soon as you hear the news.

ニュースを聞いたらすぐに電話して。

Turn off the lights before you leave.

出る前に電気を消してね。

I'll wait until you finish.

終わるまで待つよ。

会話では、電話の約束をするときに使います。

A: When will you call me?

いつ電話くれる？

B: I'll call you when I finish work.

仕事が終わったら電話するよ。

覚えておきたいのは、when / while / before / after / as soon as / until のあとは、未来のことでも現在形で言うということです。

部分使う表現例文
主な部分（未来）will などI'll call you again later
when / before / until などの部分現在形when I arrive
誤りwhen + will× when I will arrive

主な部分（will）＋ when / until など ＋ 現在形

Unit 25　Section B

when I've done

今回の学習範囲：Section B

次は、現在完了です。「〜し終えたら」と、順番をはっきり言いたいときに使います。

現在形との違いは、順番か同時かです。

今回のテーマ先に終わることは、when のあとで現在完了にできる

① when などのあとで、現在完了も使える

教科書は、次のように説明しています。

You can also use the present perfect (have done) after when / after / until / as soon as

Can I have the newspaper when you've finished with it?

新聞を読み終わったら、もらってもいい？

Don't say anything while Ian is here. Wait until he has gone.

イアンがいる間は何も言わないで。彼が帰るまで待って。

when / after / until / as soon as のあとでは、現在完了も使えます。これも、未来のことを will have done ではなく、現在完了で言っているのです。

② 現在完了は、1つのことが先に終わることを示す

教科書の説明を見てみましょう。

We use the present perfect to show that one thing is complete before the other. The two things do not happen together

つまり、現在完了を使うと、「1つのことが、もう1つのことより先に終わる」ことをはっきり示せます。2つは同時には起きません。

When I've phoned Kate, we can go out.

ケイトに電話し終えたら、出かけられるよ。

教科書の補足：(= first I'll phone Kate and after that we can go out)

「電話をかけ終える → それから出かける」という順番です。現在完了は「終わった」ことを表す形（Unit 7）なので、「先に終わらせる」という意味がはっきり伝わります。

③ 2つのことが同時に起きるなら、現在形を使う

教科書には、次の説明があります。

Do not use the present perfect if the two things happen together

When I phone Kate, I'll ask her about the party. (not when I've phoned)

ケイトに電話したら、パーティーのことを聞いてみるよ。

電話している最中に、パーティーのことを聞きます。2つは同時に起きるので、現在完了は使えません。

順番か、同時か
when I've phoned電話し終える → 出かける先に終わってから次のことをする
when I phone電話する ＝ その中で聞く同時に起きる

④ 順番が明らかなら、現在形でも現在完了でもよい

教科書は、次のように説明しています。

It is often possible to use either the present simple or the present perfect

I'll come as soon as I finish. or I'll come as soon as I've finished.

終わったらすぐに行くよ。

You'll feel better after you have something to eat. or You'll feel better after you've had something to eat.

何か食べたら、気分がよくなるよ。

「終わる → 行く」「食べる → 気分がよくなる」と、順番がもともと明らかなときは、現在形でも現在完了でも、意味はほとんど変わりません。現在完了にすると、「終わってから」という感じが少し強くなります。

補足（教科書外）

補足　メールの決まり文句 I'll get back to you when I've checked the details.（詳細を確認し次第、ご連絡します）は、この現在完了の使い方です。「確認が終わってから」という順番が伝わります。

補足　日本語の「〜し終えたら」「〜してから」は、現在完了に当たることが多い言い方です。

現在完了は、報告や貸し借りの話にも使えます。

I'll call you when I've read the report.

レポートを読み終えたら電話します。

You can go home after you've cleaned the room.

部屋の掃除を終えたら帰っていいよ。

When I see Tom, I'll tell him the news.

トムに会ったら、ニュースを伝えるよ。

Let's start as soon as everyone arrives / has arrived.

全員そろったらすぐに始めよう。

会話では、パソコンを借りたいときに使います。

A: Can I use the computer?

パソコン使っていい？

B: Sure, when I've finished this email.

いいよ、このメールを書き終えたらね。

覚えておきたいのは、when などのあとで現在完了を使うと、「先に終わる」という順番がはっきりするということです。

2つのことの関係使う表現例文
先に終わってから次のことwhen + 現在完了When I've phoned Kate, we can go out.
同時に起きるwhen + 現在形When I phone Kate, I'll ask her.
順番がもともと明らか現在形でも現在完了でも可as soon as I finish / I've finished

when ＋ have done ＝ 「〜し終えたら」（先に完了）

Unit 25　Section C

if and when

今回の学習範囲：Section C

最後は、if です。if と when の違いを整理します。

決め手は、起こる確かさです。

今回のテーマif も現在形。起こるか分からないなら if、必ず起こるなら when

① if のあとも、未来のことは現在形で言う

教科書は、次のように説明しています。

After if, we normally use the present (if I do / if I see etc.) for the future

つまり、if のあとも、when と同じように、未来のことでも現在形で言います。

I'll be angry if it happens again. (not if it will happen)

もしまたそうなったら、怒るよ。

Hurry up! If we don't hurry, we'll be late.

急いで！急がないと遅れるよ。

理由も Section A と同じです。未来であることは主な部分（I'll be angry、we'll be late）が示しているので、if の部分は現在形で済ませます。

② 起こるか不確かなら if、確実なら when を使う

日本語の「〜したら」は、if にも when にも当たります。でも英語では、その出来事が起こるかどうかの確かさで、2つを使い分けます。

if と when
ifthings that will possibly happen (or not happen)起こるかもしれないし、起こらないかもしれないこと
whenthings which are sure to happen必ず起こること

if は「もし〜したら」で、起こるかどうか分からないときの言葉です。when は「〜したら（そのときに）」で、起こることが前提になっています。

③ 起こるか分からないことには、if を使う

教科書の説明を見てみましょう。

We use if (not when) for things that will possibly happen (or not happen)

If it is raining this evening, I won't go out. (not when it is raining)

今晩もし雨が降っていたら、出かけない。

Don't worry if I'm late tonight. (not when I'm late)

今夜もし遅くなっても、心配しないで。

If they don't come soon, I'm not going to wait for them.

もし彼らがすぐ来なかったら、待たないつもりだ。

雨が降るか、遅くなるか、すぐ来ないかは、分かりません。だから if です。when it is raining にすると、「雨が降ることは決まっている」という意味になってしまいます。

④ 必ず起こることには、when を使う

教科書には、次の説明があります。

We use when for things which are sure to happen.

Compare
if（可能性）I might go out later. (it's possible) If I go out, I'll get some bread.あとで出かけるかもしれない。もし出かけたら、パンを買ってくるよ。
when（確実）I'm going out later. (for sure) When I go out, I'll get some bread.あとで出かける。出かけたら、パンを買ってくるよ。

出かけるかどうか分からないなら if、出かけることが決まっているなら when です。前の文（I might / I'm going out）が、その確かさを示しています。

補足（教科書外）

補足　メールの I'll let you know when I hear from them.（先方から連絡があったらお知らせします）は、連絡が来ることを前提にした言い方です。If I hear from them, … にすると、「連絡が来るかどうか分からない」という響きになります。

補足　if の使い方は、Unit 38〜40 でさらに詳しく学びます（If I knew … など）。

if と when は、天気や仕事の話でも、使い分けます。

If you need help, just ask.

助けが必要なら、遠慮なく言ってね。

If the train is late, I'll take a taxi.

もし電車が遅れたら、タクシーに乗るよ。

When I finish university, I'll travel around Asia.

大学を卒業したら、アジアを旅行するつもりだ。

When the meeting ends, please call me.

会議が終わったら、電話してください。

会話では、天気しだいの予定をたずねるときに使います。

A: What will you do if it rains tomorrow?

明日雨が降ったらどうする？

B: If it rains, we'll go to a museum instead.

もし雨なら、かわりに美術館に行くよ。

覚えておきたいのは、if も when もあとは現在形で、起こるか分からないなら if、必ず起こるなら whenだということです。

状況使う表現例文
起こるか分からないif + 現在形If it is raining this evening, I won't go out.
必ず起こるwhen + 現在形When I go out, I'll get some bread.

可能性 → if　／　確実 → when（どちらもあとは現在形）
