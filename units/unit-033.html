Unit 33　should 1

友達が「最近、寝不足でさ」と言ったら、あなたはなんと答えますか。「早く寝たほうがいいよ」ですよね。この「〜したほうがいいよ」が、今日の主役 should です。

should は「〜すべきだ」と訳されがちですが、実際の強さは、もっとやわらかいものです。「そうするのがいいと思うよ」くらいの、おすすめのトーンです。must / have to との強さの違いを意識しながら読んでください。後半では、「期待」を表す should と、「〜すればよかったのに」という後悔を表す should have も出てきます。

セクションの地図

Section扱う内容
Ashould ＝ 〜したほうがいい（助言・意見）
Bshould ＝ 〜のはず（当然・期待）
Cshould have (done) ＝ 〜すべきだったのに
Dought to

色の対応

should ＝青、shouldn't ＝紫、should have（過去）＝橙、must / have to（強い義務）＝赤、ought to ＝緑。

Unit 33　Section A

should for advice and opinions

今回の学習範囲：Section A

Unit 31・32 では、must や have to で、逃げ場のない「しなければならない」を学びました。

今回の should は、それよりずっと穏やかです。「するかどうかは、あなたが決めていいけど、したほうがいいと思うよ」という言い方です。

今回のテーマ助言や意見は should で言う

① should は、「そうするのがよい」と助言するときに使う

教科書は、次のように説明しています。

You should do something = it is a good thing to do or the right thing to do. You can use should to give advice or to give an opinion

つまり、should は、「それをするのがよい・正しい」という意味で、助言や意見を言うときに使う、ということです。

You look tired. You should go to bed.

疲れているみたいだね。寝たほうがいいよ。

a: Should we invite Stephanie to the party?
b: Yes, I think we should.

a：ステファニーをパーティーに招待したほうがいいかな？
b：うん、そうしたほうがいいと思う。

状況should の使い方
相手が疲れて見える寝たほうがいいと助言する。
招待するかの相談「招待したほうがいい」と答える。

should は、「それをするのがよい・正しい」と言うときに使います。疑問文は should を主語の前に出します。答えの I think we should のあとは、invite her が省略されています。

間違いやすいのは、should のあとの toです。助動詞のあとは原形です。

You should go to bed. (not You should to go to bed)

寝たほうがいい。

The man on the motorbike should be wearing a helmet.

バイクの男の人はヘルメットをかぶっているべきだ。

should be -ing は、「今〜しているべきだ」という意味です。

② should は、自分の意見を言うときにも使う

The government should do more to improve schools.

政府は学校をよくするために、もっと取り組むべきだ。

教科書の説明を見てみましょう。

We often use should with I think / I don't think / Do you think … ?

つまり、should は、I think / I don't think / Do you think …? とよくいっしょに使う、ということです。

I think the government should do more to improve schools.

政府は学校をよくするために、もっと取り組むべきだと思う。

a: Do you think I should apply for this job?
b: Yes, I think you should.

a：この仕事に応募したほうがいいと思う？
b：うん、そうしたほうがいいと思う。

助言のほかに、自分の意見を言うときにも should を使います。I think を付けると、意見であることがはっきりします。

③ shouldn't は、「〜しないほうがいい」と助言するときに使う

教科書には、次の説明があります。

You shouldn't do something = it isn't a good thing to do

つまり、shouldn't は、「それをするのはよくない」という意味です。

You shouldn't believe everything you read in newspapers.

新聞に書いてあることを何でも信じないほうがいい。

I don't think you should work so hard.

そんなに働きすぎないほうがいいと思う。

言い方意味
You shouldn't work so hard.働きすぎないほうがいい
I don't think you should work so hard.働きすぎないほうがいいと思う

「〜しないほうがいいと思う」は、I think you shouldn't … より、I don't think you should … がふつうです（Unit 22B と同じ）。

病気や夜ふかしのような場面にも、should は使えます。

You should see a doctor about that cough.

その咳は医者に診てもらったほうがいい。

You shouldn't drink coffee so late at night.

夜遅くにコーヒーを飲まないほうがいい。

④ should は、must や have to よりも弱い

教科書は、次のように説明しています。

Should is not as strong as must or have to

つまり、should は、must や have to ほど強くない、ということです。

Compare
shouldYou should apologise.謝ったほうがいい。(= it would be a good thing to do)
must / have toYou must apologise. / You have to apologise.謝らなければならない。(= you have no alternative)

状況から考えましょう。同じ「謝る」でも、ほかに選択肢があるかどうかが違います。

英文ほかの選択肢意味
You should apologise.ある（謝らない選択もできる）謝ったほうがいい
You must apologise.ない謝らなければならない

must / have to は、「ほかに選択肢がない」強い義務です。should は「そうするのがよい」という助言なので、するかどうかは相手が決められます。

会話では、心配する言葉として使います。

A: I've had a headache all day.

一日中頭が痛いんだ。

B: You should take a break and drink some water.

休憩して、水を飲んだほうがいいよ。

覚えておきたいのは、should は「そうするのがよい」という助言・意見で、must / have to ほど強くないということです。

意味使う表現例文
〜したほうがいい（助言・意見）shouldYou should go to bed.
〜しないほうがいいshouldn'tYou shouldn't believe everything.
〜しなければならない（強い義務）must / have toYou must apologise.

should ＝ 〜したほうがいい（するかどうかは相手が決める）

Unit 33　Section B

should for what we expect

今回の学習範囲：Section B

Section A では、人に「〜したほうがいい」と助言する should を見ました。実は、should にはもうひとつ、まったく別の顔があります。

「電車は3時に着くはずだ」「あの子なら受かるはずだ」。人にすすめるのではなく、物事の見通しを言う should です。

今回のテーマ「当然そうなるはず」「そうなると期待される」も should で言う

① should は、本来そうなっているはずなのに違うときにも使える

教科書は、次のように説明しています。

We use should when something is not right or what we expect

つまり、should は、本来そうあるはずなのに、そうなっていないときにも使う、ということです。

Where's Tina? She should be here by now.

ティナはどこ？もう来ているはずなのに。

教科書の補足：(= she isn't here yet, and this is not normal)

The price on this packet is wrong. It should be £2.50, not £3.50.

この包みの値段はまちがっている。3.5ポンドではなく、2.5ポンドのはずだ。

状況should の使い方
ティナがまだ来ていない「もう来ているはず」と言う。
値段が合っていない「2.5ポンドのはず」と言う。

「本来そうあるはずなのに、そうなっていない」ことを言っています。

② should は、そうなると期待するときにも使える

教科書の説明を見てみましょう。

We also use should to say that we expect something to happen

つまり、should は、「そうなるはずだ」と期待するときにも使う、ということです。

Helen has been studying hard for the exam, so she should pass.

ヘレンは試験に向けて一生懸命勉強してきたから、受かるはずだ。

教科書の補足：(= I expect her to pass)

There are plenty of hotels in the town. It shouldn't be hard to find a place to stay.

町にはホテルがたくさんある。泊まる場所を見つけるのは難しくないはずだ。

教科書の補足：(= I don't expect it to be hard)

根拠期待
一生懸命勉強してきた受かるはず（should pass）
ホテルがたくさんある難しくないはず（shouldn't be hard）

根拠から、「そうなるはず」と期待しています。否定の shouldn't は、「そうならないはず」という期待です。

③ 助言の should と「はず」の should は、文脈で見分ける

ここは少しややこしいので、should の前に来る主語に注目しましょう。

英文意味見分け方
You should go to bed.寝たほうがいい（助言）人が「する」行動についての助言
She should pass.受かるはずだ（期待）これから起きることへの期待
She should be here by now.もう来ているはずだ（期待）今の状況についての期待

人にすすめる言葉なら助言、物事が起きる見込みなら「はず」です。文脈で判断します。

「はず」の should は、電車や携帯、テストの話にも使えます。

The train should arrive at 3.

電車は3時に着くはずだ。

My phone should be fully charged, but it's at 20%.

携帯はフル充電のはずなのに、20%しかない。

The test shouldn't be too difficult.

テストはそれほど難しくないはずだ。

配達の予定を答える会話です。

A: When will my order arrive?

注文した品はいつ届きますか？

B: It should arrive by Friday.

金曜までには届くはずです。

覚えておきたいのは、should は「そうなるのが自然」という当然や期待も表すということです。

意味使う表現例文
本来そうなっているはず（でも違う）shouldShe should be here by now.
そうなると期待するshould ／ shouldn'tShe should pass. / It shouldn't be hard.

should ＝ 〜のはず（当然・期待）

Unit 33　Section C

should have (done)

今回の学習範囲：Section C

ここから、このユニットでいちばん会話に出てくる形、should have done です。「昨日、あんなこと言わなきゃよかった」「もっと勉強しとけばよかった」。そういう後悔の気持ちを言う表現です。

過去の話なので、これまでのユニットと同じく、have + 過去分詞を足します。

今回のテーマ「〜すべきだったのに」は should have + 過去分詞

① should have done は、「しなかったが、したほうがよかった」ことを表す

教科書は、次のように説明しています。

You should have done something = you didn't do it, but it would have been a good thing to do

つまり、should have done は、実際にはしなかったが、したほうがよかった、という意味です。

You missed a great party last night. You should have come. Why didn't you?

昨夜はすばらしいパーティーだったのに、来なかったね。来ればよかったのに。どうして来なかったの？

教科書の補足：(= you didn't come, but it would have been good to come)

区分内容
実際に起きたことパーティーに来なかった。
本来よかったこと来たほうがよかった。

実際にしたことなら、過去形で「〜した」と言えば済みます。わざわざ should have done と言うのは、実際にはしなかったからです。

I wonder why they're so late. They should have been here long ago.

どうして彼らはこんなに遅いんだろう。ずっと前に着いているはずなのに。

こちらは、Section B の「はず」を過去にした形です。「とっくに着いているはずだった」という意味です。

② shouldn't have done は、「したが、しないほうがよかった」ことを表す

教科書の説明を見てみましょう。

You shouldn't have done something = you did it, but it wasn't a good thing to do

つまり、shouldn't have done は、実際にはしたが、しないほうがよかった、という意味です。

I'm feeling sick. I shouldn't have eaten so much.

気分が悪い。あんなに食べるんじゃなかった。

教科書の補足：(= I ate too much)

She shouldn't have been listening to our conversation. It was private.

彼女は私たちの会話を聞いているべきではなかった。私的な話だったのに。

教科書の補足：(= she was listening)

区分内容
実際に起きたことたくさん食べた。
本来よかったことそんなに食べないほうがよかった。

実際にしたけれど、しないほうがよかった、という意味です。

③ should は今の助言、should have は過去の後悔を表す

Compare
今の助言You look tired. You should go to bed now.疲れているみたいだね。今すぐ寝たほうがいいよ。
過去You went to bed very late last night. You should have gone to bed earlier.昨夜はとても遅く寝たね。もっと早く寝ればよかったのに。
英文時状況
You should go to bed now.今まだ寝ていない。これから寝るよう助言している。
You should have gone to bed earlier.過去もう遅く寝た。過去の行動について言っている。
形実際にしたか
should have doneしなかった（したほうがよかった）
shouldn't have doneした（しないほうがよかった）

後悔や、「着いているはずだった」という不満にも使えます。

I should have studied harder for the test.

テストのために、もっと勉強すればよかった。

You shouldn't have said that to her.

彼女にあんなこと言うべきじゃなかったよ。

The package should have arrived yesterday.

荷物は昨日届いているはずだったのに。

会話では、失敗した友達への一言です。

A: I failed my driving test again.

また運転免許の試験に落ちちゃった。

B: Oh no. You should have practised more.

ああ、もっと練習すればよかったね。

覚えておきたいのは、should have doneは、過去について「実際とは逆のこと」を言うということです。

意味使う表現例文
したほうがよかったのに（しなかった）should have + 過去分詞You should have come.
しないほうがよかったのに（した）shouldn't have + 過去分詞I shouldn't have eaten so much.
今の助言should + 原形You should go to bed now.

should have done ＝ すればよかった　／　shouldn't have done ＝ しなければよかった

Unit 33　Section D

ought to

今回の学習範囲：Section D

最後は、おまけです。should には、ほぼ同じ意味の仲間がいます。

それが ought to です。形のルールだけ、押さえておきましょう。

今回のテーマshould の代わりに ought to も使える

① ought to は、should と同じ意味で使える

教科書は、次のように説明しています。

You can use ought to instead of should in the sentences on this page. We say 'ought to do' (with to)

つまり、このページの should は、すべて ought to に言いかえられる（ought のあとには to が付く）、ということです。

Do you think I ought to apply for this job?

この仕事に応募したほうがいいと思う？

教科書の補足：(= Do you think I should apply … ?)

Jack ought not to go to bed so late.

ジャックはそんなに遅く寝ないほうがいい。

教科書の補足：(= Jack shouldn't go …)

It was a great party last night. You ought to have come.

昨夜はすばらしいパーティーだった。来ればよかったのに。

教科書の補足：(= You should have come)

このユニットの should は、すべて ought to に言いかえられます。ただし、ought のあとには to が付きます。

② ought to には、to が必ず付く

意味should の形ought to の形
助言・意見should ＋ 原形ought to ＋ 原形
否定shouldn't ＋ 原形ought not to ＋ 原形
過去should have ＋ 過去分詞ought to have ＋ 過去分詞

意味は同じですが、ought には必ず to が付きます。否定は、ought not to です。

ought to は、should に置きかえるだけです。形のルールを例で確かめましょう。

You ought to call your parents more often.

もっと両親に電話したほうがいい。

You ought not to drive when you're tired.

疲れているときは運転しないほうがいい。

I ought to have checked the address.

住所を確認しておけばよかった。

補足（教科書外）　ought to は should より少しかたい響きがあり、日常会話では should のほうがよく使われます。

会話では、相談への返事に使います。

A: I've been feeling really stressed lately.

最近、本当にストレスがたまっているんだ。

B: You ought to take a few days off.

何日か休んだほうがいいよ。

覚えておきたいのは、ought toは should と同じ意味で、あとに to が付くということです。

形使う表現例文
助言・意見ought to + 原形 ＝ shouldYou ought to apply for this job.
否定ought not to + 原形 ＝ shouldn'tJack ought not to go to bed so late.
過去ought to have + 過去分詞 ＝ should haveYou ought to have come.

ought to ＋ 原形 ＝ should ＋ 原形
