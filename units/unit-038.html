UNIT 38

if I do … and if I did …

Unit 38　if I do と if I did

「バスで行くなら安いよ」。この「なら」は、2種類あります。ありうる「なら」と、ありえない「なら」です。英語は、動詞の形で、この2つをきっちり言い分けます。

今日の合言葉は、形は過去でも、意味は過去ではないです。

セクションの地図

Section扱う内容ひとことで言うと
Aif we take と if we tookありうるか、ありえないか
Bif + 過去形の意味起こると思っていない想像
Cwould をどこに置くかif の側には置かない

色の対応

if + 現在形（実際にありうる）＝青、if + 過去形（想像）＝橙、would / could / might（結果の部分）＝紫、誤り＝赤。

Unit 38　Section A

if we take and if we took

今回の学習範囲：Section A

同じ「バスで行く」でも、話している時点の状況で、動詞の形が変わります。

今回のテーマ実際にありうるなら「if + 現在形」、起こらないと分かっているなら「if + 過去形」

① まだ決まっていないなら、if + 現在形 ＋ will を使う

リサとジェスは、バスか電車かで迷っています。

Compare these examples (1)
LISA: Shall we take the bus or the train?JESS: If we take the bus, it will be cheaper.リサ：バスで行く？電車で行く？
ジェス：バスで行くなら、そのほうが安くなるよ。

バスで行く可能性が、まだ残っています。だから、現在形の if と will を使います。

区分内容
ジェスの考えバスで行く可能性がある（まだ決まっていない）。
ジェスの言い方If we take the bus, it will be cheaper.

天気の話にも、同じ形が使えます。まだ降るかどうか分からない場面です。

If it rains tomorrow, we will stay at home.

明日雨が降ったら、家にいよう。

② もう決まったなら、if + 過去形 ＋ would を使う

2人は、電車で行くことに決めました。あとで、ジェスがジョーに話します。

Compare these examples (2)
Lisa and Jess decide to take the train. Later, Jess talks to Joe.JOE: How are you going to travel?JESS: We're going to take the train. If we took the bus, it would be cheaper, but the train is quicker.リサとジェスは電車で行くことにした。あとで、ジェスがジョーと話す。
ジョー：どうやって行くの？
ジェス：電車で行くよ。バスで行くなら安いけど、電車のほうが速いから。

もうバスには乗りません。「乗るとしたら」という頭の中の話なので、if + 過去形と would です。

区分内容
ジェスの考え電車で行くと決めた。バスで行くことはもうない。
ジェスの言い方If we took the bus, it would be cheaper.

こんな場面にも使えます。買う気がまったくない車の話です。

I'm not going to buy a car. If I bought one, I would have to pay for parking.

車を買うつもりはない。買うとしたら、駐車場代を払わなければならなくなる。

③ 同じ「バスで行く」でも、状況しだいで形が変わる

状況使う形意味
まだ決まっていないif + 現在形、willバスで行くなら、安くなる。
もう決まった（行かない）if + 過去形、would（行かないけれど）バスで行くなら、安くなる。

間違いやすいのは、ありうる話に過去形を使うことです。まだ決まっていないなら、現在形です。

If I see him tomorrow, I will tell him. (not If I saw him tomorrow, I will tell him)

明日会ったら、伝えるよ。

会話では、まだ迷っているときに、現在形の if を使います。

A: Are you going to take the job?

その仕事、受けるの？

B: I'm still thinking. If I take it, I'll move to Tokyo.

まだ考え中。受けるなら、東京に引っ越すよ。

覚えておきたいのは、実際にありうるならif + 現在形、起こらないと分かっているならif + 過去形を使うということです。

状況使う形例文
まだ決まっていないif + 現在形、willIf we take the bus, it will be cheaper.
もう決まった（起こらない）if + 過去形、wouldIf we took the bus, it would be cheaper.

ありうる → if + 現在形 ＋ will　／　起こらない → if + 過去形 ＋ would

Unit 38　Section B

if + past

今回の学習範囲：Section B

if + 過去形は、過去の話ではありません。今や未来の、頭の中の話です。この感覚をつかみましょう。

今回のテーマif + 過去形は、起こらないこと・起こると思っていないことを言う（意味は過去ではない）

① if + 過去形は、起こると思っていないことを言う

教科書は、次のように説明しています。

When we talk about something that will not happen, or we don't expect that it will happen, we use if + past (if we went / if there was etc.). But the meaning is not past:

つまり、起こらないこと、起こると思っていないことは、if + 過去形（if we went / if there was など）で言い、意味は過去ではない、ということです。

大金が当たる、というのは、ふつうは起こりません。

What would you do if you won a lot of money?

大金が当たったら、どうする？

教科書の補足：(I don't really expect this to happen)

明日選挙はありません。ないと分かっていて、あったらどうなるかを聞いています。

If there was an election tomorrow, who would you vote for?

明日選挙があるなら、誰に投票する？

教科書の補足：(there will not be an election tomorrow)

否定の形でも、同じです。「来ると思っている」ことが、ここでは大事です。

I'd be surprised if they didn't come to the party.

彼らがパーティーに来なかったら、驚くだろう。

教科書の補足：(I expect them to come)

英文実際には形
What would you do if you won a lot of money?当たるとは思っていないif + 過去形
If there was an election tomorrow, …明日、選挙はないif + 過去形
I'd be surprised if they didn't come.来ると思っているif + 過去形

3つとも、形は過去ですが、意味は今や未来です。

② 見つかる可能性があるなら find、ふつうは起こらないなら found

同じ「見つける」でも、可能性があるかどうかで、形が変わります。

Compare if I find and if I found
現実的I think I left my watch at your house. If you find it, can you call me?腕時計をあなたの家に忘れてきたと思う。見つけたら、電話してくれる？
想像If you found a wallet in the street, what would you do with it?道で財布を見つけたら、どうする？
状況使う形理由
腕時計を忘れたかもしれないif you find見つかる可能性が実際にある
道で財布を見つけるif you foundふつうは起こらない（想像の話）

「もっと時間があれば」のように、今の状況を変えて想像する場面でも、過去形を使います。

If I had more time, I'd learn Spanish.

もっと時間があれば、スペイン語を習うのに。

What would you do if you lost your phone?

携帯をなくしたら、どうする？

間違いやすいのは、過去の意味だと思ってしまうことです。「昨日、お金が当たったら」という意味にはなりません。

If I won a lot of money, I'd buy a house. (not If I would win)

大金が当たったら、家を買うのに。

会話では、相手の夢を聞く質問によく使います。

A: What would you do if you won a lot of money?

大金が当たったら、どうする？

B: I'd travel around the world.

世界一周旅行をするよ。

覚えておきたいのは、if + 過去形は、形は過去でも意味は過去ではなく、起こらない・起こると思っていないことの想像だということです。

状況使う形例文
実際にありうるif + 現在形If you find it, can you call me?
起こると思っていない（想像）if + 過去形If you found a wallet, what would you do?

if + 過去形 ＝ 今や未来の想像（意味は過去ではない）

Unit 38　Section C

would in the other part

今回の学習範囲：Section C

if の側は過去形でした。では、would はどこに置くのでしょうか。答えは、if ではないほうです。

今回のテーマwould は if の部分には使わない。もう一方の部分に使う

① would は、if の部分には使わない

教科書は、次のように説明しています。

We do not normally use would in the if-part of the sentence:

つまり、if の部分には、ふつう would を使わない、ということです。

日本語の「〜だろうなら」に引きずられやすい場所です。if のすぐあとは、ふつうの過去形を置きます。

I'd be very scared if somebody pointed a gun at me. (not if somebody would point)

誰かに銃を向けられたら、とても怖いだろう。

If we went by bus, it would be cheaper. (not If we would go)

バスで行くなら、そのほうが安いだろう。

② would は、if ではないほうに置く

教科書の説明を見てみましょう。

In the other part of the sentence (not the if-part) we use would ('d) / wouldn't:

つまり、if ではないもう一方の部分には would / wouldn't を使う、ということです。

「怖いだろう」「眠れないだろう」のように、結果を言う側が would です。

I'd be (= I would be) scared if somebody pointed a gun at me.

誰かに銃を向けられたら、怖いだろう。

I'm not going to bed yet. I'm not tired. If I went to bed now, I wouldn't sleep.

まだ寝ない。眠くないから。今寝ても、眠れないだろう。

質問の文でも、would は結果の側にあります。

What would you do if you were bitten by a snake?

ヘビにかまれたら、どうする？

部分使う形例
if の部分過去形if I went to bed now
もう一方の部分would / wouldn't + 原形I wouldn't sleep

③ would の代わりに、could や might も使える

教科書には、次の説明があります。

Could and might are also possible:

つまり、would の代わりに could や might も使える、ということです。

「かもしれない」なら might、「できるだろう」なら could です。

If I won a lot of money, I might buy a house.

大金が当たったら、家を買うかもしれない。

教科書の補足：(= it is possible that I would buy a house)

If it stopped raining, we could go out.

雨がやんだら、出かけられるのに。

教科書の補足：(= we would be able to go out)

形意味
if + 過去形、would + 原形〜だろう
if + 過去形、might + 原形〜かもしれない
if + 過去形、could + 原形〜できるだろう

部屋や車の話にも使えます。広い部屋があったら、車があったら、という想像です。

If I had a bigger flat, I would invite more friends.

もっと広い部屋があれば、もっと友達を招くのに。

If I had a car, I could drive to work.

車があれば、車で通勤できるのに。

会話では、「もしも」の相談によく出ます。

A: What would you do if you missed the last train?

終電を逃したら、どうする？

B: I'd take a taxi.

タクシーに乗るよ。

覚えておきたいのは、if の部分には過去形を使い、もう一方の部分に would（could / might）を使うということです。

部分使う形例文
if の部分過去形（would は×）If we went by bus, …
もう一方の部分would / could / might + 原形…, it would be cheaper.

if + 過去形、would（could / might）+ 原形
