UNIT 43

Passive 2 (be done / been done / being done)

Unit 43　受け身 2（be done / been done / being done）

受け身（be + 過去分詞）は、形が1つではありません。will のあと、have のあと、進行形。be の部分が、そのつど姿を変えます。

Unit 42 の受け身は、am / is / are / was / were だけでした。今日は、それ以外の形を4つ見ます。ポイントは、be が be / been / being に変わることです。

セクションの地図

Section扱う内容
A不定詞の受け身（be done）
B完了不定詞の受け身（have been done）
C現在完了・過去完了の受け身（has been done / had been done）
D進行形の受け身（is being done / was being done）

色の対応

能動態＝青、受け身＝橙、be / been / being ＝紫、誤り＝赤。

Unit 43　Section A

be done

今回の学習範囲：Section A

「手遅れになる前に、何かしなければならない」。この「しなければならない」を受け身にすると、どうなるでしょうか。

答えは、must be done。助動詞のあとは、be が原形のまま残ります。

今回のテーマwill / must / can などのあとは、be + 過去分詞

① will / must / can などのあとの受け身は、be + 過去分詞になる

Infinitive
能動態Somebody will clean this room later.誰かが後でこの部屋を掃除する。
受け身This room will be cleaned later.この部屋は後で掃除される。
能動態受け身
(to) do / clean / see など(to) be + done / cleaned / seen など

能動態の原形（do / clean）が、受け身では be + 過去分詞になります。

② going to や to のあとも、be + 過去分詞で言える

The situation is serious. Something must be done before it's too late.

状況は深刻だ。手遅れになる前に、何かしなければならない。

A mystery is something that can't be explained.

ミステリーとは、説明できないもののことだ。

The music was very loud and could be heard from a long way away.

音楽はとても大きく、遠くからでも聞こえた。

A new supermarket is going to be built next year.

来年、新しいスーパーが建てられる予定だ。

Please go away. I want to be left alone.

あっちへ行って。一人にしておいてほしい。

形例
will / must / can / could + be + 過去分詞must be done / can't be explained / could be heard
going to + be + 過去分詞is going to be built
want to + be + 過去分詞I want to be left alone

間違いやすいのは、be を is / was にしてしまうことです。助動詞のあとは、原形の be です。

The room will be cleaned later. (not will is cleaned)

その部屋は後で掃除される。

will や must のあとの受け身は、予定や依頼の場面にも使えます。

The results will be announced tomorrow.

結果は明日発表される。

The tickets can be bought online.

チケットはオンラインで買える。

会話では、予定を聞かれたときに、受け身で答えます。

A: When will the project be finished?

プロジェクトはいつ終わるの？

B: It will be finished next week.

来週終わる予定だよ。

確認テスト

覚えておきたいのは、will / must / can などのあとの受け身は、be + 過去分詞だということです。

形受け身例文
能動態の原形(to) be + 過去分詞Something must be done.
willwill be + 過去分詞This room will be cleaned later.

will / must / can / going to / to ＋ be ＋ 過去分詞

Unit 43　Section B

have been done

今回の学習範囲：Section B

Section A は、これから先の話でした。では、「されていたかもしれない」「されているべきだった」のような、過去の話はどうでしょうか。

Unit 27〜40 で学んだ形に、been を足すだけです。

今回のテーマshould have / might have などのあとは、have been + 過去分詞

① should have / might have のあとの受け身は、have been + 過去分詞になる

Perfect infinitive
能動態Somebody should have cleaned the room.誰かがその部屋を掃除しておくべきだった。
受け身The room should have been cleaned.その部屋は掃除されているべきだった。
能動態受け身
(to) have + done / cleaned / seen など(to) have been + done / cleaned / seen など

have + 過去分詞が、受け身では have been + 過去分詞になります。

② would have や seem to のあとも、have been + 過去分詞で言える

I haven't received the letter yet. It might have been sent to the wrong address.

まだ手紙を受け取っていない。間違った住所に送られたのかもしれない。

If you had locked the car, it wouldn't have been stolen.

車に鍵をかけていたら、盗まれなかっただろうに。

There were some problems at first, but they seem to have been solved.

最初は問題がいくつかあったが、解決されたようだ。

形例
might / would / should + have been + 過去分詞might have been sent / wouldn't have been stolen
seem to + have been + 過去分詞seem to have been solved

Unit 27〜40 で学んだ形に、been を足すだけです。

「〜されているべきだった」は、後悔や推測の場面で使います。

The report should have been finished yesterday.

そのレポートは昨日終わっているべきだった。

My bag might have been taken by mistake.

私のかばんは間違って持っていかれたのかもしれない。

会話では、探し物のときに、過去の推測で言えます。

A: I can't find my keys.

鍵が見つからない。

B: They might have been left at the office.

会社に置き忘れられたのかもしれないね。

確認テスト

覚えておきたいのは、過去のことの受け身はhave been + 過去分詞だということです。

形受け身例文
能動態have + 過去分詞Somebody should have cleaned the room.
受け身have been + 過去分詞The room should have been cleaned.

should / might / would ＋ have ＋ been ＋ 過去分詞

Unit 43　Section C

has been done and had been done

今回の学習範囲：Section C

ここまでは助動詞のあとの受け身でした。次は、完了形の受け身です。結果や理由を言うときに、よく出てきます。

能動態の have / has / had + 過去分詞に、been を足すだけです。

今回のテーマ完了の受け身は、have / has / had + been + 過去分詞

① 現在完了の受け身は、have / has been + 過去分詞になる

Present perfect
能動態The room looks nice. Somebody has cleaned it.部屋がきれいだ。誰かが掃除した。
受け身The room looks nice. It has been cleaned.部屋がきれいだ。掃除された。

Have you heard? The trip has been cancelled.

聞いた？旅行が中止になったよ。

Have you ever been bitten by a dog?

犬にかまれたことはある？

'Are you going to the party?' 'No, I haven't been invited.'

「パーティーに行く？」「ううん、招待されていないんだ。」

② 過去完了の受け身は、had been + 過去分詞になる

Past perfect
能動態The room looked nice. Somebody had cleaned it.部屋がきれいだった。誰かが掃除していた。
受け身The room looked nice. It had been cleaned.部屋がきれいだった。掃除されていた。

The vegetables didn't taste good. They had been cooked too long.

野菜はおいしくなかった。長く煮すぎられていた。

The car was three years old, but hadn't been used very much.

その車は3年たっていたが、あまり使われていなかった。

時能動態受け身
現在完了have / has + 過去分詞have / has been + 過去分詞
過去完了had + 過去分詞had been + 過去分詞

間違いやすいのは、been の抜けです。been がないと、受け身になりません。

The room has been cleaned. (not The room has cleaned)

その部屋は掃除された。

現在完了や過去完了の受け身は、結果や理由を言うときに便利です。

The window has been repaired.

窓は修理された。

The flight had been delayed, so we waited.

便が遅れていたので、私たちは待った。

会話では、仕事の進み具合を答えるときに使います。

A: Is the report ready?

レポートはできた？

B: Yes, it has been sent to the client.

うん、お客様に送られたよ。

確認テスト

覚えておきたいのは、完了の受け身は、have / has / had + been + 過去分詞だということです。

時受け身の形例文
現在完了have / has been + 過去分詞The room has been cleaned.
過去完了had been + 過去分詞The room had been cleaned.

have / has / had ＋ been ＋ 過去分詞

Unit 43　Section D

is being done and was being done

今回の学習範囲：Section D

最後は、「今まさに〜されている最中」の受け身です。工事や作業の話によく出ます。

進行形の -ing が、受け身では being に変わります。

今回のテーマ進行形の受け身は、am / is / are / was / were + being + 過去分詞

① 現在進行形の受け身は、am / is / are + being + 過去分詞になる

Present continuous
能動態Somebody is cleaning the room at the moment.今、誰かがその部屋を掃除している。
受け身The room is being cleaned at the moment.その部屋は今、掃除されている。

There's somebody walking behind us. I think we are being followed.

後ろに誰かが歩いている。つけられている気がする。

A new bridge is being built across the river. It will be finished next year.

川に新しい橋が建設中だ。来年完成する。

② 過去進行形の受け身は、was / were + being + 過去分詞になる

Past continuous
能動態Somebody was cleaning the room when I arrived.私が着いたとき、誰かがその部屋を掃除していた。
受け身The room was being cleaned when I arrived.私が着いたとき、その部屋は掃除されている最中だった。

There was somebody walking behind us. I think we were being followed.

後ろに誰かが歩いていた。つけられていた気がする。

時能動態受け身
現在進行形am / is / are + -ingam / is / are being + 過去分詞
過去進行形was / were + -ingwas / were being + 過去分詞

間違いやすいのは、being の抜けです。「されている最中」には being が必要です。

The room is being cleaned now. (not The room is cleaned now)

その部屋は今、掃除されている最中だ。

進行形の受け身は、工事や作業の「今まさに」を言うときに使います。

The road is being repaired this week.

道路は今週、修理中だ。

The documents were being checked when I called.

私が電話したとき、書類は確認されている最中だった。

会話では、「今ちょうど〜されている最中」と断るときに使います。

A: Can I use the meeting room?

会議室を使える？

B: Sorry, it's being cleaned right now.

ごめん、今ちょうど掃除されている最中なんだ。

確認テスト

覚えておきたいのは、進行形の受け身は、be + being + 過去分詞で、「〜されている最中」を表すということです。

時受け身の形例文
現在進行形am / is / are being + 過去分詞The room is being cleaned.
過去進行形was / were being + 過去分詞The room was being cleaned.

be（am / is / are / was / were）＋ being ＋ 過去分詞
