UNIT 51

Auxiliary verbs (have/do/can etc.) / I think so / I hope so etc.

Unit 51　助動詞の省略と I think so

会話のうまい人は、同じ言葉を繰り返しません。「ドア閉めた？」「閉めたよ」。英語では、助動詞だけで答えるのが自然です。

今日は、助動詞だけで答える・反対する、相づちの Have you?、「私もです」の So am I / Neither do I、そして I think so を見ます。会話の「ことばのリズム」がよくなります。

セクションの地図

Section扱う内容
A助動詞だけで答える・否定する
BHave you? / Isn't she? で関心や驚きを示す
Cso と neither（So am I / Neither do I）
DI think so / I hope so / I'm afraid so など

色の対応

助動詞＝青、主動詞＝橙、so / neither ＝緑、I think so など＝紫、誤り＝赤。

Unit 51　Section A

auxiliary verbs

今回の学習範囲：Section A

「ドアに鍵をかけた？」と聞かれたら、あなたはどう答えますか。

Yes, I have locked the door. と全部言うのは、不自然です。Yes, I have. で十分です。

今回のテーマ助動詞だけで、繰り返しを避けて答えられる

① 文の中には、助動詞と主動詞がある

教科書は、まず助動詞と主動詞の区別を示しています。

In these sentences there is an auxiliary verb and a main verb:

つまり、文の中には、助動詞（auxiliary verb）と主動詞（main verb）がある、ということです。

助動詞主動詞文
havelostI have lost my keys.
can'tcomeShe can't come to the party.
wasbuiltThe hotel was built ten years ago.
dowantWhy do you want to go home?

have / can't / was / do は、助動詞（helping verb）です。主動詞を助けて、時や否定、疑問などを作ります。

② 繰り返しを避けたいときは、助動詞だけで答えられる

教科書は、助動詞を使って繰り返しを避ける方法を説明しています。

You can use an auxiliary verb when you don't want to repeat something:

つまり、同じ言葉を繰り返したくないときは、助動詞だけで言える、ということです。

'Have you locked the door?' 'Yes, I have.'

「ドアに鍵をかけた？」「うん、かけたよ。」

教科書の補足：(= I have locked the door)

Gary wasn't working, but Laura was.

ゲイリーは働いていなかったが、ローラは働いていた。

教科書の補足：(= Laura was working)

Jessica could lend me the money, but she won't.

ジェシカは私にお金を貸せるが、貸さないだろう。

教科書の補足：(= she won't lend me the money)

英文省略された部分
Yes, I have.locked the door
…but Laura was.working
…but she won't.lend me the money

動詞のあとの部分を省略して、助動詞だけで答えます。

③ 現在形・過去形の文には、do / does / did で答える

助動詞のない現在形・過去形の文では、次のようにします。

We use do/does/did for the present and past simple:

つまり、現在形と過去形の文には、do / does / did を使って答える、ということです。

'Do you like onions?' 'Yes, I do.'

「玉ねぎは好き？」「うん、好きだよ。」

教科書の補足：(= I like onions)

'Does Simon live in London?' 'He did, but he doesn't any more.'

「サイモンはロンドンに住んでいるの？」「住んでいたけど、もう住んでいないよ。」

ふつうの動詞（like / live）には、do / does / did で答えます。間違いやすいのは、Yes, I like. のように、動詞だけで答える形です。

④ 助動詞を使って、相手の言ったことに反対できる

助動詞は、相手に反対するときにも使えます。

You can use auxiliary verbs to deny what somebody says (= say it is not true):

つまり、助動詞を使って、相手の言ったことを否定（本当ではないと言うこと）できる、ということです。

'You're sitting in my place.' 'No, I 'm not.'

「あなたは私の席に座っているよ。」「いいえ、座っていません。」

教科書の補足：(= I'm not sitting in your place)

'You didn't lock the door before you left.' 'Yes, I did.'

「出かける前にドアに鍵をかけなかったでしょう。」「いや、かけたよ。」

教科書の補足：(= I locked the door)

相手の言葉反対する答え
You're sitting in my place.No, I'm not.
You didn't lock the door.Yes, I did.

相手が肯定なら否定の助動詞（I'm not）、相手が否定なら肯定の助動詞（I did）で、反対します。

助動詞だけの答えは、準備ができたか聞かれたときにも、反対するときにも使えます。

'Are you ready?' 'Yes, I am.'

「準備はいい？」「うん、できてるよ。」

'You broke it.' 'No, I didn't.'

「あなたが壊したんでしょう。」「いや、壊してないよ。」

会話では、自分への疑いを否定するときに使います。

A: You forgot to call me.

電話するのを忘れたでしょう。

B: No, I didn't. I called you at six.

ううん、忘れてないよ。6時に電話したよ。

確認テスト

覚えておきたいのは、同じ言葉を繰り返したくないときは、助動詞だけで答えられるということです。

場面使う形例
繰り返しを避ける助動詞Yes, I have.
現在形・過去形do / does / didYes, I do. / He did.
相手に反対する助動詞の肯定・否定No, I'm not. / Yes, I did.

助動詞だけで答える（動詞は省略する）

Unit 51　Section B

showing interest

今回の学習範囲：Section B

助動詞は、答えるだけでなく、相づちにも使えます。

「たった今、スティーブンに会ったよ」「ああ、そうなの？」。この「そうなの？」を作ります。

今回のテーマHave you? / Isn't she? / Are they? で、関心や驚きを示す

① Have you? / Isn't she? で、関心や驚きを示す

教科書は、相手の話を聞いたときの反応の仕方を説明しています。

We use have you? / isn't she? / are they? etc. to show that we are interested in what somebody has said, or to show surprise:

つまり、have you? / isn't she? / are they? などは、相手の話に関心があること、または驚いたことを示すときに使う、ということです。

'I've just seen Steven.' 'Oh, have you? How is he?'

「たった今、スティーブンに会ったよ。」「ああ、そうなの？元気だった？」

'Lisa isn't very well today.' 'Isn't she? What's wrong with her?'

「リサは今日、あまり体調がよくないんだ。」「そうなの？どうしたの？」

'It rained every day during our holiday.' 'Did it? What a shame!'

「休暇中、毎日雨が降ったんだ。」「そうなの？残念だったね！」

'James and Tanya are getting married.' 'Are they? Really?'

「ジェームズとターニャが結婚するんだって。」「そうなの？本当に？」

相手の言葉こちらの反応助動詞
I've just seen Steven.Oh, have you?have
Lisa isn't very well today.Isn't she?isn't（否定）
It rained every day.Did it?did
James and Tanya are getting married.Are they?are

相手の言葉の助動詞（have / isn't / did / are）を使って、短い疑問文で反応します。主語は、代名詞（you / she / it / they）にします。間違いやすいのは、助動詞を間違えることです。

'I've just seen Steven.' 'Oh, have you?' (not do you)

「たった今、スティーブンに会ったよ。」「ああ、そうなの？」

相づちは、旅行の予定や、悪いニュースにも使えます。

'I'm going to Paris next week.' 'Are you? For how long?'

「来週パリに行くんだ。」「そうなの？どのくらい？」

'Ken lost his job.' 'Did he? I'm sorry to hear that.'

「ケンが仕事を失ったんだ。」「そうなの？それは気の毒に。」

会話では、いい知らせに、相づちで返します。

A: I've just won a prize.

賞をもらったんだ。

B: Have you? Congratulations!

そうなの？おめでとう！

確認テスト

覚えておきたいのは、Have you? / Isn't she? / Are they?などで、相手の話に関心や驚きを示せるということです。

相手の言葉反応例
肯定の文肯定の助動詞 + 主語?'I've seen Steven.' 'Have you?'
否定の文否定の助動詞 + 主語?'Lisa isn't well.' 'Isn't she?'

相手の助動詞 ＋ 主語（代名詞）? ＝ そうなの？

Unit 51　Section C

so and neither

今回の学習範囲：Section C

次は、「私もです」です。日本語は一言ですが、英語はso と neitherの2つがあります。

相手が肯定なら so、否定なら neither です。

今回のテーマ「私もです」は、肯定なら So am I、否定なら Neither do I

① 「〜もです」は、肯定なら so、否定なら neither で言う

教科書は、so と neither の使い方を説明しています。

We use auxiliary verbs with so and neither:

つまり、「〜もです」と言うときは、so や neither といっしょに助動詞を使う、ということです。

'I'm tired.' 'So am I.'

「疲れた。」「私もです。」

教科書の補足：(= I'm tired too)

'I never read newspapers.' 'Neither do I.'

「新聞は読まないな。」「私も読まないよ。」

教科書の補足：(= I never read newspapers either)

Sarah can't drive and neither can Mark.

サラは運転できないし、マークもできない。

相手の言葉「私も」形
I'm tired.（肯定）So am I.so ＋ 助動詞 ＋ 主語
I never read newspapers.（否定）Neither do I.neither ＋ 助動詞 ＋ 主語

肯定にはso、否定にはneither。助動詞は、相手の言葉に合わせます。

② so / neither のあとは、助動詞が主語の前に来る

語順に注意が必要です。

Note the word order after so and neither (verb before subject):

つまり、so や neither のあとは、動詞（助動詞）が主語の前に来る、ということです。

I passed the exam and so did Paul. (not so Paul did)

私は試験に受かったし、ポールも受かった。

語順正誤
so ＋ did ＋ Paul正しい
× so Paul did誤り

so / neither のあとは、助動詞 + 主語の順です。間違いやすいのは、so Paul did のような語順です。

③ neither の代わりに、nor や not … either も使える

neither には、言いかえの表現があります。

Instead of neither, you can use nor. You can also use not … either:

つまり、neither の代わりに nor も使える。また、not … either でも同じ意味を表せる、ということです。

言い方例
Neither ＋ 助動詞 ＋ 主語'I don't know.' 'Neither do I.'
Nor ＋ 助動詞 ＋ 主語'I don't know.' 'Nor do I.'
主語 ＋ 助動詞 ＋ not either'I don't know.' 'I don't either.'

so や neither は、好き嫌いや苦手な話にも使えます。

'I love chocolate.' 'So do I.'

「チョコレートが大好き。」「私も。」

'I can't swim.' 'Neither can I.'

「泳げないんだ。」「私も泳げない。」

会話では、「私も」と気持ちを合わせるときに使います。

A: I'm hungry.

おなかがすいた。

B: So am I. Let's have lunch.

私も。お昼にしよう。

確認テスト

覚えておきたいのは、「〜もです」は、肯定ならso + 助動詞 + 主語、否定ならneither + 助動詞 + 主語だということです。

相手の言葉「私も」例
肯定So ＋ 助動詞 ＋ 主語'I'm tired.' 'So am I.'
否定Neither ＋ 助動詞 ＋ 主語'I never read newspapers.' 'Neither do I.'

So ＋ 助動詞 ＋ 主語　／　Neither ＋ 助動詞 ＋ 主語

Unit 51　Section D

I think so, I hope so

今回の学習範囲：Section D

最後は、I think so です。これも、繰り返しを避ける便利な形です。

否定の形に、1つ落とし穴があります。

今回のテーマ同じ言葉の繰り返しを避けて、I think so / I hope so と言える

① I think so / I suppose so は、繰り返しを避ける言い方になる

教科書は、I think so などの使い方を説明しています。

You can say I think so / I suppose so etc. when we don't want to repeat something:

つまり、同じ言葉を繰り返したくないときは、I think so / I suppose so などと言える、ということです。

'Are those people Korean?' 'I think so.'

「あの人たちは韓国人？」「そう思うよ。」

教科書の補足：(= I think they are Korean)

'Is Kate working tomorrow?' 'I suppose so.'

「ケイトは明日働くの？」「そうだと思う。」

教科書の補足：(= I suppose she is working tomorrow)

'Will you be at home this evening?' 'I expect so.'

「今晩、家にいる？」「いると思うよ。」

教科書の補足：(= I expect I'll be at home …)

I hope so / I guess so / I'm afraid so も、同じように使えます。

② hope と be afraid の否定は、not を使う

否定の形は、次のようになります。

The usual negative forms are: I think so / I expect so → I don't think so / I don't expect so

つまり、否定の形は決まっていて、動詞によって違う、ということです。

肯定否定
I think so / I expect soI don't think so / I don't expect so
I hope so / I'm afraid soI hope not / I'm afraid not
I guess so / I suppose soI guess not / I suppose not

'Is that woman American?' 'I think so. / I don't think so.'

「あの女性はアメリカ人？」「そうだと思う。／そうは思わない。」

'Do you think it will rain?' 'I hope so. / I hope not.' (not I don't hope so)

「雨が降ると思う？」「降ってほしい。／降らないでほしい。」

hope と be afraid には、don't を付けません。間違いやすいのは、I don't hope so です。

I think so は、天気や予定の質問にも使えます。

'Is she at home?' 'I think so.'

「彼女は家にいる？」「いると思う。」

'Will it be cold tomorrow?' 'I hope not.'

「明日は寒いかな？」「寒くないといいな。」

会話では、「そう願ってる」と答えるときに使います。

A: Do you think we'll win?

私たち、勝てると思う？

B: I hope so!

そう願ってる！

確認テスト

覚えておきたいのは、I think so / I hope soは繰り返しを避ける言い方で、hope と be afraid の否定は notを使うということです。

肯定否定
I think so / I expect soI don't think so / I don't expect so
I hope so / I'm afraid soI hope not / I'm afraid not
I guess so / I suppose soI guess not / I suppose not

I think / hope / suppose so ＝ そう思う・願う・思う　／　hope・afraid の否定 ＝ not
