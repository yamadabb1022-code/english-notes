UNIT 57

Verb + -ing or to … 2 (try, need, help)

Unit 57　動詞 + -ing か to …（2）

このユニットでは、try・need・help のあとの -ing と to … を比べます。前の Unit 56 と同じように、形によって意味が変わります。

セクションの地図

Section扱う内容
Atry to … ＝ 努力する／try -ing ＝ 試しにやってみる
Bneed to … ＝ する必要がある／need -ing ＝ 〜される必要がある
Chelp (to) do ＝ 手伝う／can't help -ing ＝ 〜せずにいられない

色の対応

-ing ＝ 青、to … ＝ 緑、to のない形 ＝ 紫、誤り＝赤。

Unit 57　Section A

try to … and try -ing

今回の学習範囲：Section A

try は、あとに to … が来るか -ing が来るかで、意味が変わります。

今回のテーマtry to … ＝ 努力する、try -ing ＝ 試しにやってみる

① try to do ＝ しようと努力する

教科書は、次のように説明しています。

try to do = attempt to do, make an effort to do:

つまり、try to do ＝ しようとする、努力する。

I was very tired. I tried to keep my eyes open, but I couldn't.

とても疲れていた。目を開けておこうとしたが、できなかった。

Please try to be quiet when you come home. Everyone will be asleep.

帰ってきたら、静かにするようにしてね。みんな寝ているから。

「できるかどうか分からないが、がんばる」という意味です。結果はうまくいかないこともあります。

② try -ing ＝ 試しにやってみる

教科書の説明を見てみましょう。

try something or try doing something = do it as an experiment or test:

つまり、try something や try doing something ＝ 実験・テストとして、やってみる。

These cakes are delicious. You should try one.

このケーキはおいしいよ。1つ食べてみたら。

教科書の補足：(= have one to see if you like it)

We couldn't find anywhere to stay. We tried every hotel in the town, but they were all full.

泊まる場所が見つからなかった。町のどのホテルも当たってみたが、どこも満室だった。

a: The photocopier doesn't seem to be working.
b: Try pressing the green button.

a：コピー機が動いていないみたい。
b：緑のボタンを押してみて。

教科書の補足：(= press the green button – perhaps this will help to solve the problem)

形意味結果
try to doしようと努力するできないこともある
try -ing効果を確かめるために、やってみる実際にやっている

③ 2つの違い（Compare）

Compare
try toI tried to move the table, but it was too heavy.私はテーブルを動かそうとしたが、重すぎた。(so I couldn't move it)
try -ingI didn't like the way the furniture was arranged, so I tried moving the table to the other side of the room. But it didn't look right, so I moved it back again.家具の配置が気に入らなかったので、テーブルを部屋の反対側に動かしてみた。でも、しっくりこなかったので、元に戻した。(I tried moving it = I moved it to see if it looked better)
状況使う形テーブルは動いたか
重すぎて動かせなかったtried to move動いていない
動かして、様子を見たtried moving動いている

tried to move は「動かそうとした（動かなかった）」、tried moving は「実際に動かして確かめた」です。

追加例文（教科書外）
try toI tried to call you, but your phone was off.電話しようとしたけれど、電源が切れていたよ。
try -ingWhy don't you try using a different password?別のパスワードを使ってみたら？

確認テスト

覚えておきたいのは、try toは「努力する（できないこともある）」、try -ingは「試しにやってみる」だということです。

形意味例文
try to doしようと努力するI tried to move the table, but it was too heavy.
try -ing効果を確かめるためにやってみるI tried moving the table to see if it looked better.

try to do ＝ 努力する　／　try -ing ＝ 試しにやる

Unit 57　Section B

need to … and need -ing

今回の学習範囲：Section B

Section A では、try の2つの形を見ました。

今回は、need の2つの形です。

今回のテーマneed to do ＝ する必要がある、need -ing ＝ 〜される必要がある

① need to do ＝ する必要がある

教科書は、次のように説明しています。

I need to do something = it is necessary for me to do it:

つまり、I need to do something ＝ 私がそれをする必要がある。

He needs to work harder if he wants to make progress.

進歩したいなら、彼はもっと一生懸命働く必要がある。

I don't need to come to the meeting, do I?

私は会議に出なくてもいいよね？

主語がする必要がある、という意味です。主語が「する人」です。

② need -ing ＝ 〜される必要がある

教科書の説明を見てみましょう。

You can say that something needs -ing:

つまり、something needs -ing とも言える。

My phone needs charging.

私の携帯は、充電が必要だ。

教科書の補足：(= it needs to be charged)

Does your suit need cleaning?

あなたのスーツはクリーニングが必要？

教科書の補足：(= … need to be cleaned)

It's a difficult problem. It needs thinking about carefully.

難しい問題だ。注意深く考える必要がある。

教科書の補足：(= it needs to be thought about carefully)

形主語は意味
need to doする人主語が、〜する必要がある
need -ingされる物主語が、〜される必要がある

③ 2つの違い（Compare）

Compare
need to doI need to charge my phone.私は携帯を充電する必要がある。
need -ingMy phone needs charging.私の携帯は充電が必要だ。

どちらも「充電が必要」という意味ですが、主語が違います。I need to charge は「私」が主語で、My phone needs charging は「携帯」が主語です。

追加例文（教科書外）
need toYou need to see a doctor.医者に診てもらう必要があるよ。
need -ingThe car needs washing.その車は洗う必要がある。

確認テスト

覚えておきたいのは、need to doは「（主語が）する必要がある」、need -ingは「（主語が）〜される必要がある」だということです。

形意味例文
need to do主語がする必要があるI need to charge my phone.
need -ing主語がされる必要があるMy phone needs charging.

need to do ＝ する必要　／　need -ing ＝ される必要

Unit 57　Section C

help and can't help

今回の学習範囲：Section C

Section B では、need の2つの形を見ました。

今回は、help と can't help です。

今回のテーマhelp は to があってもなくてもよい。can't help -ing は「〜せずにいられない」

① help to do / help do ＝ to はあってもなくてもよい

教科書は、次のように説明しています。

You can say help to do or help do (with or without to):

つまり、help to do とも help do とも言える（to はあってもなくてもよい）。

Everybody helped to clean up after the party. or Everybody helped clean up …

パーティーのあと、みんなが片づけを手伝った。

Can you help me move this table? or Can you help me to move … ?

このテーブルを動かすのを手伝ってくれる？

help のあとは、to が付いても付かなくても、意味は同じです。

② can't help -ing ＝ 〜せずにいられない

教科書の説明を見てみましょう。

I can't help doing something = I can't stop myself doing it:

つまり、I can't help doing something ＝ 自分でそうするのを止められない。

I don't like him, but he has a lot of problems. I can't help feeling sorry for him.

彼は好きではないが、問題をたくさん抱えている。気の毒に思わずにはいられない。

She tried to be serious, but she couldn't help laughing.

彼女は真面目にしようとしたが、笑わずにはいられなかった。

教科書の補足：(= she couldn't stop herself laughing)

I'm sorry I'm so nervous. I can't help it.

こんなに緊張していてごめんなさい。どうしようもないんです。

教科書の補足：(= I can't help being nervous)

形意味例
@purple(help (to) do)手伝うhelped clean up
can't help -ing〜せずにいられないcouldn't help laughing

2つは、help という同じ単語でも、意味がまったく違います。can't help のあとは -ing です。

追加例文（教科書外）
helpCan you help me find my keys?鍵を探すのを手伝ってくれる？
can't helpThe story was so sad. I couldn't help crying.その話はとても悲しかった。泣かずにはいられなかった。

日常会話での使用例

A: Why are you smiling?

どうして笑っているの？

B: Sorry, I can't help laughing. It's so funny!

ごめん、笑わずにいられないんだ。すごくおかしくて！

確認テスト

覚えておきたいのは、help はto があってもなくてもよく、can't help のあとは-ingで「〜せずにいられない」という意味になるということです。

形意味例文
@purple(help (to) do)手伝うCan you help me move this table?
can't help -ing〜せずにいられないI couldn't help laughing.

help (to) do ＝ 手伝う　／　can't help -ing ＝ せずにいられない
