UNIT 58

Verb + -ing or to … 3 (like / would like etc.)

Unit 58　動詞 + -ing か to …（3）

このユニットでは、好き嫌いを表す like / love / hate と、願いや希望を表す would like / would love の使い方を学びます。

一般的に「好き」と言うときと、「今したい」と言うときで、形が変わります。

セクションの地図

Section扱う内容
Alike / love / hate ＋ -ing か to …（どちらも使えるとき／-ing だけのとき／意味に差が出るとき）
Bwould like / would love ＋ to …。like と would like の違い
Cwould like to have done ＝ 「〜したかったのにできなかった」

色の対応

-ing ＝ 青、to … ＝ 緑、to have 過去分詞 ＝ 橙、誤り＝赤。

Unit 58　Section A

like / love / hate

今回の学習範囲：Section A

like / love / hate などは、-ing のことも to … のこともあります。どちらを使うかを整理します。

今回のテーマ繰り返しのことは両方使える。すでにある状況は -ing

① 繰り返す行動 ＝ -ing でも to … でもよい

教科書は、次のように説明しています。

When you talk about repeated actions, you can use -ing or to … after these verbs. So you can say:

つまり、繰り返す行動を言うときは、これらの動詞のあとに -ing も to … も使える。

Do you like getting up early? or Do you like to get up early?

早起きは好き？

Stephanie hates flying. or Stephanie hates to fly.

ステファニーは飛行機に乗るのが大嫌いだ。

I love meeting people. or I love to meet people.

人と会うのが大好きだ。

I don't like being kept waiting. or … like to be kept waiting.

待たされるのは好きじゃない。

ふだんの好き嫌いなら、どちらを使っても大きな違いはありません。

② すでにある状況 ＝ -ing（to … は使わない）

教科書の説明を見てみましょう。

We use -ing (not to …) when we talk about a situation that already exists (or existed). For example:

つまり、すでにある（あった）状況について言うときは、-ing を使う（to … は使わない）。

Paul lives in Berlin now. He likes living there.

ポールは今、ベルリンに住んでいる。そこでの生活が気に入っている。

Do you like being a student?

学生でいるのは好き？

The office I worked in was horrible. I hated working there.

私が働いていたオフィスはひどかった。そこで働くのが嫌だった。

状況使う形例
繰り返す行動・一般的な好み-ing／to …I like getting up early.
すでにある（あった）状況-ingだけHe likes living there.

ポールの例は、「今そこに住んでいる」という現実があります。現実にある状況は -ing だけで言います。

③ like doing と like to do の違い

教科書には、次の説明があります。

There is sometimes a difference between I like to do and I like doing:

つまり、I like to do と I like doing には、違いがあることもある。

Compare
like doingI like cleaning the kitchen.台所の掃除が好きだ（楽しんでいる）。(= I enjoy it.)
like to doIt's not my favourite job, but I like to clean the kitchen as often as possible.好きな仕事ではないが、できるだけ頻繁に台所を掃除するようにしている。(= I choose to do it, but maybe I don't enjoy it)
形意味楽しんでいるか
like doingそれをして、楽しんでいる楽しんでいる
like to doそうすることを選んでいる楽しんでいるとは限らない

like -ing は「楽しい」、like to は「そうするのがよいと思って選ぶ」です。

④ enjoy と mind は -ing だけ

教科書は、次のように説明しています。

Note that we use -ing (not to …) with enjoy and mind:

つまり、enjoy と mind には、-ing を使う（to … は使わない）ことに注意する。

I enjoy cleaning the kitchen. (not I enjoy to clean)

台所を掃除するのは楽しい。

I don't mind cleaning the kitchen. (not I don't mind to clean)

台所を掃除するのは構わない。

追加例文（教科書外）
状況She likes living alone.彼女は一人暮らしが気に入っている。
選ぶI like to arrive early at the airport.私は空港に早めに着くようにしている。

日常会話での使用例

A: Do you like cooking?

料理は好き？

B: Yes, I enjoy cooking for friends.

うん、友達に作るのが楽しいよ。

確認テスト

覚えておきたいのは、like / love / hate は、繰り返す行動なら-ingもto …もよく、すでにある状況は-ingだけで、enjoy と mind は-ingだけだということです。

状況使う形例文
繰り返す行動・一般的な好み-ing／to …I love meeting people. / I love to meet people.
すでにある状況-ingHe likes living there.
enjoy / mind-ingI enjoy cleaning.

状況 → -ing　／　選ぶ・習慣 → to …も可　／　enjoy・mind → -ing

Unit 58　Section B

would like / would love / would hate / would prefer

今回の学習範囲：Section B

Section A では、like などのあとの形を見ました。

今回は、would like など、願いや希望を表す形です。

今回のテーマwould like などのあとは to …。ただし would mind は -ing

① would like / would love のあとは to …

教科書は、次のように説明しています。

Would like / would love etc. are usually followed by to … :

つまり、would like / would love などのあとには、ふつう to … が続く。

I'd like to go away for a few days.

何日か出かけたい。

教科書の補足：(I'd = I would)

What would you like to do this evening?

今夜は何をしたい？

I wouldn't like to go on holiday alone.

一人で休暇に出かけるのは嫌だ。

I'd love to meet your family.

あなたの家族にぜひ会いたい。

Would you prefer to eat now or later?

食事は今にする？あとにする？

② I like と I would like の違い

教科書の説明を見てみましょう。

Compare I like and I would like (I'd like):

つまり、I like と I would like (I'd like) を比べる。

Compare
I like（一般的）I like playing tennis. / I like to play tennis.テニスをするのが好きだ。(= I like it in general)
I'd like（今）I'd like to play tennis today.今日はテニスをしたい。(= I want to play today)
形意味いつのこと
I like -ing / to …好きふだんのこと・一般的な好み
I'd like to …したい今・その場の願い

I like は「好き」で、いつでも成り立つ話です。I'd like は「今したい」と言うときです。

③ would mind は -ing

教科書には、次の説明があります。

Would mind is followed by -ing:

つまり、would mind のあとには -ing が続く。

Would you mind closing the door, please? (not mind to close)

ドアを閉めていただけませんか。

mind は Section A のとおり -ing です。would を付けても、あとの形は変わりません。

追加例文（教科書外）
would loveI'd love to visit Japan one day.いつか日本を訪ねてみたい。
would mindWould you mind waiting a moment?少しお待ちいただけますか。

日常会話での使用例

A: Would you like to come to dinner?

夕食に来ませんか？

B: I'd love to. Thank you!

ぜひ。ありがとう！

確認テスト

覚えておきたいのは、今の願いはwould like to …、一般的な好みはlike -ingで、would mind のあとは-ingだということです。

形意味例文
like -ing一般的な好みI like playing tennis.
would like to …今したいI'd like to play tennis today.
would mind -ing〜してもらえませんかWould you mind closing the door?

would like / would love / would prefer ＋ to …　／　would mind ＋ -ing

Unit 58　Section C

I would like to have (done something)

今回の学習範囲：Section C

Section B では、would like to … を見ました。

今回は、「したかったのにできなかった」ことを言う形です。

今回のテーマwould like to have done ＝ 〜したかったのにできなかった

① would like to have done ＝ できなくて残念

教科書は、次のように説明しています。

I would like to have done something = I regret now that I didn't or couldn't do it:

つまり、I would like to have done something ＝ しなかった、またはできなかったことを、今残念に思っている。

It's a shame we didn't see Anna. I would like to have seen her again.

アンナに会えなかったのは残念だ。また会いたかったのに。

We'd like to have gone away, but we were too busy at home.

出かけたかったのに、家のことで忙しすぎた。

形意味実際には
would like to do（これから）したいまだしていない
would like to have done（過去に）したかったしなかった・できなかった

② would love / would hate / would prefer も同じ形

教科書の説明を見てみましょう。

We use the same structure after would love / would hate / would prefer:

つまり、would love / would hate / would prefer のあとでも、同じ形を使う。

Poor David! I would hate to have been in his position.

かわいそうなデイビッド！ 彼の立場にはなりたくなかった。

I'd love to have gone to the party, but it was impossible.

パーティーに行きたかったのに、無理だった。

追加例文（教科書外）
残念I'd like to have met your parents, but they were away.ご両親に会いたかったのですが、お留守でした。
ほっとしたI would hate to have missed the concert.そのコンサートを逃さなくてよかった。

日常会話での使用例

A: Did you go to the party?

パーティーには行ったの？

B: No. I'd love to have gone, but I was ill.

ううん。行きたかったけど、病気だったんだ。

確認テスト

覚えておきたいのは、would like to doは「これからしたい」、would like to have doneは「したかったのにできなかった」だということです。

形意味例文
would like to doこれからしたいI'd like to see her.
would like to have doneしたかったのにできなかったI'd like to have seen her.

would like to do ＝ これから　／　would like to have done ＝ できなかった
