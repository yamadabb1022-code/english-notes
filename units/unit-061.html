UNIT 61

be/get used to … (I'm used to …)

Unit 61　be used to / get used to

このユニットでは、「〜に慣れている」を表す be used to と、「〜に慣れる」を表す get used to を学びます。used to do（昔は〜していた）と形が似ているので、違いを整理します。

セクションの地図

Section扱う内容
Aリサの例（イギリスの左側通行）でイメージをつかむ
Bbe used to ＝ 慣れている／get used to ＝ 慣れる
Cbe used to のあとは -ing（to は前置詞）
Dbe used to doing と used to do の違い

色の対応

be used to / get used to ＝ 青、used to do（昔は〜した）＝ 橙、誤り＝赤。

Unit 61　Section A

Situation: Lisa in Britain

今回の学習範囲：Section A

まず、教科書の例で、「慣れていない」「慣れる」「慣れている」の3つの段階を見ます。

今回のテーマ慣れていない → 慣れる → 慣れている

① リサの3つの段階

Study this example situation
Lisa is American, but she lives in Britain. When she first drove a car in Britain, driving on the left was a problem for her because: She wasn't used to it. She wasn't used to driving on the left. (because Americans drive on the right)リサはアメリカ人だが、イギリスに住んでいる。イギリスで初めて車を運転したとき、左側通行は問題だった。慣れていなかったからだ。左側を運転することに慣れていなかった（アメリカ人は右側を走るから）。
But after some time, driving on the left became easier. She got used to driving on the left.しばらくすると、左側通行は楽になった。彼女は、左側を運転することに慣れた。
Now it's no problem for Lisa: She is used to driving on the left.今、リサには問題ない。左側を運転することに慣れている。
時期リサの状態英語
最初慣れていなかったwasn't used to driving on the left
しばらくして慣れた（慣れていく途中）got used to driving on the left
今慣れているis used to driving on the left

3つの形は、時間の流れで考えます。最初は慣れていなくて（wasn't used to）、慣れていって（got used to）、今は慣れている（is used to）という順番です。

確認テスト

覚えておきたいのは、慣れていない（wasn't used to）→ 慣れる（got used to）→ 慣れている（is used to）という時間の流れです。

時期形意味
最初wasn't used to慣れていない
途中get used to慣れる
今is used to慣れている

be used to ＝ 慣れている　／　get used to ＝ 慣れる

Unit 61　Section B

I'm used to something

今回の学習範囲：Section B

Section A では、リサの例を見ました。

今回は、教科書の説明と例文で、意味を確認します。

今回のテーマbe used to ＝ 新しくも変でもない。get used to ＝ そうなっていく

① be used to ＝ 慣れている

教科書は、次のように説明しています。

I'm used to something = it is not new or strange for me

You can say: be / get used to something or doing something

つまり、be / get used to something や doing something と言える。

Paul lives alone. He has lived alone for a long time, so it is not strange for him. He's used to it. He is used to living alone.

ポールは一人暮らしだ。長い間一人暮らしなので、彼には変なことではない。彼はそれに慣れている。一人暮らしに慣れている。

I bought some new shoes. They felt a little strange at first because I wasn't used to them.

新しい靴を買った。慣れていなかったので、最初は少し変な感じがした。

② get used to ＝ 慣れる

Our new apartment is on a busy street. I expect we'll get used to the noise, but at the moment it's very disturbing.

新しいアパートは交通量の多い通りにある。そのうち騒音に慣れると思うが、今はとても気になる。

Helen has a new job. She has to get up much earlier now than before. She finds it hard because she isn't used to getting up early.

ヘレンは新しい仕事を始めた。以前よりずっと早く起きなければならない。早起きに慣れていないので、つらいと感じている。

形意味変化
be used to慣れている状態
get used to慣れる慣れていく変化

be は「状態」、get は「変化」です。Unit 1 の get better（よくなる）の get と同じように、get は「〜になる」という意味です。

追加例文（教科書外）
beI'm used to getting up early. I do it every day.早起きには慣れている。毎日しているから。
getYou'll get used to the food here soon.ここの食べ物には、すぐに慣れるよ。

日常会話での使用例

A: Is the cold weather a problem?

寒い天気はつらい？

B: Not now. I'm getting used to it.

今はそうでもない。だんだん慣れてきたよ。

確認テスト

覚えておきたいのは、be used toは「慣れている（状態）」、get used toは「慣れる（変化）」だということです。

形意味例文
be used to慣れているI'm used to the noise.
get used to慣れるI'll get used to the noise.

be used to ＝ 慣れている　／　get used to ＝ 慣れる

Unit 61　Section C

be/get used to doing

今回の学習範囲：Section C

Section B では、意味を確認しました。

今回は、あとに続く形です。

今回のテーマbe / get used to のあとは、-ing（to は前置詞）

① あとに動詞を置くときは -ing

教科書は、次のように説明しています。

We say 'be/get used to doing something' (not I'm used to do).

つまり、'be / get used to doing something' と言う（I'm used to do とは言わない）。

Lisa is used to driving on the left. (not is used to drive)

リサは、左側を運転することに慣れている。

I'm used to living alone. (not I'm used to live)

私は一人暮らしに慣れている。

② なぜ -ing？ ＝ to は前置詞

教科書の説明を見てみましょう。

When we say 'I am used to …', to is a preposition:

つまり、'I am used to …' と言うときの to は前置詞である。

We're not used to the noise. / it. / living here. (not live here)

私たちは、その騒音／それ／ここに住むことに慣れていない。

Unit 60C で見たとおり、前置詞 to のあとは、名詞か -ing です。used to のあとに名詞（the noise）が来るのと同じように、動詞が来るときは -ing になります。

Compare to + infinitive
不定詞の toWe don't want to live here.私たちはここに住みたくない。
前置詞の toWe're not used to living here.私たちはここに住むことに慣れていない。
文to の種類あとの形
want to live不定詞の to原形
be used to living前置詞の to-ing
追加例文（教科書外）
be used toI'm not used to eating so late.こんなに遅く食べるのには慣れていない。
get used toShe got used to working at night.彼女は夜に働くことに慣れた。

日常会話での使用例

A: Do you mind the noise?

騒音は気になる？

B: No, I'm used to sleeping with noise.

ううん、うるさいなかで寝るのには慣れているよ。

確認テスト

覚えておきたいのは、be / get used to の to は前置詞なので、あとに動詞を置くときは-ingの形にするということです。

文to の種類あとの形
I want to live here.不定詞の to原形
I'm used to living here.前置詞の to-ing

be / get used to ＋ 名詞 または -ing

Unit 61　Section D

I am used to doing and I used to do

今回の学習範囲：Section D

Section C では、be used to のあとの形を見ました。

今回は、形のよく似た used to do（Unit 18）との違いです。

今回のテーマbe used to doing ＝ 慣れている、used to do ＝ 昔は〜していた

① be used to (doing) ＝ 今、慣れている

教科書は、次のように説明しています。

I am used to (doing) something = it isn't strange or new for me:

つまり、I am used to (doing) something ＝ それは自分にとって、変でも新しくもない。

I'm used to the weather here.

ここの天気には慣れている。

I'm used to driving on the left because I've lived in Britain a long time.

イギリスに長く住んでいるので、左側を運転することには慣れている。

② used to do ＝ 昔は〜していた

教科書の説明を見てみましょう。

I used to do something = I did it regularly in the past but no longer do it. We use this only for the past (I used …), not for the present. See Unit 18.

つまり、I used to do something ＝ 過去に定期的にしていたが、今はもうしない。これは過去だけに使う（I used …）。現在には使わない。Unit 18 を見る。

I used to drive to work every day, but these days I usually go by bike.

昔は毎日、車で通勤していたが、最近はたいてい自転車で行く。

We used to live just outside the town, but now we live near the centre.

昔は町のすぐ外に住んでいたが、今は中心部の近くに住んでいる。

③ 2つの違い

形意味時間あとに続く形
be used to doing今、慣れている現在（be の形が変わる）-ing（名詞でもよい）
used to do昔はよく〜していた（今はしない）過去だけ原形
Compare
be used toI'm used to driving on the left.左側を運転することに慣れている。（今、慣れている）
used toI used to drive on the left.昔は左側を運転していた。（今は運転しない）

形は似ていますが、意味もあとに続く形もまったく違います。be used to のあとは -ing、used to のあとは原形です。

追加例文（教科書外）
be used toI'm used to working long hours.長時間働くことには慣れている。
used toI used to work long hours, but I don't now.昔は長時間働いていたが、今は違う。

日常会話での使用例

A: You look very relaxed in this heat.

この暑さのなかで、すごく落ち着いているね。

B: I used to live in Thailand, so I'm used to the hot weather.

タイに住んでいたから、暑い天気には慣れているんだ。

確認テスト

覚えておきたいのは、be used to + -ingは「今、慣れている」、used to + 原形は「昔はしていた」だということです。

形意味例文
be used to doing慣れているI'm used to driving on the left.
used to do昔は〜していたI used to drive to work.

be used to + -ing ＝ 慣れている　／　used to + 原形 ＝ 昔はした
