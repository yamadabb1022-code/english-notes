UNIT 71

Countable nouns with a/an and some

Unit 71　数えられる名詞と a / an・some

日本語には、「a」も「an」も「some」もありません。だから、「帽子をかぶらない」を She never wears hat. と、a を抜かしてしまいがちです。今日は、数えられる名詞のa / anとsomeを、ルールで整理します。

セクションの地図

Section扱う内容
A単数形には a / an が要る。名詞だけでは使えない
B「どんな種類か」を言う a / an。複数形では名詞だけ。職業・体の特徴
Csome の2つの意味（いくつか／全部ではないが一部）と、some を付けない場合

色の対応

a / an（単数）＝ 青、複数形 ＝ 緑、some ＝ 橙、誤り＝赤。

Unit 71　Section A

a/an before singular countable nouns

今回の学習範囲：Section A

単数形は、1人では使えません。必ず、a / an（または the / my / this）が付きます。

今回のテーマ単数形の名詞には、a / an（または the / my / this など）が必要

① 数えられる名詞は、単数にも複数にもなる

教科書は、次のように説明しています。

Countable nouns can be singular or plural:

つまり、数えられる名詞は、単数にも複数にもなります。

単数形複数形
a dogdogs
a childsome children
the eveningthe evenings
this partythese parties
an umbrellatwo umbrellas

② 単数形の前には、a / an を付ける

教科書の説明を見てみましょう。

Before singular countable nouns you can use a/an:

つまり、数えられる名詞の単数形の前には、a / an を付けられます。

Bye! Have a nice evening.

じゃあね！ すてきな夜を。

Do you need an umbrella?

傘は要る？

③ 単数形は、a / the / my などなしでは使えない

教科書には、次の説明があります。

You cannot use singular countable nouns alone (without a/the/my etc.):

つまり、数えられる名詞の単数形は、a / the / my などなしでは、単独で使えません。

She never wears a hat. (not wears hat)

彼女は帽子をかぶらない。

Be careful of the dog.

その犬に気をつけて。

What a beautiful day!

なんてすてきな日だろう！

Did you hurt your leg?

脚をけがしたの？

付ける語例
a / ana hat / an umbrella
the / this / thatthe dog
my / your / his などyour leg

a / an は、日常のものの話にも、いろいろな名詞に付きます。

I need a pen. Do you have one?

ペンが要る。持っている？

Please close the door.

ドアを閉めてください。

会話では、持ち物をたずねるときに使います。

A: Do you have a pen?

ペンを持っている？

B: Sorry, I don't have a pen.

ごめん、ペンを持っていないんだ。

覚えておきたいのは、数えられる名詞の単数形は、a / an（または the / my など）を付けないと使えないということです。

名詞付け方例文
単数形a / an、the、my などShe never wears a hat.
複数形名詞だけでもよいShe never wears hats.

単数形の前には、a / an / the / my などが必要

Unit 71　Section B

a/an for kind and job

今回の学習範囲：Section B

次は、a / an のもう1つの顔です。「どんな種類か」「どんな職業か」を言います。

間違いやすいのは、職業の a の抜けです。

今回のテーマ種類・職業を言うときは a / an。複数形では名詞だけ

① a / an は、何の種類かを言うときにも使う

教科書は、次のように説明しています。

We use a/an … to say what kind of thing something is, or what kind of person somebody is: That's a nice table. In the plural we use the noun alone (not some …):

つまり、a / an … は、あるものがどんな種類のものか、ある人がどんな種類の人かを言うときに使います。複数形では、名詞だけを使い、some は付けません。

Those are nice chairs. (not some nice chairs)

それらはすてきな椅子だ。

② 単数なら a / an + 名詞、複数なら名詞だけで言う

教科書の説明を見てみましょう。

Compare singular and plural:

つまり、単数と複数を比べてみましょう。

Compare
単数（a / an）A dog is an animal. / I'm an optimist. / My father is a doctor. / Jane is a really nice person. / What a lovely dress!犬は動物だ。/ 私は楽天家だ。/ 父は医者だ。/ ジェーンは本当にいい人だ。/ なんてすてきなドレスだろう！
複数（名詞だけ）Dogs are animals. / We're optimists. / My parents are both doctors. / Jane and Ben are really nice people. / What awful shoes!犬は動物だ。/ 私たちは楽天家だ。/ 両親は2人とも医者だ。/ ジェーンとベンは本当にいい人たちだ。/ なんてひどい靴だろう！
数形例
単数a / an + 名詞My father is a doctor.
複数名詞だけMy parents are both doctors.

③ 体の特徴を言うときも、a / an を使う

教科書には、次の説明があります。

We say that somebody has a long nose / a nice face / blue eyes / long fingers etc. :

つまり、人の外見を言うときは、a long nose、a nice face、blue eyes、long fingers のように言います。

Jack has a long nose. (not the long nose)

ジャックは鼻が長い。

Jack has blue eyes. (not the blue eyes)

ジャックは青い目をしている。

体の特徴には、the を付けません。単数なら a、複数なら名詞だけです。

④ 職業を言うときも、a / an を使う

教科書は、次のように説明しています。

We use a/an when we say what somebody's job is:

つまり、人の職業を言うときは、a / an を付けます。

Sandra is a nurse. (not Sandra is nurse)

サンドラは看護師だ。

Would you like to be an English teacher?

英語の先生になりたい？

職業は、家族や友達の紹介のときに使います。

My sister is a pilot.

姉はパイロットだ。

My brothers are engineers.

兄たちはエンジニアだ。

会話では、家族の仕事をたずねられたときの返事に使います。

A: What does your father do?

お父さんのお仕事は？

B: He's a teacher.

先生です。

覚えておきたいのは、種類・職業を言うときはa / an（単数）、複数のときは名詞だけで、some は付けないということです。

数形例文
単数a / an + 名詞My father is a doctor.
複数名詞だけMy parents are doctors.

単数 → a / an + 名詞　／　複数 → 名詞だけ（some は付けない）

Unit 71　Section C

some

今回の学習範囲：Section C

最後に、some です。「いくつか」だけでなく、もう1つの意味があります。

「一般的な話」には、some を使いません。

今回のテーマsome には2つの意味がある。「いくつか」と「一部」

① some は、「いくつか」を表す

教科書は、次のように説明しています。

You can use some with plural countable nouns. We use some in two ways. (1) some = a number (of) / a few (of) / a pair (of):

つまり、some は、数えられる名詞の複数形に使えます。使い方は2通りあります。(1) some は「いくつかの」（a number of / a few of / a pair of）という意味です。

I've seen some good movies recently. (not seen good movies)

最近、いい映画を何本か見た。

Some friends of mine are coming to stay at the weekend.

友達が何人か、週末に泊まりに来る。

I need some new sunglasses.

新しいサングラスが要る。

教科書の補足：(= a new pair of sunglasses)

教科書の説明を見てみましょう。

Often you can say the same thing with or without some. For example:

つまり、some があってもなくても、同じことを言えることがよくあります。

I need (some) new clothes.

新しい服が要る。

The room was empty apart from a table and (some) chairs.

部屋は、テーブルと椅子（いくつか）のほかは空だった。

② 一般的な話には、some を付けない

教科書には、次の説明があります。

Do not use some when you are talking about things in general (see Unit 75):

つまり、一般的な話をするときは、some を使いません（Unit 75）。

I love bananas. (not some bananas)

バナナが大好きだ。

My aunt is a writer. She writes books. (not some books)

おばは作家だ。本を書いている。

話の種類形例
ある数（いくつか）some + 複数形I've seen some good movies.
一般的な話複数形だけI love bananas.

③ some は、「全部ではなく一部の」も表す

教科書は、次のように説明しています。

(2) some = some but not all:

つまり、(2) some は、「全部ではないが、一部の」という意味にもなります。

Some children learn very quickly.

子どもたちのなかには、とても早く覚える子もいる。

教科書の補足：(but not all children)

Tomorrow there will be rain in some places, but most of the country will be dry.

明日は、雨の降る場所もあるが、国のほとんどは乾燥するだろう。

some の意味言い方例
いくつかsome = a fewsome good movies
一部の（全部ではない）some = not allSome children learn quickly.

some は、買い物や映画の話にも使えます。

I bought some oranges at the market.

市場でオレンジをいくつか買った。

Some people prefer tea to coffee.

紅茶のほうが好きな人もいる。

会話では、感想を言うときに使います。

A: Do you like movies?

映画は好き？

B: Yes. I've seen some great movies this year.

うん、今年はいい映画を何本か見たよ。

覚えておきたいのは、someは「いくつか」と「一部の（全部ではない）」を表し、一般的な話では複数形だけを使うということです。

意味形例文
いくつかsome + 複数形I've seen some good movies.
一部のSome + 複数形Some children learn quickly.
一般的な話複数形だけI love bananas.

some ＝ いくつか・一部　／　一般的な話 ＝ some なし
