UNIT 84

there … and it …

Unit 84　there … と it …

「新しいレストランがある」と「そのレストランはおいしい」。日本語では、どちらも自然ですが、英語ではthere と it を使い分けます。決め手は、「初めて話題に出すか、もう分かっているか」です。

セクションの地図

Section扱う内容
Athere is ＝ 存在を初めて言う／it ＝ 特定のもの
Bthere will be / there must be などの形。there と it の比べ
CIt's dangerous to … の形。距離・時間・天気の it

色の対応

there ＝ 青、it ＝ 緑、誤り＝赤。

Unit 84　Section A

there is … and it is …

今回の学習範囲：Section A

まず、基本の違いです。

今回のテーマ初めて「ある」と言うなら there、すでに分かっているものなら it

① 初めて話題に出すものは、there で「ある」と言う

Study this example
A: There's a new restaurant in Hill Street. / B: Yes, I know. I've heard it's very good.A：ヒル通りに新しいレストランがあるよ。/ B：うん、知っている。とてもおいしいらしいね。

教科書は、次のように説明しています。

We use there … when we talk about something for the first time, to say that it exists:

つまり、何かについて初めて話し、それが存在することを言うときは、there … を使う。

There's a new restaurant in Hill Street.

ヒル通りに新しいレストランがある。

I'm sorry I'm late. There was a lot of traffic. (not It was a lot of traffic)

遅れてごめん。交通量がとても多かった。

Things are very expensive now. There has been a big rise in the cost of living.

今は物価がとても高い。生活費が大きく上がっている。

場面使う語意味
初めて話す（存在を言う）there is / there was〜がある・あった

② すでに話題に出たものや状況は、it で言う

教科書の説明を見てみましょう。

It = a specific thing, place, fact, situation etc. :

つまり、it ＝ 特定の物・場所・事実・状況など。

We went to the new restaurant. It's very good.

私たちは新しいレストランに行った。とてもおいしかった。

教科書の補足：(It = the restaurant)

I wasn't expecting her to call me. It was a complete surprise.

彼女が電話してくるとは思っていなかった。まったくの驚きだった。

教科書の補足：(It = that she called)

場面使う語意味
すでに話したもの・事実itそれは〜だ

③ 初めてなら there、すでに分かっているなら it で言う

教科書には、次の説明があります。

Compare there and it:

つまり、there と it を比べる。

Compare
there（存在）I like this town. There's a lot to do here.この町は好きだ。ここにはすることがたくさんある。
it（特定のもの）It's an interesting place.おもしろい場所だ。
文何を言っているか
There's a lot to do here.「することがたくさん存在する」（存在）
It's an interesting place.「この町は」おもしろい場所だ（this town を指す）

④ there には、「そこに」という場所の意味もある

教科書は、次のように説明しています。

There also means 'to/at/in that place':

つまり、there には、「その場所へ／で／に」の意味もある。

The house is unoccupied. There's nobody living there.

その家は空き家だ。そこには誰も住んでいない。

教科書の補足：(= in the house)

there は、店・天気・事故など、身の回りの存在の話にも使えます。

There's a bank near here.

近くに銀行がある。

I bought a new phone. It's very light.

新しい携帯を買った。とても軽い。

会話では、近くにあるものを聞くときに使います。

A: Is there a supermarket near here?

この近くにスーパーはある？

B: Yes, there's one on the corner. It's open until ten.

うん、角に1軒あるよ。10時まで開いているよ。

覚えておきたいのは、初めて「ある」と言うならthere is、すでに分かっているものを言うならit isだということです。

場面使う語例文
存在を初めて言うthere is / wasThere's a new restaurant.
特定のものを言うit is / wasIt's very good.

there ＝ 存在　／　it ＝ 特定のもの

Unit 84　Section B

there will be, there must be, there used to be

今回の学習範囲：Section B

次は、there のいろいろな形です。

助動詞を挟んで、「あるかもしれない」「あったに違いない」と言います。

今回のテーマthere + will be / must be / used to be …

① there の後ろに、助動詞 + be を続けられる

教科書は、次のように説明しています。

You can say: there will be / there must be / there might be etc. / there must have been / there should have been / there would have been etc. / there is sure to be / there is bound to be / there is going to be / there is likely to be / there is supposed to be / there used to be

つまり、次のように言える。there will be / there must be / there might be など。there must have been / there should have been / there would have been など。there is sure to be / there is bound to be / there is going to be。there is likely to be / there is supposed to be / there used to be。

'Is there a flight to Rome tonight?' 'There might be. I'll check online.'

「今夜ローマ行きの便はある？」「あるかもしれない。ネットで調べてみる。」

If people drove more carefully, there wouldn't be so many accidents.

人々がもっと慎重に運転すれば、事故はこんなに多くないだろう。

I could hear music coming from the house. There must have been somebody at home.

家から音楽が聞こえていた。家に誰かいたに違いない。

There's bound to be a café somewhere around here.

このあたりのどこかに、カフェがあるに違いない。

② there は「ある」、it は特定のものを言う

教科書の説明を見てみましょう。

Compare there and it:

つまり、there と it を比べる。

Compare
thereThey live on a busy road. There must be a lot of noise from the traffic.彼らは交通量の多い道路に住んでいる。車の音がたくさんしているに違いない。
itThey live on a busy road. It must be very noisy.彼らは交通量の多い道路に住んでいる。とてもうるさいに違いない。(It = living on a busy road)
Compare（過去）
thereThere used to be a cinema here, but it closed a few years ago.ここには昔、映画館があったが、数年前に閉館した。
itThat building is now a supermarket. It used to be a cinema.あの建物は、今はスーパーだ。昔は映画館だった。
文何を言っているか
There must be a lot of noise.騒音が「存在する」
It must be very noisy.（その状況は）とてもうるさい
There used to be a cinema here.映画館が「存在した」
It used to be a cinema.（その建物は）映画館だった

there will be などの形は、予定・可能性・推量にも使えます。

There will be a meeting tomorrow.

明日、会議がある。

It might be a good idea to call first.

先に電話するのがいいかもしれない。

会話では、チケットが残っているかをたずねるときに使います。

A: Are there any tickets left?

チケットは残っている？

B: There might be a few.

いくつか残っているかもしれない。

覚えておきたいのは、there はthere will be / must be / used to beのように be の前にいろいろな語が入り、itは特定のものを指すということです。

形意味例
there must beあるに違いないThere must be a lot of noise.
there used to be昔はあったThere used to be a cinema.
it must be〜に違いないIt must be very noisy.

there + 助動詞 + be ＝ 存在

Unit 84　Section C

It's dangerous to …

今回の学習範囲：Section C

最後は、It が仮の主語になる形です。

今回のテーマ長い主語は後ろに回して、It で始める

① 長い主語は後ろに回して、It's + 形容詞 + to … で言う

教科書は、次のように説明しています。

We say: It's dangerous to walk in the road. (not To walk in the road is dangerous) Normally we use It … at the beginning of sentences like this. Some more examples:

つまり、It's dangerous to walk in the road. と言う（To walk in the road is dangerous ではない）。このような文では、ふつう文頭に It … を使う。ほかの例。

It's dangerous to walk in the road. (not To walk in the road is dangerous)

道路を歩くのは危険だ。

It didn't take us long to get here.

ここに来るのに、時間はかからなかった。

It's a shame (that) you can't come to the party.

パーティーに来られないのは残念だ。

It's not worth waiting any longer. Let's go.

もうこれ以上待っても意味がない。行こう。

形意味
It's 形容詞 to …〜するのは…だ
It's a shame (that) …〜なのは残念だ
It's not worth -ing〜する価値がない

② 距離・時間・天気は、it で言う

教科書の説明を見てみましょう。

We also use it to talk about distance, time and weather:

つまり、it は、距離・時間・天気を言うときにも使う。

How far is it from here to the airport?

ここから空港までどのくらい？

It's a long time since we last saw you.

最後にあなたに会ってから、長い時間がたった。

③ it は特定のもの、there は存在を言う

教科書には、次の説明があります。

Compare it and there:

つまり、it と there を比べる。

Compare
it（天気の状態）It was windy.風が強かった。
there（存在）There was a cold wind.冷たい風が吹いていた。
文何を言っているか
It was windy.天気の状態（形容詞 windy）
There was a cold wind.風という名詞が存在した

it は、天気・時間・距離にも使えます。

It's raining. Take an umbrella.

雨が降っている。傘を持っていきなさい。

It takes about an hour to get there.

そこへ行くのに、1時間くらいかかる。

会話では、所要時間をたずねるときに使います。

A: How long does it take to get to the station?

駅まで、どのくらいかかる？

B: It takes about ten minutes.

10分くらいだよ。

覚えておきたいのは、It's + 形容詞 + to …で「〜するのは…だ」を表し、距離・時間・天気にもitを使うということです。

場面使う語例文
長い主語（to …）It'sIt's dangerous to walk in the road.
距離・時間・天気It'sIt's a long time since we met.
名詞の存在There'sThere was a cold wind.

It's 形容詞 to … ／ 距離・時間・天気 → it ／ 存在 → there
