UNIT 85

some and any

Unit 85　some と any

このユニットでは、some と any の使い分けを学びます。日本語では「いくつか」「いくらか」ですが、英語では文の種類によって形が変わります。

セクションの地図

Section扱う内容
A肯定文は some、否定文は any。意味が否定なら any
B疑問文では some も any も使える
Cif のなかの any
D「どれでも」の any
Esomebody / anybody は単数だが、they / their で受ける

色の対応

some ＝ 青、any ＝ 緑、誤り＝赤。

Unit 85　Section A

Positive and negative

今回の学習範囲：Section A

まず、some と any の基本です。

今回のテーマ肯定文は some、否定文は any

① 肯定文は some、否定文は any

教科書は、次のように説明しています。

In general we use some (also somebody/someone/something) in positive sentences and any (also anybody etc.) in negative sentences:

つまり、一般的に、some（somebody / someone / something も）は肯定文で、any（anybody なども）は否定文で使う。

Compare
some（肯定文）We bought some flowers. / He's busy. He has some work to do. / There's somebody at the door. / I want something to eat.私たちは花を買った。/ 彼は忙しい。やる仕事がある。/ 玄関に誰かいる。/ 何か食べたい。
any（否定文）We didn't buy any flowers. / He's lazy. He never does any work. / There isn't anybody at the door. / I don't want anything to eat.私たちは花を買わなかった。/ 彼は怠け者だ。まったく仕事をしない。/ 玄関には誰もいない。/ 何も食べたくない。
文形例
肯定文some / somebody / somethingI want something to eat.
否定文any / anybody / anythingI don't want anything to eat.

② 意味が否定なら any

教科書の説明を見てみましょう。

We use any in the following sentences because the meaning is negative:

つまり、次の文では、意味が否定なので any を使う。

She went out without any money.

彼女は、お金をまったく持たずに出かけた。

教科書の補足：(she didn't take any money with her)

He refused to eat anything.

彼は、何も食べようとしなかった。

教科書の補足：(he didn't eat anything)

It's a very easy exam. Hardly anybody fails.

とても簡単な試験だ。落ちる人はほとんどいない。

教科書の補足：(= almost nobody fails)

文否定の言葉any
She went out without any money.withoutany
He refused to eat anything.refuseanything
Hardly anybody fails.hardlyanybody

not が入っていなくても、without / refuse / hardly のように意味が否定なら、any を使います。

追加例文（教科書外）
someI need some advice.アドバイスが欲しい。
anyI don't have any money.お金をまったく持っていない。

日常会話での使用例

A: Do you want anything to eat?

何か食べたい？

B: No, thanks. I don't want anything.

ううん、何も要らない。

覚えておきたいのは、肯定文は some、否定文は anyで、意味が否定なら not がなくてもanyを使うということです。

文形例文
肯定文someWe bought some flowers.
否定文anyWe didn't buy any flowers.
意味が否定（without / hardly）anyHardly anybody fails.

肯定 → some　／　否定・否定の意味 → any

Unit 85　Section B

Questions

今回の学習範囲：Section B

Section A では、肯定文と否定文を見ました。

今回は、疑問文です。

今回のテーマ疑問文では、「あるはず」なら some、「あるか分からない」なら any

① some を使う疑問文

教科書は、次のように説明しています。

We use both some and any in questions. We use some/somebody/something to talk about a person or thing that we know exists, or we think exists:

つまり、疑問文では、some も any も使う。存在すると分かっている、または存在すると思っている人や物については、some / somebody / something を使う。

Are you waiting for somebody?

誰かを待っているの？

教科書の補足：(I think you are waiting for somebody)

教科書の説明を見てみましょう。

We use some in questions when we ask for or offer things:

つまり、物を頼んだり、勧めたりするときの疑問文では、some を使う。

Can I have some sugar, please?

砂糖をいただけますか。

教科書の補足：(there is probably some sugar that I can have)

Would you like something to eat?

何か食べるものはいかがですか。

教科書の補足：(there is something to eat)

② any を使う疑問文

教科書には、次の説明があります。

But in most questions, we use any. We do not know if the thing or person exists:

つまり、でも、ほとんどの疑問文では any を使う。その物や人が存在するかどうか分からない。

Do you have any luggage?

荷物はお持ちですか。

教科書の補足：(maybe you do, maybe not)

Is there anybody in the house?

家に誰かいる？

教科書の補足：(maybe there is, maybe not)

疑問文のタイプ使う語理由
頼む・勧める・あるはずだと思うsomeあると分かっている・思っている
ふつうの疑問文anyあるかどうか分からない
追加例文（教科書外）
頼むCould I have some water, please?お水をいただけますか。
ふつうの疑問Do you have any questions?質問はありますか。

日常会話での使用例

A: Would you like some coffee?

コーヒーはいかがですか？

B: Yes, please. Do you have any milk?

はい、お願いします。ミルクはありますか？

覚えておきたいのは、疑問文では、頼む・勧めるならsome、ふつうの質問ならanyを使うということです。

疑問文のタイプ使う語例文
頼む・勧めるsomeCan I have some sugar?
ふつうの疑問anyDo you have any luggage?

頼む・勧める → some　／　ふつうの疑問 → any

Unit 85　Section C

if + any

今回の学習範囲：Section C

Section B では、疑問文を見ました。

今回は、if を含む文です。

今回のテーマif のなかでは any を使う

① if + any

教科書は、次のように説明しています。

You can use if + any:

つまり、if + any が使える。

Let me know if you need anything.

何か必要なら知らせて。

If anyone has any questions, I'll be pleased to answer them.

質問のある人がいれば、喜んでお答えします。

② if の意味を含む文

教科書の説明を見てみましょう。

The following sentences have the idea of if:

つまり、次の文には、if の考えが含まれている。

I'm sorry for any trouble I've caused.

ご迷惑をおかけしたなら、申し訳ありません。

教科書の補足：(= if I have caused any trouble)

The police want to speak to anyone who saw the accident.

警察は、事故を見た人がいれば話を聞きたい。

教科書の補足：(= if there is anyone)

文if の意味any
Let me know if you need anything.if があるanything
I'm sorry for any trouble.if を含む（もしあれば）any
追加例文（教科書外）
ifIf you have any problems, please call me.何か問題があれば、電話してください。

日常会話での使用例

A: Please contact me if you have any questions.

質問があれば、連絡してください。

B: Thank you. I will.

ありがとう。そうします。

覚えておきたいのは、if のなかや、if の意味を含む文ではanyを使うということです。

文使う語例文
if の文any / anything / anyoneLet me know if you need anything.
if の意味を含む文anyI'm sorry for any trouble.

if + any

Unit 85　Section D

any ＝ it doesn't matter which

今回の学習範囲：Section D

Section C では、if を見ました。

今回は、「どれでも」の any です。

今回のテーマany は「どれでもよい」も表す

① any ＝ どれでもよい

教科書は、次のように説明しています。

We also use any with the meaning 'it doesn't matter which':

つまり、any は、「どれでもよい」という意味でも使う。

You can take any bus. They all go to the centre.

どのバスに乗ってもいい。みんな中心部へ行くから。

教科書の補足：(= it doesn't matter which bus you take)

Come and see me any time you want.

いつでも好きなときに、会いに来て。

教科書の説明を見てみましょう。

We use anybody/anyone/anything/anywhere in the same way:

つまり、anybody / anyone / anything / anywhere も同じように使う。

We forgot to lock the door. Anybody could have come in.

ドアに鍵をかけ忘れた。誰でも入れただろう。

② some- と any- を比べる

教科書には、次の説明があります。

Compare some- and any-:

つまり、some- と any- を比べる。

some-（何か決まっている）any-（どれでもよい）
I'm hungry. I want something to eat.（何か食べたい）What would you like? — I don't mind. Anything.（何でもいいよ）
Let's go out somewhere.（どこかへ出かけよう）Where shall we go? — Anywhere. I just want to go out.（どこでもいい）

something は「何か（ある1つ）」、anything は「何でも（どれでもよい）」です。

追加例文（教科書外）
どれでもAny day is fine for me.私は、どの日でもいい。

日常会話での使用例

A: Where would you like to eat?

どこで食べたい？

B: Anywhere is fine with me.

どこでもいいよ。

覚えておきたいのは、anyには「どれでもよい」の意味もあり、someは「（決まった）何か」だということです。

意味使う語例文
何か（決まっている）somethingI want something to eat.
どれでもよいanythingAnything is fine.

some- ＝ 何か　／　any- ＝ どれでも

Unit 85　Section E

somebody, anybody + they

今回の学習範囲：Section E

最後は、somebody / anybody の動詞と代名詞です。

今回のテーマsomebody は単数だが、they / their で受ける

① somebody などは単数

教科書は、次のように説明しています。

Somebody/someone/anybody/anyone are singular words:

つまり、somebody / someone / anybody / anyone は単数の言葉だ。

Someone is here to see you.

誰かが、あなたに会いに来ている。

言葉動詞
somebody / someone / anybody / anyone単数動詞（is / has など）

② 受ける代名詞は they / them / their

教科書の説明を見てみましょう。

But we use they/them/their after these words:

つまり、でも、これらの言葉のあとでは they / them / their を使う。

Someone has forgotten their umbrella.

誰かが傘を忘れていった。

教科書の補足：(= his or her umbrella)

If anybody wants to leave early, they can.

早く帰りたい人がいれば、帰ってもいい。

教科書の補足：(= he or she can)

部分形
動詞単数（someone has）
代名詞they / them / their（男女を区別しない）
追加例文（教科書外）
theySomebody called, but they didn't leave a message.誰かから電話があったが、伝言はなかった。

日常会話での使用例

A: Did anyone call?

誰か電話してきた？

B: Somebody did, but they didn't say who they were.

誰かが、でも誰とも言わなかった。

覚えておきたいのは、somebody / anybody などは単数動詞で受けるが、代名詞はthey / them / theirを使うということです。

部分形例
動詞単数Someone is here.
代名詞they / theirSomeone has forgotten their umbrella.

somebody + 単数動詞 ／ they・their で受ける
