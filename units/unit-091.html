Unit 91　each と every

「各チームに11人」と「すべての窓が開いていた」。どちらも「それぞれ」「すべて」に近いですが、each は1つずつ見て、every は全体として見ます。見る角度の違いです。

セクションの地図

Section扱う内容
Aeach ＝ 1つずつ、every ＝ 全体として。使い分けのヒント
Beach と every の形（of の有無、名詞の有無）
C文の途中の each。値段の each
Deveryone と every one の違い

色の対応

each ＝ 青、every ＝ 緑、誤り＝赤。

Unit 91　Section A

each or every?

今回の学習範囲：Section A

まず、見方の違いです。

今回のテーマeach は「1つずつ」、every は「全体として」

① each は1つずつ、every は全体として見る

教科書は、次のように説明しています。

Each and every are similar. Often it is possible to use each or every: Each time I see you, you look different. or Every time I see you … But each and every are not exactly the same.

We use each when we think of things separately, one by one. We use every when we think of things as a group. The meaning is similar to all.

つまり、each は、物を1つずつ別々に考えるときに使う。every は、物をグループとして考えるときに使う。意味は all に近い。

Study each sentence carefully.

1つ1つの文を、注意深く勉強しなさい。

教科書の補足：(= study the sentences one by one)

Every window in the house was open.

家のどの窓も開いていた。

教科書の補足：(= all the windows in the house)

語見方イメージ
each1つずつ別々に1つ目、2つ目…と順に見る
every全体をひとまとめにall に近い

② each は少数、every は多数のときに使いやすい

教科書の説明を見てみましょう。

Each is more usual for a small number. Every is more usual for a large number:

つまり、each は、少ない数のときによく使う。every は、多い数のときによく使う。

There were four books on the table. Each book was a different colour.

テーブルの上に本が4冊あった。1冊1冊が、違う色だった。

(in a card game) At the beginning of the game, each player has three cards.

（カードゲームで）ゲームの始めに、各プレーヤーはカードを3枚持つ。

Kate loves reading. She has read every book in the library.

ケイトは読書が大好きだ。図書館の本を全部読んだ。

教科書の補足：(= all the books)

I'd like to visit every country in the world.

世界のすべての国を訪ねたい。

教科書の補足：(= all the countries)

③ each しか使えない場合と、every しか使えない場合がある

教科書には、次の説明があります。

Each (but not every) can be used for two things:

つまり、each は（every は不可）、2つのものにも使える。

In football, each team has eleven players. (not every team)

サッカーでは、各チームに11人の選手がいる。

教科書は、次のように説明しています。

We use every (not each) to say how often something happens:

つまり、何かがどのくらいの頻度で起こるかを言うときは、every を使う（each ではない）。

'How often do you use your car?' 'Every day.' (not Each day)

「どのくらい車を使う？」「毎日だよ。」

There's a bus every ten minutes. (not each ten minutes)

10分ごとにバスがある。

each は、1人ずつ・1つずつに目を向ける話にも使えます。

Each student has a locker.

各生徒が、ロッカーを1つ持っている。

Every student passed the exam.

学生は全員、試験に受かった。

会話では、習慣の頻度をたずねるときに使います。

A: How often do you check your email?

どのくらい、メールを確認する？

B: Every hour.

1時間ごとに。

覚えておきたいのは、eachは「1つずつ」、everyは「全体として（all に近い）」で、頻度には every を使うということです。

語見方例
each1つずつ（少ない数）Each book was a different colour.
every全体（多い数）She has read every book in the library.
every頻度There's a bus every ten minutes.

each ＝ 1つずつ　／　every ＝ 全体・頻度

Unit 91　Section B

The structures

今回の学習範囲：Section B

次は、形の違いです。

each は名詞なしでも使えますが、every は名詞が必要です。

今回のテーマeach は名詞なしでも使える。every は名詞が必要

① each は名詞なしでも使えるが、every は名詞が必要である

教科書は、次のように説明しています。

Compare the structures we use with each and every. We use each with or without a noun: We use every with a noun:

つまり、each と every のあとに続く形を比べる。each は名詞があってもなくても使える。every は名詞が必要だ。

Compare
each（名詞なしでもよい）None of the rooms are the same. Each room is different. or Each is different. Or you can use each one: Each one is different.どの部屋も同じではない。1つ1つの部屋が違う。または、each one も使える。
every（名詞が必要）She's read every book in the library. We don't use every alone, but you can say every one: 'Have you read all these books?' 'Yes, every one.'彼女は、図書館の本をすべて読んだ。every だけでは使わないが、every one とは言える。「これらの本は全部読んだ？」「うん、1冊残らず。」

② 「それぞれ」は each of、「1つ1つ」は every one of で言う

教科書の説明を見てみましょう。

We say each of (the/these/them … etc.): We say every one of … (but not every of):

つまり、each of（the / these / them など）と言う。every one of … と言う（every of ではない）。

Compare
each ofEach of the books was a different colour. (not each of books) / Each of them was a different colour. / Read each of these sentences carefully.それぞれの本は、違う色だった。/ それらは、それぞれ違う色だった。/ これらの文を1つずつ、注意深く読みなさい。
every one ofI've read every one of those books. (not every of those books) / I've read every one of them.それらの本を、1冊残らず読んだ。/ それらを、1冊残らず読んだ。
形everyeach
名詞なしevery oneeach / each one
of + the + 名詞every one of the …each of the …

each of は、学生や持ち物の話にも使えます。

Each of the students has a laptop.

学生たちは、それぞれノートパソコンを持っている。

Every one of them passed.

彼らは、全員受かった。

会話では、みんなが英語を話すかをたずねるときに使います。

A: Do they all speak English?

みんな英語を話すの？

B: Yes, every one of them.

うん、1人残らず。

覚えておきたいのは、eachは名詞なしでも使え、everyは名詞が必要（名詞なしは every one）だということです。

語名詞なしof を付ける
eacheach / each oneeach of the …
everyevery oneevery one of the …

each (of) ／ every (+ 名詞) ／ every one (of)

Unit 91　Section C

each in the middle, a dollar each

今回の学習範囲：Section C

次は、each の置き場所です。

文の途中や、値段のあとにも置けます。

今回のテーマeach は、文の途中や値段のあとにも置ける

① each は、文の途中にも置ける

教科書は、次のように説明しています。

We also use each in the middle of a sentence. For example:

つまり、each は、文の途中にも使う。例えば次のようになる。

The students were each given a book.

学生たちは、それぞれ本を1冊もらった。

教科書の補足：(= Each student was given a book.)

② each は、値段のあとに置いて「1つにつき」を表す

教科書の説明を見てみましょう。

We say a dollar each, ten pounds each etc. :

つまり、a dollar each、ten pounds each などと言う。

These oranges are 40 pence each.

これらのオレンジは、1個40ペンスだ。

教科書の補足：(each = for one orange)

形意味
動詞のあとの eachそれぞれ
値段 + each1つにつき

each は、値段や個数を言うときにも使えます。

The tickets cost ten dollars each.

チケットは、1枚10ドルだ。

会話では、値段をたずねるときに使います。

A: How much are the tickets?

チケットはいくら？

B: Twenty pounds each.

1枚20ポンドだよ。

覚えておきたいのは、eachは文の途中に置いて「それぞれ」、値段のあとに置いて「1つにつき」を表すということです。

位置意味例
文の途中それぞれThe students were each given a book.
値段のあと1つにつきThese oranges are 40 pence each.

値段 + each ＝ 1つにつき

Unit 91　Section D

everyone and every one

今回の学習範囲：Section D

最後は、everyone と every one です。

今回のテーマeveryone ＝ みんな（人だけ）、every one ＝ 1つ1つ（物も人も）

① everyone は「みんな」、every one は「1つ1つ」である

教科書は、次のように説明しています。

Everyone (one word) is only for people (= everybody). Every one (two words) is for things or people:

つまり、everyone（1語）は、人だけに使う（＝ everybody）。every one（2語）は、物にも人にも使う。

Compare
everyoneEveryone enjoyed the party.みんな、パーティーを楽しんだ。(= Everybody …)
every oneSarah is invited to lots of parties and she goes to every one.サラは、たくさんのパーティーに招待されていて、1つ残らず行く。(= to every party)
つづり対象意味
everyone人だけみんな
every one物も人も1つ1つ・1人1人

everyone と every one は、つづりで意味が変わります。

Everyone is here.

みんな、来ている。

I like these books. I've read every one.

これらの本が好きだ。1冊残らず読んだ。

会話では、出席をたずねるときに使います。

A: Did everyone come?

みんな来た？

B: Yes, every one of them.

うん、1人残らず。

覚えておきたいのは、everyone（1語）は人だけ、every one（2語）は物にも人にも使うということです。

つづり対象例
everyone人だけEveryone enjoyed the party.
every one物も人もShe goes to every one.

everyone ＝ 人だけ　／　every one ＝ 1つ1つ
