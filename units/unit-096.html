UNIT 96

Relative clauses 5: extra information clauses (2)

Unit 96　関係詞節（5）追加情報の節（2）

「リーさん、先日の会議でお話ししましたが、提案に興味をお持ちです」。ビジネス文書で見かける、少しかたい関係詞の形です。前置詞 + whom / which、all of whom、そして文全体を受ける which。書き言葉でよく使います。

セクションの地図

Section扱う内容
A前置詞 + whom / which（to whom / without which）
Ball of whom / most of which などの量を表す形
Cwhich が文全体を受ける形（which ≠ what）

色の対応

前置詞 + whom / which ＝ 青、量 + of whom / which ＝ 緑、文全体を受ける which ＝ 橙、誤り＝赤。

Unit 96　Section A

Preposition + whom / which

今回の学習範囲：Section A

まず、前置詞 + whom / which です。

今回のテーマ前置詞 + whom（人）/ which（物）

① かたい書き言葉では、前置詞を whom / which の前に置く

to whom や without which のような形は、新聞や論文などの、書き言葉の香りがします。会話で使うと、少し堅苦しく、気取って聞こえるかもしれません。

教科書は、次のように説明しています。

You can use a preposition + whom (for people) and which (for things). So you can say: to whom / with whom / about whom etc. / of which / without which / from which etc.

つまり、前置詞 + whom（人）や、前置詞 + which（物）が使えます。to whom、with whom、about whom、of which、without which、from which などです。

Mr Lee, to whom I spoke at the meeting, is interested in our proposal.

リーさんは、会議で私が話した人だが、私たちの提案に関心を持っている。

Fortunately we had a good map, without which we would have got lost.

幸い、よい地図があった。それがなかったら、道に迷っていただろう。

説明される名詞前置詞 + 関係詞
人to whom / with whom / about whom
物of which / without which / from which

② 会話では、前置詞を動詞のあとに残す

教科書の説明を見てみましょう。

In spoken English we often keep the preposition after the verb in the relative clause: Katherine told me she works for a company called 'Latoma', which I'd never heard of before. We do not use whom when the preposition is in this position:

つまり、話し言葉では、前置詞を関係詞節の動詞のあとに残すことが多いです。キャサリンは、Latoma という会社で働いていると言っていましたが、私は聞いたことがありませんでした。前置詞がこの位置にあるときは、whom は使いません。

Katherine told me she works for a company called 'Latoma', which I'd never heard of before.

キャサリンは、'Latoma' という会社で働いていると言った。私は、その会社を聞いたことがなかった。

Mr Lee, who I spoke to at the meeting, is interested in our proposal. (not whom I spoke to)

リーさんは、会議で私が話した人だが、私たちの提案に関心を持っている。

スタイル形whom
かたい（書き言葉）前置詞 + whom使う
ふつう（話し言葉）who … 前置詞使わない

前置詞を前に置く形は、かたい書き言葉です。会話では、前置詞を後ろに残す形がふつうです（Unit 93C）。

前置詞 + whom は、会議や契約の文書にも使えます。

The man with whom I work is very helpful.

私がいっしょに働いている男性は、とても親切だ。

会話では、人について聞かれて説明するときに使います。

A: Who's Mr Lee?

リーさんって誰？

B: He's the man who I spoke to at the meeting.

会議で話した人だよ。

覚えておきたいのは、かたい書き言葉では前置詞 + whom / which、ふつうの会話では前置詞を後ろに残すということです。

スタイル形
書き言葉to whom / without which
会話who / which … + 前置詞

前置詞 + whom（人）/ which（物）

Unit 96　Section B

all of whom, most of which

今回の学習範囲：Section B

次は、量 + of whom / which です。

「そのうちの〜」を追加します。

今回のテーマall of whom / most of which などで、「そのうちの〜」を追加する

① all of whom / most of which は、「そのうちの〜」を追加する

全体の人数や数を、すでに言ってあって、そのうちの内訳を、あとから足す形です。Helen has three brothers, all of whom are married. は、「兄弟は3人。そのうち、3人とも結婚している」と、情報を足しています。

教科書は、次のように説明しています。

You can say:

つまり、次のように言えます。

Helen has three brothers, all of whom are married.

ヘレンには兄（弟）が3人いて、全員が結婚している。

They asked me a lot of questions, most of which I couldn't answer.

彼らは、私にたくさん質問してきたが、そのほとんどに答えられなかった。

教科書の説明を見てみましょう。

In the same way you can say: many of whom / some of whom / neither of whom etc. (for people) / none of which / both of which / one of which etc. (for things)

つまり、同じように、many of whom、some of whom、neither of whom など（人）、none of which、both of which、one of which など（物）と言えます。

Martin tried on three jackets, none of which fitted him.

マーティンは3着のジャケットを着てみたが、どれも体に合わなかった。

Two men, neither of whom I had seen before, came into the office.

男の人が2人、事務所に入ってきたが、どちらも見たことのない人だった。

They have three cars, two of which they rarely use.

彼らは車を3台持っているが、そのうち2台はめったに使わない。

Sue has a lot of friends, many of whom she was at school with.

スーには友達がたくさんいて、その多くが学校でいっしょだった人たちだ。

説明される名詞形意味
人（brothers / friends）all / many / some / neither of whomそのうち〜
物（questions / cars）most / none / both / two of whichそのうち〜

② the cause of which / the name of which のように、名詞 + of which も使える

教科書には、次の説明があります。

You can also say: the cause of which / the name of which etc.

つまり、the cause of which や the name of which などとも言えます。

The house was damaged in a fire, the cause of which was never established.

その家は火事で被害を受けたが、原因は結局分からなかった。

We stayed at a beautiful hotel, the name of which I don't remember now.

私たちは美しいホテルに泊まったが、その名前は今は覚えていない。

量 + of which は、本や車などの物にも使えます。

She wrote five novels, two of which became bestsellers.

彼女は5冊の小説を書き、そのうち2冊がベストセラーになった。

会話では、兄弟の人数を聞かれて答えるときに使います。

A: Do you have any brothers?

兄弟はいる？

B: Yes, three, all of whom live in Canada.

うん、3人いて、全員がカナダに住んでいるよ。

覚えておきたいのは、追加情報として「そのうちの〜」を言うときは、人には量 + of whom、物には量 + of whichを使うということです。

説明される名詞形例
人all / many / neither of whomthree brothers, all of whom …
物most / none / two of whichquestions, most of which …

Unit 96　Section C

which, not what

今回の学習範囲：Section C

最後は、文全体を受ける which です。

今回のテーマ前の文全体は which で受ける（what は使わない）

① カンマのあとの which は、前の文全体を受ける

which は、直前の名詞だけでなく、文全体の内容を指せます。Sarah couldn't meet us, which was a shame. の which は、「サラが会えなかったこと」全体です。日本語の「それは残念だった」の「それ」に、ぴったりです。

Study this example
2つの文Joe got the job. This surprised everybody. (2 sentences)ジョーは、その仕事に就いた。それはみんなを驚かせた。
1つの文Joe got the job, which surprised everybody. (1 sentence)ジョーは、その仕事に就いて、それはみんなを驚かせた。

教科書は、次のように説明しています。

In this example, which = 'the fact that Joe got the job'. We use which (not what) in sentences like these:

つまり、この例では、which は「ジョーが仕事に就いたという事実」を指しています。このような文では which を使い、what は使いません。

Sarah couldn't meet us, which was a shame. (not what was a shame)

サラが私たちに会えなかったのは、残念だった。

The weather was good, which we hadn't expected. (not what we hadn't expected)

天気がよかった。それは予想していなかった。

which が指すもの例
前の文全体（事実）, which
名詞 1つ, which（ふつうの Type 2）

カンマのあとの which は、直前の名詞だけでなく、前の文全体を指せます。「ジョーが仕事に就いた」という出来事全体が、「みんなを驚かせた」のです。

教科書の説明を見てみましょう。

For what and that, see Units 92D and 93D.

つまり、what と that については、Unit 92D と 93D を見てください。

文全体を受ける which は、感想やコメントにも使えます。

It rained all day, which spoiled our picnic.

1日中雨が降り、それでピクニックが台なしになった。

会話では、天気について感想を言うときに使います。

A: How was the weather?

天気はどうだった？

B: It was sunny, which was great.

晴れていて、それはよかったよ。

覚えておきたいのは、, whichは、前の文全体の内容を受けることができ、what は使わないということです。

受けるもの関係詞
前の文全体, which（what は不可）

文, which + 動詞（前の文全体を受ける）
