UNIT 102

so and such

Unit 102　so と such

「とても疲れた」「すごくいい天気だった」。日本語は、どちらも「とても」ですが、英語は so と such に分かれます。決め手は、あとに続く語です。形容詞なら so、名詞なら such です。

セクションの地図

Section扱う内容
Aso + 形容詞・副詞、such + (形容詞 +) 名詞
Bso / such は意味を強める。so … that / such … that（結果）
C「こんなに」「そんな」の so / such。no such …
Dso long と such a long time など、組み合わせの違い

色の対応

so ＝ 青、such ＝ 緑、誤り＝赤。

Unit 102　Section A

so + adjective, such + noun

今回の学習範囲：Section A

まず、基本の形です。

今回のテーマso のあとは形容詞・副詞、such のあとは名詞（形容詞 + 名詞）

① so は形容詞・副詞の前、such は名詞を含む形の前に置く

so と such は、どちらも「とても」ですが、あとに続く形が決まっています。so のあとには、形容詞か副詞だけが来ます。such のあとには、名詞が来ます（形容詞が前に付いてもかまいません）。

The film was so good.

その映画は、とてもよかった。

It was such a good film.

それは、とてもいい映画だった。

so と such は、どちらも「とても」ですが、あとに続く形が決まっています。so のあとには、形容詞か副詞だけが来ます。such のあとには、名詞が来ます（形容詞が前に付いてもかまいません）。

The film was so good.

その映画は、とてもよかった。

It was such a good film.

それは、とてもいい映画だった。

教科書は、次のように説明しています。

Compare so and such: We use so + adjective/adverb: so stupid / so quick / so nice / so quickly. We use such + noun: such a story / such people. We also use such + adjective + noun: such a stupid story / such nice people.

つまり、so と such を比べてみましょう。so のあとには、形容詞・副詞が続きます。so stupid、so quick、so nice、so quickly などです。such のあとには、名詞が続きます。such a story や such people などです。such + 形容詞 + 名詞の形もあります。such a stupid story や such nice people などです。

Compare
so + 形容詞・副詞I didn't like the book. The story was so stupid. / Everything happened so quickly.その本は好きではなかった。話がとてもばかげていた。/ すべてがとても速く起きた。
such + 名詞I didn't like the book. It was such a stupid story. (not a so stupid story) / I like Liz and Joe. They are such nice people. (not so nice people)その本は好きではなかった。とてもばかげた話だった。/ リズとジョーが好きだ。2人はとてもいい人たちだ。
あとに続くもの使う語例
形容詞・副詞soso stupid / so quickly
名詞（形容詞 + 名詞）suchsuch a stupid story

教科書の説明を見てみましょう。

We say such a … (not a such): such a big dog

つまり、such a … と言い、a such とは言いません。such a big dog のようになります。

so は、天気・味・疲れなど、形容詞の強調にも使えます。

The soup was so hot that I couldn't eat it.

スープはとても熱くて、食べられなかった。

It was such a hot day.

とても暑い日だった。

会話では、映画の感想を言うときに使います。

A: How was the film?

映画はどうだった？

B: It was such a good film. I was so happy.

とてもいい映画だったよ。すごく楽しかった。

覚えておきたいのは、so + 形容詞・副詞、such + (a +) (形容詞 +) 名詞という形で使うということです。

あとに続くもの語例
形容詞・副詞soso quickly
名詞such a / suchsuch a stupid story

so + 形容詞・副詞　／　such (a) + (形容詞) + 名詞

Unit 102　Section B

so … that and such … that

今回の学習範囲：Section B

次は、so … that です。結果を言えます。

「とても〜なので、…」という文です。

今回のテーマso / such は意味を強める。so … that で結果を言える

① so と such は、意味を強める

教科書は、次のように説明しています。

So and such make the meaning stronger:

つまり、so と such は、意味を強めます。

Compare
soI've had a busy day. I'm so tired. / It's difficult to understand him. He talks so quietly.忙しい1日だった。とても疲れている。/ 彼の話は聞き取りにくい。とても静かに話す。(so tired = really tired)
suchWe had a great trip. We had such a good time. / You always think good things are going to happen. You're such an optimist.すばらしい旅行だった。とても楽しい時間を過ごした。/ あなたはいつも、いいことが起きると思っている。本当に楽天家だ。

② so … that / such … that は、結果を表す

「とても〜なので、…だ」という、原因と結果の形です。so や such で程度を言って、that 以下で、その結果を言います。会話では、that を省くことが多いです。

It was so cold (that) the lake froze.

とても寒かったので、湖が凍った。

「とても〜なので、…だ」という、原因と結果の形です。so や such で程度を言って、that 以下で、その結果を言います。会話では、that を省くことが多いです。

It was so cold (that) the lake froze.

とても寒かったので、湖が凍った。

教科書の説明を見てみましょう。

You can use so … that: You can use such … that:

つまり、so … that と such … that の形が使えます。

I was so tired that I fell asleep in the armchair.

とても疲れていて、肘掛け椅子で眠ってしまった。

It was such nice weather that we spent the whole day on the beach.

とてもいい天気だったので、1日中、海辺で過ごした。

教科書には、次の説明があります。

We usually leave out that:

つまり、that は、ふつう省略します。

I was so tired (that) I fell asleep.

とても疲れていて、眠ってしまった。

It was such nice weather (that) we spent the whole day on the beach.

とてもいい天気だったので、1日中、海辺で過ごした。

形意味
so + 形容詞・副詞 + that …とても〜なので…
such + (a +) 形容詞 + 名詞 + that …とても〜なので…

so … that は、結果をつなげて言うときにも使えます。

It was so cold that the lake froze.

とても寒くて、湖が凍った。

会話では、遅れた理由を言うときに使います。

A: Why were you late?

どうして遅れたの？

B: There was such heavy traffic that I couldn't move.

交通渋滞がひどくて、動けなかったんだ。

覚えておきたいのは、soとsuchは意味を強め、so … that・such … thatで「とても〜なので…」という結果を表すということです。

形意味
so + 形容詞 + thatとても〜なので…
such + 名詞 + thatとても〜なので…

so / such … (that)

Unit 102　Section C

so and such = like this

今回の学習範囲：Section C

so と such には、もう1つの意味があります。こんなにです。

驚きを表すときに使います。

今回のテーマso / such には「こんなに」「そんな」の意味もある

① so は「こんなに」、such は「そんな」を表す

この so や such は、驚きや感想を言うときに使います。「こんなに古いとは思わなかった」の気持ちが、I didn't realise it was so old. にこもっています。強調して、声を高くして言うのがふつうです。

この so や such は、驚きや感想を言うときに使います。「こんなに古いとは思わなかった」の気持ちが、I didn't realise it was so old. にこもっています。強調して、声を高くして言うのがふつうです。

教科書は、次のように説明しています。

So and such also mean 'like this':

つまり、so と such には、「このような」という意味もあります。

Somebody told me the house was built 100 years ago. I didn't realise it was so old.

その家は100年前に建てられたと聞いた。そんなに古いとは思わなかった。

教科書の補足：(= as old as it is)

I'm tired because I got up at six. I don't usually get up so early.

6時に起きたので疲れている。ふだんは、こんなに早く起きない。

I didn't realise it was such an old house.

そんなに古い家だとは思わなかった。

You know it's not true. How can you say such a thing?

それが本当でないことは分かっているでしょう。どうしてそんなことが言えるの？

教科書の補足：(= a thing like this)

② no such … は、「そのような〜はない」を表す

教科書の説明を見てみましょう。

Note the expression no such …:

つまり、no such … という表現にも、気をつけましょう。

You won't find the word 'blid' in the dictionary. There's no such word.

辞書には 'blid' という言葉は載っていない。そんな言葉は存在しない。

教科書の補足：(= this word does not exist)

形意味
so + 形容詞こんなに〜（= as … as it is）
such a + 名詞そんな〜
no such + 名詞そんな〜は存在しない

such は、驚きや感想を言うときにも使えます。

I've never seen such a beautiful sunset.

こんなに美しい夕焼けは、見たことがない。

会話では、驚きを伝えるときに使います。

A: There's a ghost in the house!

家に幽霊がいるよ！

B: Don't be silly. There's no such thing.

ばかなことを言わないで。そんなものは存在しないよ。

覚えておきたいのは、soとsuchには「こんなに」「そんな」の意味もあり、no such …は「そんな〜は存在しない」だということです。

形意味
so + 形容詞・副詞こんなに〜
such a + 名詞そんな〜
no such + 名詞そんな〜は存在しない

so early / such a thing / no such word

Unit 102　Section D

so long / such a long time

今回の学習範囲：Section D

最後は、間違いやすい組み合わせです。

今回のテーマso + 形容詞・副詞、such + (a) 名詞で、決まった組み合わせがある

① so long と such a long time は、品詞が違うので形が変わる

so long の long は形容詞、such a long time の time は名詞です。so のあとは形容詞、such のあとは名詞を含む形、と覚えておけば、迷いません。同じ意味の文でも、so と such で形が変わるのです。

so long の long は形容詞、such a long time の time は名詞です。so のあとは形容詞、such のあとは名詞を含む形、と覚えておけば、迷いません。同じ意味の文でも、so と such で形が変わるのです。

教科書は、次のように説明しています。

Compare: so long / such a long time; so far / such a long way; so much, so many / such a lot (of)

つまり、so long と such a long time、so far と such a long way、so much / so many と such a lot (of) を比べてみましょう。

Compare
so + 形容詞・副詞I haven't seen her for so long I've forgotten what she looks like. / I didn't know it was so far. / I'm sorry I'm late – there was so much traffic.彼女に長い間会っていないので、見た目を忘れてしまった。/ そんなに遠いとは知らなかった。/ 遅れてごめん。交通量がとても多かった。
such + 名詞I haven't seen her for such a long time. (not so long time) / I didn't know it was such a long way. / I'm sorry I'm late – there was such a lot of traffic.彼女には、とても長い間会っていない。/ そんなに遠い道のりだとは知らなかった。/ 遅れてごめん。交通量がとても多かった。
so + 形容詞・副詞such + (a) + 名詞
so longsuch a long time
so farsuch a long way
so much / so manysuch a lot (of)

so long の long は形容詞（または副詞）、such a long time の time は名詞です。so long time とは言いません。

so と such は、時間や距離の話でも使い分けます。

It took so long to get here.

ここへ来るのに、とても時間がかかった。

It took such a long time to get here.

ここへ来るのに、とても長い時間がかかった。

会話では、待ち時間をたずねるときに使います。

A: Have you been waiting long?

長く待っている？

B: Yes, for such a long time!

うん、とても長い間ね！

覚えておきたいのは、so + 形容詞（long / far / much）とsuch a + 名詞（long time / long way / lot of）は、同じ意味でも組み合わせが違うということです。

so を使う形such を使う形
so longsuch a long time
so farsuch a long way
so much / manysuch a lot (of)

so + 形容詞・副詞　／　such a + 名詞
