UNIT 104

quite, pretty, rather and fairly

Unit 104　quite / pretty / rather / fairly

「わりと有名」「かなり寒い」「まあまあ広い」。日本語の「わりと」は、1語で済みます。英語は、quite・pretty・rather・fairly と4つあります。強さと気持ちが、それぞれ少しずつ違います。

セクションの地図

Section扱う内容
Aquite と pretty（very より弱く、a little より強い）。quite の位置と使い方
Brather ＝ 悪い意味のことに多い。よい意味では「意外に」
Cfairly ＝ quite / rather / pretty より弱い
Dquite ＝ 「完全に」の意味

色の対応

quite / pretty ＝ 青、rather ＝ 橙、fairly ＝ 緑、quite（完全に）＝ 紫、誤り＝赤。

Unit 104　Section A

quite and pretty

今回の学習範囲：Section A

まず、quite と pretty です。

今回のテーマquite / pretty ＝ very より弱く、a little より強い

① quite と pretty は、very より弱く、a little より強い

quite と pretty は、「かなり」と「わりと」の中間くらいです。very good だと、「とてもよい」ですが、quite good や pretty good なら、「なかなかいい」くらいです。英語話者は、日常会話で、pretty をとてもよく使います。

quite と pretty は、「かなり」と「わりと」の中間くらいです。very good だと、「とてもよい」ですが、quite good や pretty good なら、「なかなかいい」くらいです。英語話者は、日常会話で、pretty をとてもよく使います。

教科書は、次のように説明しています。

Quite and pretty are similar in meaning (= less than 'very', but more than 'a little'):

つまり、quite と pretty は、意味が似ています。'very' より弱く、'a little' より強い程度を表します。

I'm surprised you haven't heard of her. She's quite famous. or She's pretty famous.

あなたが彼女を知らないとは驚きだ。かなり有名なのに。

教科書の補足：(= less than 'very famous', but more than 'a little famous')

Anna lives quite near me, so we see each other pretty often.

アンナは、私のわりと近くに住んでいるので、わりとよく会う。

強さ語例
弱いa littlea little famous
中くらいquite / prettyquite famous
強いveryvery famous

② quite は、a / an の前に置く

ふつうの形容詞は、a のあとに来ます。a very old house。でも、quite は、a の前です。quite an old house。この語順の違いは、quite の、大きな特徴です。

ふつうの形容詞は、a のあとに来ます。a very old house。でも、quite は、a の前です。quite an old house。この語順の違いは、quite の、大きな特徴です。

教科書の説明を見てみましょう。

Quite goes before a/an: We live in quite an old house. (not a quite old house) Compare:

つまり、quite は、a / an の前に置きます。We live in quite an old house. と言い、a quite old house とは言いません。比べてみましょう。

Compare
quite + a + 形容詞 + 名詞Sarah has quite a good job.サラは、わりとよい仕事に就いている。
a + pretty + 形容詞 + 名詞Sarah has a pretty good job.サラは、わりとよい仕事に就いている。
語a / an との位置
quitea / an の前（quite a good job）
prettya / an のあと（a pretty good job）

③ quite だけが使える形もある

教科書には、次の説明があります。

You can also use quite (but not pretty) in the following ways: quite a/an + noun (without an adjective): quite a lot (of …): quite + verb, especially like and enjoy:

つまり、quite は、次のようにも使えます（pretty は使えません）。quite a / an + 名詞（形容詞なし）、quite a lot (of …)、quite + 動詞（特に like や enjoy）です。

I didn't expect to see them. It was quite a surprise.

彼らに会うとは思っていなかった。かなりの驚きだった。

教科書の補足：(= quite a big surprise)

There were quite a lot of guests at the wedding.

結婚式には、かなり大勢の客がいた。

I quite like tennis, but it's not my favourite sport.

テニスはまあまあ好きだが、いちばん好きなスポーツではない。

quite は、映画・仕事・買い物の感想にも使えます。

It was quite a long film.

わりと長い映画だった。

会話では、好みをたずねられたときに使います。

A: Do you like jazz?

ジャズは好き？

B: I quite like it.

まあまあ好きだよ。

覚えておきたいのは、quite / prettyは「very より弱く、a little より強い」で、quite は a / an の前に置くということです。

語位置例
quitea / an の前quite a good job
prettya / an のあとa pretty good job

quite a + 形容詞 + 名詞　／　a pretty + 形容詞 + 名詞

Unit 104　Section B

rather

今回の学習範囲：Section B

次は、rather です。

悪い意味に使うことが多い言葉です。

今回のテーマrather ＝ 悪い意味のことに多い。よい意味では「意外に」

① rather は、悪い意味のことに使うことが多い

rather は、「期待より悪い」という気持ちが入ります。It's rather cold. は、「思っていたより寒い（嫌だな）」です。イギリス英語で、よく使われます。

rather は、「期待より悪い」という気持ちが入ります。It's rather cold. は、「思っていたより寒い（嫌だな）」です。イギリス英語で、よく使われます。

教科書は、次のように説明しています。

Rather is similar to quite and pretty. We often use rather for negative ideas (things we think are not good):

つまり、rather は、quite や pretty に似ています。悪い意味のこと（よくないと思うこと）に、rather をよく使います。

The weather isn't so good. It's rather cloudy.

天気はあまりよくない。どちらかといえば曇りだ。

Paul is rather shy. He doesn't talk very much.

ポールはどちらかといえば内気だ。あまり話さない。

この2つの例では、rather の代わりに quite を使ってもかまいません。

② よい意味に使うと、「意外に」の意味になる

よい意味に rather を使うと、「思ったより、ずっといい」という、驚きを表します。These oranges are rather good. は、「このオレンジ、意外においしい」です。

よい意味に rather を使うと、「思ったより、ずっといい」という、驚きを表します。These oranges are rather good. は、「このオレンジ、意外においしい」です。

教科書の説明を見てみましょう。

When we use rather for positive ideas (good/nice etc.), it means 'unusually' or 'surprisingly':

つまり、よい意味のこと（good / nice など）に rather を使うと、「ふつうでなく」「意外にも」という意味になります。

These oranges are rather good. Where did you get them?

このオレンジは、意外においしい。どこで買ったの？

意味語気持ち
悪い意味ratherよくない
よい意味rather意外にもよい

rather は、天気や性格の話にも使えます。

It's rather cold today.

今日は、かなり寒い。

会話では、味の感想を言うときに使います。

A: How's the soup?

スープはどう？

B: It's rather good, actually.

実は、意外においしいよ。

覚えておきたいのは、ratherは悪い意味のことによく使い、よい意味では「意外に」を表すということです。

意味語例
悪い意味ratherrather cloudy / rather shy
よい意味ratherrather good（意外に）

rather + 悪い意味 ／ 意外によい

Unit 104　Section C

fairly

今回の学習範囲：Section C

次は、fairly です。

4つのなかで、いちばん弱い言葉です。

今回のテーマfairly は、quite / rather / pretty より弱い

① fairly は、もっとよくなる余地がある場合に使う

fairly は、4つのなかで、いちばん弱い言葉です。fairly good は、「悪くはないけれど、特別いいわけでもない」。ほめ言葉としては、物足りない、ということです。

fairly は、4つのなかで、いちばん弱い言葉です。fairly good は、「悪くはないけれど、特別いいわけでもない」。ほめ言葉としては、物足りない、ということです。

教科書は、次のように説明しています。

Fairly is weaker than quite/rather/pretty. For example, if something is fairly good, it is not very good and it could be better:

つまり、fairly は、quite / rather / pretty より弱い言葉です。たとえば、something is fairly good なら、とてもよいわけではなく、もっとよくなる余地があります。

My room is fairly big, but I'd prefer a bigger one.

私の部屋はわりと広いが、もっと広いほうがいい。

We see each other fairly often, but not as often as we used to.

私たちは、わりとよく会うが、以前ほどではない。

強さ語
弱いfairly
中くらいquite / pretty
強いvery

fairly は、わりとよいが、完璧ではない、という評価にも使えます。

The restaurant was fairly good, but not great.

そのレストランはまあまあよかったが、すばらしくはなかった。

会話では、映画をすすめるかどうかを言うときに使います。

A: Is the film good?

その映画はおもしろい？

B: It's fairly good. Not amazing.

まあまあだよ。すごくはないけど。

覚えておきたいのは、fairlyは quite / rather / pretty より弱い「まあまあ」だということです。

語強さ
fairly弱い（まあまあ）
quite / pretty中くらい
rather中くらい（悪い意味に多い）

fairly < quite / pretty / rather < very

Unit 104　Section D

quite = completely

今回の学習範囲：Section D

最後は、quite の別の顔です。

今回のテーマquite には「完全に」の意味もある

① quite は、「まったく」の意味にもなる

quite には、「かなり」と「まったく」の、2つの意味があります。意味を決めるのは、後ろの語です。sure、right、true、different のような、程度で言えない形容詞のときは、「まったく」になります。

I'm quite sure.

私は、まったく確信している。

It's quite good.

なかなかいい。

quite には、「かなり」と「まったく」の、2つの意味があります。意味を決めるのは、後ろの語です。sure、right、true、different のような、程度で言えない形容詞のときは、「まったく」になります。

I'm quite sure.

私は、まったく確信している。

It's quite good.

なかなかいい。

教科書は、次のように説明しています。

Quite also means 'completely'. For example: 'Are you sure?' 'Yes, quite sure.' (= completely sure)

つまり、quite には、「完全に」という意味もあります。たとえば、「確かですか？」「はい、完全に確かです（quite sure）。」のようになります。

'Are you sure?' 'Yes, quite sure.'

「確かなの？」「うん、まったく確かだ。」

教科書の補足：(= completely sure)

教科書の説明を見てみましょう。

Quite means 'completely' with a number of adjectives, especially: sure / right / true / clear / different / incredible / amazing / certain / wrong / safe / obvious / unnecessary / extraordinary / impossible

つまり、quite は、次のような形容詞といっしょに使うと、「完全に」の意味になります。sure、right、true、clear、different、incredible、amazing、certain、wrong、safe、obvious、unnecessary、extraordinary、impossible などです。

She was quite different from what I expected.

彼女は、私が思っていたのとはまったく違っていた。

教科書の補足：(= completely different)

Everything they said was quite true.

彼らが言ったことは、すべてまったく本当だった。

教科書の補足：(= completely true)

② 動詞といっしょの quite は、「まったく」を表す

教科書には、次の説明があります。

We also use quite (= completely) with some verbs. For example:

つまり、動詞といっしょにも、quite（完全に）を使います。例を見てみましょう。

I quite agree with you.

まったく同感だ。

教科書の補足：(= I completely agree)

③ not quite は、「完全にではない」を表す

教科書は、次のように説明しています。

not quite = not completely:

つまり、not quite は、「完全にではない」という意味です。

I don't quite understand what you mean.

あなたの言いたいことが、完全には分からない。

'Are you ready yet?' 'Not quite.'

「もう準備できた？」「まだ完全にはね。」

④ quite の2つの意味は、後ろの語で見分ける

教科書の説明を見てみましょう。

Compare the two meanings of quite:

つまり、quite の2つの意味を比べてみましょう。

Compare
わりとThe story is quite interesting.その話は、わりとおもしろい。(= less than 'very interesting')
完全にThe story is quite true.その話は、まったく本当だ。(= completely true)
quite の意味あとに来る語例
わりとinteresting / good / old などquite interesting
完全にtrue / sure / different / impossible などquite true

「まったく」の quite は、同意や断定の場面にも使えます。

That's quite impossible.

それはまったく不可能だ。

会話では、賛成するかをたずねられたときに使います。

A: Do you agree?

賛成する？

B: Yes, I quite agree.

うん、まったく同感だ。

覚えておきたいのは、quiteは、true / sure / different などの形容詞とは「完全に」、interesting / good などとは「わりと」の意味になるということです。

あとに来る語意味
true / sure / different など完全に
interesting / good などわりと

quite + sure ＝ 完全に　／　quite + interesting ＝ わりと
