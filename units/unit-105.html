UNIT 105

Comparative 1 (cheaper, more expensive etc.)

Unit 105　比較級（1）cheaper / more expensive

「電車より車のほうが安い」。日本語は、「安い」に「より」を足すだけで比べられます。英語は、形容詞を変身させます。cheap → cheaper、expensive → more expensive。短い語には -er、長い語には more を付けます。

セクションの地図

Section扱う内容
A比較級とは（cheaper / more expensive）。than でつなぐ
B-er か more … か（1音節・2音節・-ly の副詞）
C不規則な比較級（better / worse / further）

色の対応

-er ＝ 青、more … ＝ 緑、不規則 ＝ 紫、誤り＝赤。

Unit 105　Section A

What is a comparative?

今回の学習範囲：Section A

まず、比較級とは何かです。

今回のテーマ比較級は、2つのものを比べる形

① 比較級は、2つのものを比べるときの形である

Look at these examples
How shall we travel? Shall we drive or go by train? / Let's drive. It's cheaper. Don't go by train. It's more expensive.どうやって行く？ 車にする？ 電車にする？/ 車にしよう。そのほうが安い。電車はやめよう。そのほうが高い。

教科書は、次のように説明しています。

Cheaper and more expensive are comparative forms. After comparatives you can use than (see Unit 107):

つまり、cheaper と more expensive は比較級だ。比較級のあとには、than を使える（Unit 107 を見る）。

It's cheaper to drive than go by train.

電車で行くより、車で行くほうが安い。

Going by train is more expensive than driving.

電車で行くことは、車で行くより高い。

元の形比較級than
cheapcheapercheaper than
expensivemore expensivemore expensive than

日本語の「〜より安い」の「より」が、than に当たります。

覚えておきたいのは、比較級は-erまたはmore …の形で、比べる相手はthanで示すということです。

形例
-ercheaper
more …more expensive
thancheaper than

比較級 + than + 比べる相手

Unit 105　Section B

-er or more …?

今回の学習範囲：Section B

次は、-er と more の使い分けです。

決め手は、語の長さです。

今回のテーマ短い語は -er、長い語は more …

① 短い語には -er を付け、長い語の前には more を置く

教科書は、次のように説明しています。

The comparative form is -er or more … . We use -er for short words (one syllable): We use more … for longer words (two syllables or more):

つまり、比較級は -er または more … の形だ。短い語（1音節）には -er を使う。長い語（2音節以上）には more … を使う。

語の長さ比較級の作り方例
1音節-ercheap → cheaper / fast → faster / large → larger / thin → thinner
2音節以上more …more serious / more expensive / more often / more comfortable

教科書の説明を見てみましょう。

We also use -er for two-syllable words that end in -y (-y → -ier):

つまり、-y で終わる2音節の語にも -er を使う（-y → -ier）。

原形比較級
luckyluckier
earlyearlier
easyeasier
prettyprettier

教科書には、次の説明があります。

We also use more … for adverbs that end in -ly: more slowly / more seriously / more easily / more quietly

つまり、-ly で終わる副詞にも more … を使う。more slowly / more seriously / more easily / more quietly。

つづりの変わり方（thin → thinner など）は、教科書の巻末（Appendix 6）にまとめられています。

② 例文で、-er と more の違いを確かめる

教科書は、次のように説明しています。

Compare these examples:

つまり、これらの例を比べる。

Compare
-erYou're older than me. / The exam was quite easy – easier than I expected. / Can you walk a bit faster? / I'd like to have a bigger car. / Last night I went to bed earlier than usual.あなたは私より年上だ。/ 試験はわりと簡単で、思ったより簡単だった。/ もう少し速く歩ける？/ もっと大きい車が欲しい。/ 昨夜は、いつもより早く寝た。
more …You're more patient than me. / The exam was quite difficult – more difficult than I expected. / Can you walk a bit more slowly? / I'd like to have a more reliable car. / I don't play tennis much these days. I used to play more often.あなたは私より辛抱強い。/ 試験はわりと難しく、思ったより難しかった。/ もう少しゆっくり歩ける？/ もっと信頼できる車が欲しい。/ 最近はあまりテニスをしない。以前はもっとよくしていた。

③ 2音節の語には、どちらも使えるものがある

教科書の説明を見てみましょう。

We use both -er or more … with some two-syllable adjectives, especially: clever / narrow / quiet / shallow / simple. It's too noisy here. Can we go somewhere quieter? or … somewhere more quiet?

つまり、いくつかの2音節の形容詞には、-er も more … も使う。特に、clever / narrow / quiet / shallow / simple。It's too noisy here. Can we go somewhere quieter? とも somewhere more quiet? とも言える。

語比較級
clever / narrow / quiet / shallow / simple-erもmore …も可

比較級は、軽さ・速さ・値段など、ふだんの比べ方にも使えます。

This bag is lighter than that one.

このバッグは、あれより軽い。

This book is more interesting than that one.

この本は、あれよりおもしろい。

会話では、2つのどちらが簡単かをたずねるときに使います。

A: Which is easier, English or Spanish?

英語とスペイン語、どちらが簡単？

B: Spanish is easier for me.

私には、スペイン語のほうが簡単だよ。

覚えておきたいのは、短い語（1音節・-y で終わる語）は-er、長い語・-ly の副詞はmore …だということです。

語比較級
1音節（cheap）cheaper
-y で終わる2音節（easy）easier
長い語（expensive）more expensive
-ly の副詞（slowly）more slowly

短い語 → -er　／　長い語 → more …

Unit 105　Section C

Irregular comparatives

今回の学習範囲：Section C

最後は、不規則な形です。

good → better、bad → worse、far → further です。

今回のテーマgood / bad / far は、形が変わる

① good / well の比較級は、better である

教科書は、次のように説明しています。

A few adjectives and adverbs have irregular comparative forms: good/well → better

つまり、いくつかの形容詞と副詞は、不規則な比較級を持つ。good / well → better。

The garden looks better since you tidied it up.

庭は、あなたが整えてから、よくなった。

I know him well – probably better than anybody else knows him.

彼のことはよく知っている。たぶん、ほかの誰よりもよく知っている。

② bad / badly の比較級は、worse である

教科書の説明を見てみましょう。

bad/badly → worse

つまり、bad / badly → worse。

'How's your headache? Better?' 'No, it's worse.'

「頭痛はどう？ よくなった？」「いや、悪化した。」

He did very badly in the exam – worse than expected.

彼は試験でひどい出来だった。予想よりも悪かった。

③ far の比較級は、further（または farther）である

教科書には、次の説明があります。

far → further (or farther)

つまり、far → further（または farther）。

It's a long walk from here to the park – further than I thought. (or farther than)

ここから公園までは、長い道のりだ。思っていたより遠い。

教科書は、次のように説明しています。

Note that further (but not farther) also means 'more' or 'additional':

つまり、further（farther は不可）には、「さらなる」「追加の」という意味もある。

Let me know if you hear any further news.

さらに知らせがあれば、教えて。

教科書の補足：(= any more news)

原形比較級
good / wellbetter
bad / badlyworse
farfurther / farther

不規則な比較級は、体調や品質の話にも使えます。

This phone is better than my old one.

この携帯は、古いのよりいい。

会話では、体調の変化をたずねるときに使います。

A: How's your cold?

風邪の調子はどう？

B: It's worse today.

今日は悪化している。

覚えておきたいのは、good / well → better、bad / badly → worse、far → further（farther）は不規則だということです。

原形比較級
good / wellbetter
bad / badlyworse
farfurther / farther

good → better ／ bad → worse ／ far → further
