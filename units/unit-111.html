Unit 111　still / any more / yet / already

このユニットでは、「まだ」「もう」を表す still / any more / yet / already の使い分けを学びます。日本語の「まだ」「もう」は、英語では4つに分かれます。

セクションの地図

Section扱う内容
Astill ＝ まだ（続いている）
Bnot … any more / any longer / no longer ＝ もう〜ない（変わった）
Cyet ＝ まだ〜ない（期待している）。yet と still の比べ
Dalready ＝ もう（予想より早く）

色の対応

still ＝ 青、any more ＝ 橙、yet ＝ 緑、already ＝ 紫、誤り＝赤。

Unit 111　Section A

still

今回の学習範囲：Section A

まず、still です。

今回のテーマstill ＝ まだ（続いている・変わっていない）

① still ＝ 続いている

教科書は、次のように説明しています。

We use still to say that a situation or action is continuing. It hasn't changed or stopped:

つまり、still は、状況や動作が続いていることを言うときに使う。変わっていないし、止まってもいない。

It's ten o'clock and Joe is still in bed.

10時なのに、ジョーはまだ寝ている。

When I went to bed, Chris was still working.

私が寝るとき、クリスはまだ働いていた。

Do you still want to go away or have you changed your mind?

まだ出かけたい？ それとも気が変わった？

② still ＝ それでも

教科書の説明を見てみましょう。

Still also means 'in spite of this'. For example:

つまり、still には、「それにもかかわらず」の意味もある。例えば次のようになる。

He has everything he needs, but he's still unhappy.

彼は必要なものをすべて持っているが、それでも不幸だ。

教科書には、次の説明があります。

Still usually goes in the middle of the sentence with the verb. See Unit 110.

つまり、still は、ふつう文の中ほど、動詞のそばに置く。Unit 110 を見る。

追加例文（教科書外）
stillI still live with my parents.私は、まだ両親と住んでいる。

日常会話での使用例

A: Are you still waiting for him?

まだ彼を待っているの？

B: Yes, I'm still here.

うん、まだここにいるよ。

確認テスト

覚えておきたいのは、stillは「まだ（続いている）」「それでも」を表し、動詞のそばに置くということです。

語意味位置
stillまだ・それでも動詞のそば

still ＝ 続いている

Unit 111　Section B

any more, any longer, no longer

今回の学習範囲：Section B

Section A では、still を見ました。

今回は、「もう〜ない」を表す言い方です。

今回のテーマnot … any more ＝ もう〜ない（変わった）

① not … any more / any longer

教科書は、次のように説明しています。

We use not … any more or not … any longer to say that a situation has changed. Any more and any longer go at the end of a sentence:

つまり、状況が変わったことを言うときは、not … any more または not … any longer を使う。any more と any longer は、文の最後に置く。

Lucy doesn't work here any more. She left last month. or Lucy doesn't work here any longer.

ルーシーは、もうここで働いていない。先月辞めた。

We used to be good friends, but we aren't any more. or … we aren't any longer.

私たちは以前、仲のよい友達だったが、もうそうではない。

any more は、1語の anymore とも書きます。

② no longer

教科書の説明を見てみましょう。

You can also use no longer. No longer goes in the middle of the sentence: Lucy no longer works here. We do not normally use no more in this way:

つまり、no longer も使える。no longer は文の中ほどに置く。Lucy no longer works here. この意味では、ふつう no more は使わない。

Lucy no longer works here.

ルーシーは、もうここで働いていない。

We are no longer friends. (not no more friends)

私たちは、もう友達ではない。

形位置
not … any more / any longer文の最後
no longer文の中ほど（動詞のそば）

③ still と not … any more の比べ

教科書には、次の説明があります。

Compare still and not … any more:

つまり、still と not … any more を比べる。

Compare
still（続いている）Sally still works here, but Lucy doesn't work here any more.サリーは、まだここで働いているが、ルーシーはもうここで働いていない。
追加例文（教科書外）
any moreHe doesn't live here any more.彼は、もうここに住んでいない。

日常会話での使用例

A: Do you still play the piano?

まだピアノを弾いているの？

B: No, I don't play any more.

ううん、もう弾いていないよ。

確認テスト

覚えておきたいのは、not … any more / any longer（文の最後）とno longer（文の中ほど）は「もう〜ない」を表すということです。

形位置
not … any more / any longer文の最後
no longer動詞のそば

変わった → not … any more / no longer

Unit 111　Section C

yet

今回の学習範囲：Section C

Section B では、「もう〜ない」を見ました。

今回は、yet です。

今回のテーマyet ＝ まだ〜ない・もう〜？（期待している）

① yet ＝ 否定文と疑問文

教科書は、次のように説明しています。

We use yet mainly in negative sentences (He isn't here yet) and questions (Is he here yet?). Yet (= until now) shows that the speaker expects something to happen. Yet usually goes at the end of a sentence:

つまり、yet は、おもに否定文（He isn't here yet）と疑問文（Is he here yet?）で使う。yet（＝ 今まで）は、話し手が何かが起こるのを期待していることを表す。yet は、ふつう文の最後に置く。

It's 10 o'clock and Joe isn't here yet.

10時なのに、ジョーはまだ来ていない。

Have you decided what to do yet?

何をするか、もう決めた？

'Where are you going on holiday?' 'We don't know yet.'

「休暇はどこへ行くの？」「まだ分からない。」

yet は、現在完了とよく使います（Have you decided … yet?）。ふつうの過去形も使えます。

② yet と still の比べ

教科書の説明を見てみましょう。

Compare yet and still:

つまり、yet と still を比べる。

Compare
still（続いている）Mike lost his job six months ago and is still unemployed. / Is it still raining?マイクは、半年前に仕事を失い、まだ失業している。/ まだ雨が降っている？
yet（期待している）Mike lost his job six months ago and hasn't found another job yet. / Has it stopped raining yet?マイクは、半年前に仕事を失い、まだ別の仕事を見つけていない。/ もう雨はやんだ？

③ still + 否定

教科書には、次の説明があります。

Still is also possible in negative sentences (before the negative): She said she would be here an hour ago and she still hasn't come. This is similar to 'she hasn't come yet'. But still … not shows a stronger feeling of surprise or impatience. Compare:

つまり、still は、否定文（否定の前）にも使える。She said she would be here an hour ago and she still hasn't come. これは 'she hasn't come yet' に似ている。でも、still … not は、驚きやいらだちの気持ちがより強い。比べる。

Compare
yet（まもなく来ると思う）I sent him an invitation last week. He hasn't replied yet.先週、彼に招待状を送った。まだ返事がない。(but I expect he will reply soon)
still（遅すぎる）I sent him an invitation weeks ago and he still hasn't replied.数週間前に、彼に招待状を送った。それなのに、まだ返事がない。(he should have replied before now)
形気持ち
hasn't … yetまだ〜ない（そのうち起こると思う）
still hasn't …まだ〜ない（もう起こっているはずなのに、驚き・いらだち）
追加例文（教科書外）
yetI haven't finished my homework yet.まだ宿題が終わっていない。

日常会話での使用例

A: Have you eaten yet?

もう食べた？

B: Not yet.

まだだよ。

確認テスト

覚えておきたいのは、yetは否定文・疑問文で「まだ〜ない」「もう〜？」を表し、stillは「続いている」を表すということです。

語意味位置
yetまだ〜ない・もう〜？文の最後
stillまだ続いている動詞のそば（否定の前）

yet ＝ 期待している　／　still ＝ 続いている

Unit 111　Section D

already

今回の学習範囲：Section D

最後は、already です。

今回のテーマalready ＝ もう（予想より早く）

① already ＝ 予想より早く

教科書は、次のように説明しています。

We use already to say that something happened sooner than expected.

つまり、already は、何かが予想より早く起こったことを言うときに使う。

'What time is Sue leaving?' 'She has already left.'

「スーは何時に出発するの？」「もう出発したよ。」

教科書の補足：(= sooner than you expected)

Shall I tell Joe what happened or does he already know?

ジョーに何があったか話そうか？ それとも、もう知っている？

I've just had lunch and I'm already hungry.

ちょうど昼ごはんを食べたのに、もうおなかがすいた。

② already の位置

教科書の説明を見てみましょう。

Already usually goes in the middle of a sentence (see Unit 110) or at the end:

つまり、already は、ふつう文の中ほど（Unit 110 を見る）、または文の最後に置く。

She's already left. or She's left already.

彼女は、もう出発した。

語意味位置
alreadyもう（予想より早く）中ほどまたは最後
追加例文（教科書外）
alreadyI've already seen that film.その映画は、もう見た。

日常会話での使用例

A: Do you want to see the new film?

新しい映画を見たい？

B: I've already seen it.

もう見たよ。

確認テスト

覚えておきたいのは、alreadyは「もう（予想より早く）」で、文の中ほどか最後に置くということです。

語意味位置
alreadyもう（予想より早く）中ほどまたは最後

already ＝ 予想より早く
