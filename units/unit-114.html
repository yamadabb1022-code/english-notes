Unit 114　in case

「傘を持っていく。雨が降るといけないから」。この「〜といけないから」が、in case です。if と似ていますが、意味はまったく違います。in case は、先に備えることを表します。

セクションの地図

Section扱う内容
Ain case ＝ 〜といけないから（念のため）。will は使わない
Bin case と if の違い
Cin case + 過去形
Din case of ＝ 〜の場合（掲示・説明書）

色の対応

in case ＝ 青、if ＝ 緑、誤り＝赤。

Unit 114　Section A

in case

今回の学習範囲：Section A

まず、基本の使い方です。

今回のテーマin case ＝ 「〜といけないから、今のうちに備える」

① in case は、「〜といけないので、念のため」を表す

Study this example situation
Your car should have a spare wheel in case you have a puncture. (= because it is possible you will have a puncture)車には、パンクしたときのために、スペアタイヤを積んでおくべきだ。（＝ パンクする可能性があるから）

教科書は、次のように説明しています。

in case something happens = because it is possible it will happen

Some more examples of in case:

つまり、in case のほかの例。

I'd better write down my password in case I forget it.

忘れるといけないので、パスワードを書き留めておいたほうがいい。

教科書の補足：(= because it is possible I will forget it)

Shall I draw a map for you in case you have a problem finding our house?

私たちの家を見つけるのに苦労するといけないので、地図を描こうか？

教科書の補足：(= because it is possible you will have a problem finding our house)

② just in case は、「念のため」を表す

教科書の説明を見てみましょう。

We use just in case for a smaller possibility:

つまり、さらに小さな可能性には、just in case を使う。

I don't think it will rain, but I'll take an umbrella just in case.

雨は降らないと思うが、念のため傘を持っていく。

教科書の補足：(= just in case it rains)

③ in case のあとには、will を使わない

教科書には、次の説明があります。

We do not use will after in case (see also Unit 25):

つまり、in case のあとでは will を使わない（Unit 25 も見る）。

I'll write down my password in case I forget it. (not in case I will forget)

忘れるといけないので、パスワードを書き留めておく。

形意味
in case + 主語 + 現在形〜といけないので
just in case念のため

in case は、傘や上着など、持ち物の準備にも使えます。

Take a coat in case it gets cold.

寒くなるといけないので、コートを持っていって。

会話では、傘が要るかをたずねるときに使います。

A: Do you need your umbrella?

傘は要る？

B: I'll take it just in case.

念のため持っていくよ。

覚えておきたいのは、in caseは「〜といけないから（念のため）」で、あとは現在形を使い、will は使わないということです。

形意味
in case + 現在形〜といけないので
just in case念のため

in case + 主語 + 現在形

Unit 114　Section B

in case and if

今回の学習範囲：Section B

次は、if との違いです。

備えるのが先か、条件が先か。そこが分かれ目です。

今回のテーマin case ＝ 先に備える、if ＝ 条件を満たしたらする

① in case は先に備え、if は条件を満たしたあとにする

教科書は、次のように説明しています。

In case and if are not the same. We use in case to say why somebody does (or doesn't do) something. You do something now in case something happens later. Compare:

つまり、in case と if は同じではない。in case は、人がなぜ何かをする（しない）のかを言うために使う。あとで何かが起こるといけないので、今何かをする。比べる。

Compare
in case（先に備える）We'll buy some more food in case Tom comes.トムが来るといけないので、食べ物を多めに買っておく。(= Maybe Tom will come. We'll buy some more food now, whether he comes or not. Then we'll already have the food if he comes.)
if（条件）We'll buy some more food if Tom comes.トムが来たら、食べ物を多めに買う。(= Maybe Tom will come. If he comes, we'll buy some more food. If he doesn't come, we won't buy any more food.)
語いつ買う？トムが来ない場合
in case今買う（来る前に）もう買ってある
if来てから買う買わない

② 例文で、in case と if の違いを確かめる

I'll give you my phone number in case you need to contact me.

連絡が必要になるといけないので、電話番号を教えておく。

You can call me on this number if you need to contact me.

連絡が必要なら、この番号に電話してください。

You should inform the police if your bike is stolen.

自転車が盗まれたら、警察に届けるべきだ。

言い方意味
in case今、備えておく
ifそうなったら、する

if と in case は、荷物や連絡先の話でも使い分けます。

I'll take an umbrella in case it rains.

雨が降るといけないので、傘を持っていく。

I'll take an umbrella if it rains.

雨が降ったら、傘を持っていく。

会話では、食べ物を持っていくかをたずねるときに使います。

A: Shall I bring some food?

食べ物を持っていこうか？

B: Yes, in case people are hungry.

うん、みんながおなかをすかせているといけないから。

覚えておきたいのは、in caseは「今、備えておく」、ifは「そうなったらする」だということです。

語意味
in case今、備えておく
ifそうなったら、する

in case ＝ 備える　／　if ＝ 条件

Unit 114　Section C

in case + past

今回の学習範囲：Section C

次は、過去の話です。

あとの動詞も、過去形になります。

今回のテーマ過去の話では、in case のあとも過去形

① 過去の話では、in case のあとも過去形にする

教科書は、次のように説明しています。

You can use in case + past to say why somebody did something:

つまり、in case + 過去形で、人がなぜ何かをしたのかを言える。

I gave him my phone number in case he needed to contact me.

連絡が必要になるといけないので、彼に電話番号を教えた。

教科書の補足：(= because it was possible that he would need to contact me)

I drew a map for Sarah in case she had a problem finding our house.

私たちの家を見つけるのに苦労するといけないので、サラに地図を描いた。

We rang the doorbell again in case they hadn't heard it the first time.

1回目が聞こえなかったといけないので、もう一度ベルを鳴らした。

時形
現在・未来in case + 現在形
過去in case + 過去形

過去の in case は、備えて行動した話にも使えます。

I took a coat in case it got cold.

寒くなるといけないので、コートを持っていった。

会話では、早く出た理由を説明するときに使います。

A: Why did you leave early?

どうして早く出たの？

B: In case there was a lot of traffic.

交通渋滞しているといけないからね。

覚えておきたいのは、過去の話ではin case + 過去形で「〜といけないので」を表すということです。

時形
現在・未来in case + 現在形
過去in case + 過去形

in case + 過去形（過去の話）

Unit 114　Section D

in case of

今回の学習範囲：Section D

最後は、in case of です。掲示や説明書でよく見ます。

今回のテーマin case of ＝ 〜の場合（掲示や説明書）

① in case of は、「〜の場合は」を表す

教科書は、次のように説明しています。

in case of = if there is … (especially on notices, instructions etc.):

つまり、in case of ＝ もし〜があれば（特に掲示や説明書などで使う）。

In case of fire, please leave the building as quickly as possible.

火災の場合は、できるだけ早く建物から出てください。

教科書の補足：(= if there is a fire)

In case of emergency, call this number.

緊急の場合は、この番号に電話してください。

教科書の補足：(= if there is an emergency)

形あとの形
in case of名詞（fire / emergency）
in case主語 + 動詞

in case of は、火災や雨天などの案内にも使えます。

In case of rain, the match will be postponed.

雨天の場合は、試合は延期される。

会話では、緊急時の対応をたずねるときに使います。

A: What should I do in an emergency?

緊急のときは、どうすればいい？

B: In case of emergency, press this button.

緊急の場合は、このボタンを押してください。

覚えておきたいのは、in case of + 名詞は「〜の場合は」で、掲示や説明書によく使うということです。

形あとの形意味
in case of名詞〜の場合は
in case主語 + 動詞〜といけないので

in case of + 名詞
