Unit 115　unless / as long as / provided

「遅くまで働かない限り、明日会おう」「スピードを出さないと約束するなら、車を貸すよ」。条件の言い方は、if だけではありません。unless、as long as、provided。気持ちが少しずつ違います。

セクションの地図

Section扱う内容
Aunless ＝ 〜でない限り（except if）
Bas long as / so long as / provided / providing ＝ 〜しさえすれば（条件）
C未来のことでも will を使わない

色の対応

unless ＝ 橙、as long as / provided ＝ 青、誤り＝赤。

Unit 115　Section A

unless

今回の学習範囲：Section A

まず、unless です。

今回のテーマunless ＝ except if（〜でない限り）

① unless は、「〜でない限り」を表す

unless は、「〜という例外がなければ」という意味です。I'll see you tomorrow unless I have to work late. は、「遅くまで働かなければならない場合を除いて、明日会おう」。例外を、あとから足す言い方です。

Study this example situation
The club is for members only. You can't go in unless you are a member.そのクラブは、会員専用だ。会員でない限り、入れない。

教科書は、次のように説明しています。

This means: You can't go in except if you are a member. You can go in only if you are a member. unless = except if

Some more examples of unless:

つまり、unless の、ほかの例を見てみましょう。

I'll see you tomorrow unless I have to work late.

遅くまで仕事をしなければならない場合を除いて、明日会おう。

教科書の補足：(= except if I have to work late)

There are no buses to the beach. Unless you have a car, it's difficult to get there.

海へのバスはない。車がない限り、行くのは難しい。

教科書の補足：(= except if you have a car)

② unless は、if … not に言い換えられる

教科書の説明を見てみましょう。

Instead of unless it is often possible to say if … not:

つまり、unless の代わりに、if … not と言えることも多いです。

Unless we leave now, we'll be late. or If we don't leave now, we'll be late.

今出発しない限り、遅れる。

言い方意味
unless + 肯定文〜でない限り
if + 否定文もし〜でなければ

unless は、「〜でない限り」という例外を言うときにも使えます。

You can't enter unless you have a ticket.

チケットがない限り、入れない。

会話では、入場の条件を言うときに使います。

A: Can I come in?

入ってもいい？

B: Not unless you have an invitation.

招待状がない限り、だめだよ。

覚えておきたいのは、unlessは「〜でない限り」で、if … notに言い換えられるということです。

言い方意味
unless + 肯定〜でない限り
if … notもし〜でなければ

unless ＝ except if ＝ if … not

Unit 115　Section B

as long as, provided

今回の学習範囲：Section B

次は、as long as と provided です。

この条件さえ満たせば、という気持ちが強くなります。

今回のテーマas long as / provided ＝ 条件つきで

① as long as / so long as は、「〜しさえすれば」を表す

as long as は、「この条件さえ満たせば、OK」という、条件つきの許可を表します。You can stay as long as you like. は、「好きなだけいていいよ」。条件を言いながら、気軽に許可を出す表現です。

教科書は、次のように説明しています。

You can say as long as or so long as (= if, on condition that):

つまり、as long as または so long as と言えます（if や「条件つきで」の意味です）。

You can borrow my car as long as you promise not to drive too fast.

運転がスピードを出しすぎないと約束するなら、私の車を貸してもいいよ。

教科書の補足：(= You can borrow my car, but you must promise not to drive too fast. This is a condition.)

② provided / providing も、「〜という条件なら」を表す

教科書の説明を見てみましょう。

You can also say provided (that) or providing (that):

つまり、provided (that) や providing (that) とも言えます。

Travelling by car is convenient provided (that) you have somewhere to park.

車での移動は、駐車する場所があれば、便利だ。

教科書の補足：(= It's convenient but only if you have somewhere to park.)

Providing (that) the room is clean, I don't mind which hotel we stay at.

部屋が清潔でさえあれば、どのホテルに泊まっても構わない。

教科書の補足：(= The room must be clean, but otherwise I don't mind.)

言い方意味
as long as / so long as〜しさえすれば（条件）
provided (that) / providing (that)〜しさえすれば（条件）
unless〜でない限り

「if」よりも、「この条件さえ満たせば」という気持ちが強い言い方です。

as long as は、貸し借りや許可の条件にも使えます。

You can stay as long as you like.

好きなだけ、いていいよ。

会話では、使っていいかをたずねられて、条件つきで許可するときに使います。

A: Can I use your computer?

あなたのコンピューターを使ってもいい？

B: Yes, as long as you don't delete anything.

うん、何も消さなければね。

覚えておきたいのは、as long as / so long as / provided / providingは「〜しさえすれば」という条件を表すということです。

言い方意味
as long as / so long as〜しさえすれば
provided / providing (that)〜しさえすれば

as long as / provided (that) + 条件

Unit 115　Section C

Future

今回の学習範囲：Section C

最後は、未来の話です。

今回のテーマunless / as long as などのあとは、will を使わない

① 未来の話でも、あとは現在形を使う

教科書は、次のように説明しています。

unless / as long as etc. for the future: When we are talking about the future, we do not use will after unless / as long as / so long as / provided / providing. We use a present tense (see Unit 25):

つまり、未来のことを話すときは、unless / as long as / so long as / provided / providing のあとで will を使いません。現在形を使います（Unit 25）。

I'm not going out unless it stops raining. (not unless it will stop)

雨がやまない限り、出かけない。

Providing the weather is good, we're going to have a picnic tomorrow. (not providing the weather will be good)

天気さえよければ、明日はピクニックをする。

語あとの形（未来の話）
unless / as long as / provided現在形
(not will)使わない

未来の話でも、条件の節は現在形です。

You can come as long as you promise to be quiet.

静かにすると約束するなら、来てもいい。

会話では、天気しだいの予定を言うときに使います。

A: Are we going to the beach tomorrow?

明日は海へ行く？

B: Yes, unless it rains.

うん、雨が降らなければね。

覚えておきたいのは、未来の話でも、unless / as long as / provided のあとは現在形を使い、will は使わないということです。

語あとの形
unless / as long as / provided現在形

unless / as long as / provided + 現在形（未来でも）
