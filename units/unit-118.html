like and as if

Unit 118　like と as if

このユニットでは、「〜のように見える」「〜のように聞こえる」を表す like / as if / as though を学びます。

セクションの地図

Section扱う内容
Alook / sound / feel + like / as if / as though + 主語 + 動詞
Bit looks like … / it sounds as if …
Cほかの動詞（ran like … / talked as if …）
Das if + 過去形（現実と違うことを言う）

色の対応

like / as if / as though ＝ 青、過去形（現実と違う）＝ 紫、誤り＝赤。

Unit 118　Section A

look like / as if

今回の学習範囲：Section A

まず、人や物の様子を言う形です。

今回のテーマlike / as if / as though ＋ 主語 + 動詞 ＝ 〜のように

① look / sound / feel + like / as if

教科書は、次のように説明しています。

We use like or as if to say how somebody/something looks, sounds or feels:

つまり、like または as if は、人や物がどう見えるか、聞こえるか、感じられるかを言うときに使う。

That house looks like it's going to fall down. or That house looks as if it's going to fall down.

その家は、今にも倒れそうに見える。

Amy sounded like she had a cold, didn't she? or Amy sounded as if she had a cold, didn't she?

エイミーは、風邪を引いているような声だったよね？

I've just had a holiday, but I don't feel like I've had a holiday. or … I don't feel as if I've had a holiday.

休暇を取ったばかりなのに、休暇を取ったという気がしない。

教科書の説明を見てみましょう。

You can also use as though in these examples:

つまり、これらの例では、as though も使える。

I don't feel as though I've had a holiday.

休暇を取ったという気がしない。

形意味
look / sound / feel + like〜のように見える
look / sound / feel + as if〜のように見える
look / sound / feel + as though〜のように見える

② 形容詞と、like / as if + 節の比べ

教科書には、次の説明があります。

Compare:

つまり、比べる。

Compare
look + 形容詞You look tired.疲れているように見える。
look + like / as if + 主語 + 動詞You look like you haven't slept. / You look as if you haven't slept.寝ていないように見える。
追加例文（教科書外）
as ifShe looks as if she's tired.彼女は、疲れているように見える。

日常会話での使用例

A: You look as if you've seen a ghost.

幽霊でも見たような顔をしているよ。

B: I just saw an accident.

事故を見てしまったんだ。

覚えておきたいのは、look / sound / feel + like / as if / as though + 主語 + 動詞で「〜のように見える・聞こえる」を表すということです。

形意味
look + 形容詞〜に見える
look + like / as if + 節〜のように見える

look / sound / feel + like / as if + 主語 + 動詞

Unit 118　Section B

it looks like, it sounds as if

今回の学習範囲：Section B

Section A では、人・物の様子を見ました。

今回は、it を主語にした形です。

今回のテーマit looks like … / it sounds as if …

① it looks like / it sounds as if

教科書は、次のように説明しています。

We say: it looks like … or it looks as if … / it sounds like … or it sounds as if …

つまり、it looks like … または it looks as if …、it sounds like … または it sounds as if … と言う。

It sounds like they're having a party next door.

隣でパーティーをしているみたいだ。

Sarah is very late. It looks like she isn't coming. or It looks as if she isn't coming.

サラはとても遅い。来ないみたいだ。

It looked like it was going to rain, so we took an umbrella. or It looked as if it was going to rain …

雨が降りそうだったので、傘を持っていった。

教科書の説明を見てみましょう。

You can also use as though:

つまり、as though も使える。

It sounds as though they're having a party.

パーティーをしているみたいだ。

形意味
it looks like / as if / as though …〜のようだ（見た感じ）
it sounds like / as if / as though …〜のようだ（聞いた感じ）
追加例文（教科書外）
it looksIt looks like it's going to be a nice day.いい天気になりそうだ。

日常会話での使用例

A: What's that noise?

あの音は何？

B: It sounds as if someone is shouting.

誰かが叫んでいるみたいだ。

覚えておきたいのは、it looks like / as if / as though …とit sounds like / as if …は、見た感じ・聞いた感じを表すということです。

形意味
it looks like / as if + 節見た感じ
it sounds like / as if + 節聞いた感じ

it looks / sounds like / as if + 主語 + 動詞

Unit 118　Section C

Other verbs

今回の学習範囲：Section C

Section B では、it を主語にした形を見ました。

今回は、ほかの動詞との組み合わせです。

今回のテーマlike / as if は、ほかの動詞のやり方も説明できる

① ほかの動詞 + like / as if

教科書は、次のように説明しています。

You can use like / as if / as though with other verbs to say how somebody does something:

つまり、like / as if / as though は、ほかの動詞とも使って、人が何かをどのようにするかを言える。

He ran like he was running for his life.

彼は、命がけで走っているかのように走った。

After the interruption, the speaker went on talking as if nothing had happened.

邪魔が入ったあとも、話し手は、何事もなかったかのように話し続けた。

When I told them my plan, they looked at me as though I was mad.

私の計画を話したら、彼らは、私が気が狂ったかのような目で見た。

動詞形
ranlike he was running for his life
went on talkingas if nothing had happened
looked at meas though I was mad
追加例文（教科書外）
as ifShe smiled as if she knew a secret.彼女は、秘密を知っているかのように微笑んだ。

日常会話での使用例

A: Why is he looking at you like that?

どうして彼はあんなふうにあなたを見ているの？

B: He's looking at me as if I were a stranger.

まるで他人を見るような目で見ているんだ。

覚えておきたいのは、like / as if / as thoughは、ほかの動詞のあとにも置いて、「〜かのように」のやり方を表すということです。

形意味
動詞 + like / as if / as though + 節〜かのように…する

動詞 + as if + 主語 + 動詞

Unit 118　Section D

as if + past

今回の学習範囲：Section D

最後は、as if のあとの過去形です。

今回のテーマ現実と違うことを言うときは、過去形

① as if + 過去形

教科書は、次のように説明しています。

After as if, we sometimes use the past when we are talking about the present. For example:

つまり、as if のあとでは、現在のことを話していても、過去形を使うことがある。例えば次のようになる。

I don't like him. He talks as if he knew everything.

彼は好きではない。何でも知っているかのように話す。

教科書の説明を見てみましょう。

The meaning is not past. We use the past (as if he knew) because the idea is not real: he does not know everything. We use the past in the same way with if and wish (see Unit 39). We do not normally use like in this way.

つまり、意味は過去ではない。過去形（as if he knew）を使うのは、その考えが現実ではないからだ。彼は何でも知っているわけではない。if や wish でも、同じように過去形を使う（Unit 39 を見る）。この形では、ふつう like は使わない。

英文現実
He talks as if he knew everything.実際は何でも知っているわけではない
Why do you talk about him as if he was an old man?実際は老人ではない

② 例文

教科書には、次の説明があります。

Some more examples:

つまり、ほかの例。

She's always asking me to do things for her – as if I didn't have enough to do already.

彼女はいつも、私に何かを頼んでくる。まるで、私がすることが足りないかのように。

教科書の補足：(I have enough to do already)

Joe's only 40. Why do you talk about him as if he was an old man?

ジョーはまだ40歳だ。どうして彼のことを、老人のように話すの？

教科書の補足：(he isn't an old man)

③ was の代わりに were

教科書は、次のように説明しています。

When you use the past in this way, you can use were instead of was:

つまり、このように過去形を使うときは、was の代わりに were も使える。

Why do you talk about him as if he were an old man?

どうして彼のことを、老人のように話すの？

They treat me as if I were their own son. or … as if I was their own son.

彼らは、私を実の息子であるかのように扱う。

教科書の補足：(I'm not their son)

形意味
as if + 過去形現実とは違うことを仮定する
as if + werewas の代わりも可
追加例文（教科書外）
過去形He spends money as if he were a millionaire.彼は、百万長者であるかのようにお金を使う。

日常会話での使用例

A: Why does he act like that?

どうして彼はあんなふうに振る舞うの？

B: He acts as if he owned the place.

まるで、ここの持ち主みたいに振る舞うんだよ。

覚えておきたいのは、現実と違うことを言うときは、as if + 過去形（were も使える）を使い、意味は現在だということです。

形意味
as if + 過去形〜かのように（現実とは違う）

as if + 過去形（意味は現在）
