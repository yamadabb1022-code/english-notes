UNIT 140

Phrasal verbs 4 on/off (1)

Unit 140　句動詞（4）on / off（1）

「電気をつける」「試合が中止になった」「コートを脱いだ」「朝6時に出発した」。on と off は、スイッチだけでなく、行事・服・移動の言葉にも広がります。4つの場面に分けて見ていきます。

セクションの地図

Section扱う内容
Aon / off ＝ 電気・機械のスイッチ
Bgo on / call off / put off（行事など）
Cput on / try on / take off（服）
Doff ＝ 離れていく（be off / set off / take off / see off）

色の対応

on ＝ 青、off ＝ 緑、誤り＝赤。

Unit 140　Section A

on and off for lights, machines

今回の学習範囲：Section A

まず、スイッチの on / off です。

今回のテーマon ＝ つく、off ＝ 消える

① on は「つく」、off は「消える」を表す

on は、「接触している」、off は、「離れている」。電気のスイッチは、回路がつながれば on、切り離されれば off です。このイメージから、いろいろな on / off の句動詞に、意味が広がっていきます。

教科書は、次のように説明しています。

on and off for lights, machines etc.: We say: the light is on / put the light on / leave the light on etc. turn the light on/off or switch the light on/off

つまり、電気や機械などの on と off です。the light is on、put the light on、leave the light on と言います。turn the light on / off や、switch the light on / off も言えます。

Shall I leave the lights on or turn them off?

電気をつけたままにしようか？ それとも消そうか？

'Is the heating on?' 'No, I switched it off.'

「暖房はついている？」「ううん、消したよ。」

教科書の説明を見てみましょう。

also put (music, a song) on, put the kettle on:

つまり、put (music / a song) on や put the kettle on のようにも言います。

Let's put some music on. What would you like to hear?

音楽をかけよう。何が聞きたい？

We need boiling water, so I'll put the kettle on.

熱湯が要るので、やかんを火にかけるよ。

言い方意味
turn on / switch on / put onつける
turn off / switch off消す
leave … onつけたままにする

on / off は、機械や家電のスイッチにも使えます。

Please turn the TV on.

テレビをつけてください。

会話では、オーブンがついているかをたずねるときに使います。

A: Is the oven on?

オーブンはついている？

B: No, I turned it off.

ううん、消したよ。

覚えておきたいのは、電気や機械は、onでつき、offで消えるということです。

言い方意味
turn on / switch onつける
turn off / switch off消す

on ⇔ off

Unit 140　Section B

on and off for events

今回の学習範囲：Section B

次は、行事です。

go on / call off / put off の3つです。

今回のテーマgo on / call off / put off

① go on は進行、call off は中止、put off は延期を表す

on は、「続いている」、off は、「止まっている」。go on は、「続く」。call off は、「止める」。put off は、「今ではなく、あとに離す」→「延期する」。on と off の対比で、意味が見えてきます。

教科書は、次のように説明しています。

go on = happen / call something off = cancel it / put something off, put off doing something = delay it

つまり、go on は「起こる」、call something off は「中止する」、put something off や put off doing something は「延期する」という意味です。

What's all that noise? What's going on?

あの騒ぎは何？ 何が起きているの？

教科書の補足：(= what's happening)

The concert in the park had to be called off because of the weather.

公園でのコンサートは、天気のために中止になった。

The election has been put off until January.

選挙は、1月まで延期された。

We can't put off making a decision. We have to decide now.

決断を先延ばしにはできない。今、決めなければならない。

句動詞意味
go on起こる
call off中止する
put off延期する

call off と put off は、中止や延期の連絡にも使えます。

The match was called off because of the rain.

雨のために、試合は中止になった。

会話では、状況をたずねるときに使います。

A: What's going on?

何が起きているの？

B: There's a party next door.

隣でパーティーをしているんだ。

覚えておきたいのは、go onは「起こる」、call offは「中止する」、put offは「延期する」だということです。

句動詞意味
go on起こる
call off中止する
put off延期する

go on ／ call off ／ put off

Unit 140　Section C

on and off for clothes

今回の学習範囲：Section C

次は、服の on / off です。

身につける、脱ぐ、試着する、です。

今回のテーマput on ＝ 身につける、take off ＝ 脱ぐ

① put on は身につける、take off は脱ぐ、を表す

put on は、「体の上に置く」→「身につける」。take off は、「体から離す」→「脱ぐ」。洋服・眼鏡・化粧・シートベルトなど、体につけるものに使います。take off は、飛行機が「地面から離れる」ことも、表します。

教科書は、次のように説明しています。

put on clothes, glasses, make-up, a seat belt etc. / put on weight = get heavier / try on clothes (to see if they fit) / take off clothes, glasses etc.

つまり、put on clothes / glasses / make-up / a seat belt などは、「身につける」という意味です。put on weight は「体重が増える」、try on clothes は「合うか確かめる」、take off clothes / glasses などは「脱ぐ」という意味です。

My hands were cold, so I put my gloves on.

手が冷たかったので、手袋をはめた。

I've put on two kilos in the last month.

この1か月で、2キロ太った。

I tried on a jacket in the shop, but it didn't look right.

お店で上着を試着したが、似合わなかった。

It was warm, so I took off my coat.

暖かかったので、コートを脱いだ。

句動詞意味
put on身につける
put on weight太る
try on試着する
take off脱ぐ

put on と take off は、服だけでなく、体重の話にも使えます。

Put your coat on. It's cold outside.

コートを着て。外は寒いよ。

会話では、試着をお願いするときに使います。

A: Can I try this on?

これを試着してもいい？

B: Of course.

もちろん。

覚えておきたいのは、服はput on / try onで着て、take offで脱ぐということです。

句動詞意味
put on着る
try on試着する
take off脱ぐ

put on ⇔ take off

Unit 140　Section D

off = away from

今回の学習範囲：Section D

最後は、離れていく off です。

今回のテーマoff ＝ そこから離れていく

① off は、そこから離れていく動きを表す

off は、「そこから離れていく」イメージです。set off は、「出発地から離れる」→「出発する」。see someone off は、「その人が離れていくのを見送る」。離れる、始まる、終わる、という意味が、含まれます。

教科書は、次のように説明しています。

be off (to a place) / walk off / run off / drive off / ride off / go off (similar to walk away / run away etc.) / set off = start a journey / take off = leave the ground (for planes) / see somebody off = go with them to the airport/station to say goodbye

つまり、be off (to a place)、walk off / run off / drive off / ride off / go off は、「離れていく」という意味で、walk away や run away に似ています。set off は「旅に出発する」、take off は「離陸する」、see somebody off は「空港や駅まで見送る」という意味です。

Tomorrow I'm off to Paris. / I'm off on holiday.

明日はパリへ出かける。／休暇に出かける。

教科書の補足：(= I'm going to Paris / I'm going on holiday)

Anna got on her bike and rode off.

アンナは、自転車に乗って走り去った。

Mark left home at the age of eighteen and went off to Canada.

マークは、18歳で家を出て、カナダへ行った。

We set off early to avoid the traffic.

渋滞を避けるため、早く出発した。

教科書の補足：(= We left early)

After a long delay, the plane finally took off.

長い遅れのあと、飛行機がようやく離陸した。

Helen was going away. We went to the station with her to see her off.

ヘレンは、旅に出るところだった。駅までいっしょに行って、見送った。

句動詞意味
be off (to …)出かける
walk off / ride off / drive off立ち去る
set off出発する
take off離陸する
see … off見送る

set off は、旅行や仕事の出発にも使えます。

We set off at six in the morning.

私たちは、朝6時に出発した。

会話では、出発時間をたずねるときに使います。

A: When are you leaving?

いつ出発するの？

B: We're setting off at eight.

8時に出発するよ。

覚えておきたいのは、be off / set off / take off / see offは、「離れていく・出発する・見送る」を表すということです。

句動詞意味
be off / set off出かける・出発する
take off離陸する
see … off見送る

set off ／ take off ／ see off
