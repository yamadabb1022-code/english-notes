UNIT 143

Phrasal verbs 7 up (1)

Unit 143　句動詞（7）up（1）

「あとで追いつくよ」「趣味を始めた」「香港で生まれ、オーストラリアで育った」「部屋を片づけて」「結局〜になった」。up の句動詞は、使う場面が多くて便利です。意味ごとに5つのグループに分けて見ていきます。

セクションの地図

Section扱う内容
A近づく・追いつく（come up / catch up / keep up）
B始める（set up / take up / fix up）
C育つ・育てる（grow up / bring up）
Dきれいにする（clean up / tidy up / wash up）
Eそのほか（end up / give up / make up / take up / turn up / use up）

色の対応

up ＝ 青、誤り＝赤。

Unit 143　Section A

approach, catch up

今回の学習範囲：Section A

まず、近づく・追いつく up です。

今回のテーマgo up / come up ＝ 近づく、catch up ＝ 追いつく

① go up / come up は近づく、catch up は追いつく、keep up はついていく、を表す

up には、「近づく」という意味もあります。come up to は、「そばまで行く」。catch up は、「追いつく」。keep up は、「ついていく」。距離を縮める、というイメージです。

教科書は、次のように説明しています。

go up, come up, walk up (to …) = approach / catch up (with somebody), catch somebody up = move faster than people in front of you so that you reach them / keep up (with somebody) = continue at the same speed or level

つまり、go up、come up、walk up (to …) は、「近づく」という意味です。catch up (with somebody) や catch somebody up は、「前の人より速く動いて追いつく」という意味です。keep up (with somebody) は、「同じ速さ・水準で続ける」という意味です。

A man came up to me in the street and asked me for money.

通りで、男の人が近づいてきて、お金を求めた。

I'm not ready to go yet. You go on and I'll catch up with you. / I'll catch you up.

まだ行く準備ができていない。先に行って。あとで追いつくから。

You're walking too fast. I can't keep up (with you).

歩くのが速すぎる。ついていけない。

You're doing well. Keep it up!

よくやっているよ。その調子で続けて！

句動詞意味
@blue(come up (to))近づく
@blue(catch up (with))追いつく
@blue(keep up (with))遅れずについていく

catch up は、人や遅れに追いつく場面にも使えます。

I'll catch up with you later.

あとで追いつくよ。

会話では、待ってほしいときに使います。

A: Wait for me!

待って！

B: Hurry up and catch up!

急いで追いついて！

覚えておきたいのは、come up / catch up / keep upは「近づく・追いつく・遅れずについていく」を表すということです。

句動詞意味
come up近づく
catch up追いつく
keep upついていく

come up ／ catch up ／ keep up

Unit 143　Section B

set up, take up

今回の学習範囲：Section B

次は、始める up です。

set up / take up / fix up です。

今回のテーマset up / take up / fix up ＝ 始める

① set up は設立する、take up は始める、fix up は手配する、を表す

up には、「立ち上げる」という意味もあります。set up は、「立てて置く」→「設立する」。take up は、「手に取る」→「始める」。fix up は、「しっかり固める」→「手配する」。

教科書は、次のように説明しています。

set up an organisation, a company, a business, a system, a website etc. = start it / take up a hobby, a sport, an activity etc. = start doing it / fix up a meeting etc. = arrange it

つまり、set up an organisation / a company / a business / a system / a website などは、「始める」という意味です。take up a hobby / a sport / an activity なども、「始める」という意味です。fix up a meeting などは、「手配する」という意味です。

The government has set up a committee to investigate the problem.

政府は、その問題を調べる委員会を設置した。

Laura took up photography a few years ago. She takes really good pictures.

ローラは、数年前に写真を始めた。とてもいい写真を撮る。

We've fixed up a meeting for next Monday.

来週の月曜日に、会議を設定した。

句動詞意味
set up設立する
take up（趣味などを）始める
fix up（会議などを）手配する

take up は、趣味や習い事を始めるときにも使えます。

She took up tennis last year.

彼女は、昨年テニスを始めた。

会話では、趣味をたずねるときに使います。

A: Have you got any hobbies?

趣味はある？

B: I took up painting last year.

去年、絵を始めたよ。

覚えておきたいのは、set upは「設立する」、take upは「趣味などを始める」、fix upは「手配する」だということです。

句動詞意味
set up設立する
take up始める
fix up手配する

set up ／ take up ／ fix up

Unit 143　Section C

grow up, bring up

今回の学習範囲：Section C

次は、育つ・育てる up です。

grow up と bring up です。

今回のテーマgrow up ＝ 大人になる、bring up ＝ 育てる

① grow up は育つ、bring up は育てる、を表す

grow up は、「上へ育つ」→「大人になる」。bring up は、「上へ連れてくる」→「育てる」。up は、「成長して、上がっていく」イメージです。

教科書は、次のように説明しています。

grow up = become an adult / bring up a child = raise, look after a child

つまり、grow up は「大人になる」、bring up a child は「子どもを育てる」という意味です。

Amy was born in Hong Kong but grew up in Australia.

エイミーは香港で生まれたが、オーストラリアで育った。

Her parents died when she was a child and she was brought up by her grandparents.

子どものころに両親を亡くし、祖父母に育てられた。

句動詞意味
grow up育つ
bring up育てる
be brought up育てられる

grow up は、育った場所を言うときにも使えます。

I grew up in a small town.

私は、小さな町で育った。

会話では、出身地をたずねるときに使います。

A: Where did you grow up?

どこで育ったの？

B: In Osaka.

大阪だよ。

覚えておきたいのは、grow upは「大人になる」、bring upは「育てる」だということです。

句動詞意味
grow up育つ
bring up育てる

grow up ⇔ bring up

Unit 143　Section D

clean up, tidy up, wash up

今回の学習範囲：Section D

次は、きれいにする up です。

clean up / tidy up / wash up です。

今回のテーマclean up / tidy up / wash up

① clean up / tidy up / wash up は、きれいにすることを表す

up には、「完全に」「最後まで」という意味もあります。clean up は、「すっかりきれいにする」。tidy up は、「完全に整頓する」。「すみずみまで仕上げる」という気持ちが入ります。

教科書は、次のように説明しています。

clean up, clear up, tidy up = make something clean, tidy etc. / wash up = wash the plates, dishes etc. after a meal

つまり、clean up / clear up / tidy up は、「きれいにする」「整頓する」という意味です。wash up は、「食後に皿などを洗う」という意味です。

Look at this mess! Who's going to tidy up? (or … to tidy it up)

この散らかり方を見て！ 誰が片づけるの？

I hate washing up. (or I hate doing the washing-up.)

皿洗いは大嫌いだ。

句動詞意味
clean up / clear up / tidy upきれいにする・片づける
wash up食器を洗う

tidy up は、部屋や机を片づけるときにも使えます。

Please tidy up your room.

部屋を片づけて。

会話では、皿洗いの担当を決めるときに使います。

A: Who's going to wash up?

誰が皿洗いをするの？

B: I'll do it.

私がやるよ。

覚えておきたいのは、clean up / tidy up / wash upは「きれいにする・片づける・食器を洗う」を表すということです。

句動詞意味
clean up / tidy upきれいにする
wash up食器を洗う

clean up ／ tidy up ／ wash up

Unit 143　Section E

Other verbs + up

今回の学習範囲：Section E

最後は、そのほかの up です。

今回のテーマend up / give up / make up / take up / turn up / use up

① end up は結局〜になる、give up はあきらめる、を表す

end up は、「最後に行き着く」。give up は、「持ち上げて、手放す」→「あきらめる」。up は、「完了」を表すこともあります。

教科書は、次のように説明しています。

end up somewhere, end up doing something etc. / give up = stop trying, give something up = stop doing it

つまり、end up somewhere や end up doing something は、「結局〜になる」という意味です。give up は「やめる」、give something up は「それをやめる」という意味です。

There was a fight in the street and three men ended up in hospital.

通りで喧嘩があり、3人の男が、結局、病院に運ばれた。

教科書の補足：(= that's what happened to these men in the end)

I couldn't find a hotel and ended up sleeping on a bench at the station.

ホテルが見つからず、結局、駅のベンチで寝る羽目になった。

Don't give up. Keep trying!

あきらめないで。続けて！

Sue got bored with her job and decided to give it up.

スーは仕事に飽きて、辞めることにした。

② make up / take up / turn up / use up は、構成・占有・現れる・使い切るを表す

教科書の説明を見てみましょう。

make up something, be made up of something / take up space or time = use space or time / turn up, show up = arrive, appear / use something up = use all of it so that nothing is left

つまり、make up something や be made up of something は、「〜からできている」という意味です。take up space or time は、「場所や時間を使う」、turn up や show up は、「着く」「現れる」、use something up は、「全部使い切る」という意味です。

Children under 16 make up half the population of the city.

16歳未満の子どもが、その都市の人口の半分を占めている。

教科書の補足：(= half the population are children under 16)

Air is made up of mainly nitrogen and oxygen.

空気は、おもに窒素と酸素からできている。

教科書の補足：(= Air consists of …)

Most of the space in the room was taken up by a large table.

部屋のスペースのほとんどを、大きなテーブルが占めていた。

We arranged to meet David last night, but he didn't turn up.

昨夜、デイビッドと会う約束だったが、現れなかった。

I'm going to make soup. We have a lot of vegetables and I want to use them up.

スープを作る。野菜がたくさんあるので、使い切りたい。

句動詞意味
end up結局〜になる
give upあきらめる・やめる
make up / be made up of構成する
take up（場所・時間を）取る
turn up / show up現れる
use up使い切る

end up や turn up は、予想外の結果や現れるときにも使えます。

He didn't turn up for the meeting.

彼は、会議に現れなかった。

会話では、来たかどうかをたずねるときに使います。

A: Did she come to the party?

彼女はパーティーに来た？

B: No, she didn't turn up.

ううん、現れなかったよ。

覚えておきたいのは、end up / give up、make up / take up / turn up / use upは、それぞれ特別な意味を持つ句動詞だということです。

句動詞意味
end up結局〜になる
give upあきらめる
turn up現れる
use up使い切る

end up ／ give up ／ turn up ／ use up
