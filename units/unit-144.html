UNIT 144

Phrasal verbs 8 up (2)

Unit 144　句動詞（8）up（2）

このユニットでは、up を使った句動詞の続きを学びます。

セクションの地図

Section扱う内容
A話題・アイデア（bring up / come up / come up with / make up）
B気持ち・天気・貯金（cheer up / save up / clear up）
C壊す・傷つける（blow up / tear up / beat up）
Dそのほか（break up / split up / do up / look up / put up with / hold up / mix up）

色の対応

up ＝ 青、誤り＝赤。

Unit 144　Section A

topic, idea

今回の学習範囲：Section A

まず、話題やアイデアの up です。

今回のテーマbring up / come up / come up with / make up

① bring up / come up / come up with / make up

教科書は、次のように説明しています。

bring up a topic etc. = introduce it in a conversation / come up = be introduced in a conversation / come up with an idea, a suggestion etc. = produce an idea / make something up = invent something that is not true

つまり、bring up a topic など ＝ 会話に持ち出す。come up ＝ 会話に出る。come up with an idea / a suggestion など ＝ 思いつく。make something up ＝ 本当でないことをでっちあげる。

I don't want to hear any more about this. Please don't bring it up again.

これ以上は聞きたくない。もう持ち出さないで。

Some interesting things came up in our discussion yesterday.

昨日の話し合いで、おもしろいことがいくつか出た。

Sarah is very creative. She's always coming up with new ideas.

サラはとても創造的だ。いつも新しいアイデアを思いつく。

What Kevin told you about himself wasn't true. He made it all up.

ケビンが自分について言ったことは、本当ではなかった。全部でっちあげだ。

句動詞意味
bring up（話題を）持ち出す
come up（話題が）出る
come up with思いつく
make upでっちあげる
追加例文（教科書外）
come up withWe need to come up with a plan.計画を考え出す必要がある。

日常会話での使用例

A: Any ideas?

何かアイデアはある？

B: I've just come up with one.

今、思いついたよ。

覚えておきたいのは、bring up / come up / come up with / make upは「話題・アイデア」に関する句動詞だということです。

句動詞意味
bring up持ち出す
come up with思いつく
make upでっちあげる

bring up ／ come up with ／ make up

Unit 144　Section B

cheer up, save up, clear up

今回の学習範囲：Section B

Section A では、話題の up を見ました。

今回は、気持ち・貯金・天気の up です。

今回のテーマcheer up / save up / clear up

① cheer up / save up / clear up

教科書は、次のように説明しています。

cheer up = be happier, cheer somebody up = make somebody feel happier / save up for something / to do something = save money to buy something / clear up = become bright (for weather)

つまり、cheer up ＝ 元気になる、cheer somebody up ＝ 人を元気づける。save up for something / to do something ＝ 何かを買うために貯金する。clear up ＝ （天気が）晴れる。

You look so sad! Cheer up!

とても悲しそうだね！ 元気を出して！

Helen is depressed. What can we do to cheer her up?

ヘレンは落ち込んでいる。元気づけるには、どうしたらいい？

Dan is saving up for a trip to New Zealand.

ダンは、ニュージーランド旅行のために貯金している。

It was raining when I got up, but it cleared up later.

起きたときは雨だったが、あとで晴れた。

句動詞意味
cheer up元気を出す
cheer 人 up元気づける
save up for貯金する
clear up（天気が）晴れる
追加例文（教科書外）
cheer upCheer up! Things will get better.元気を出して！ 状況はよくなるよ。

日常会話での使用例

A: I'm so sad.

とても悲しい。

B: Cheer up!

元気を出して！

覚えておきたいのは、cheer up / save up / clear upは「元気を出す・貯金する・晴れる」を表すということです。

句動詞意味
cheer up元気を出す
save up貯金する
clear up晴れる

cheer up ／ save up ／ clear up

Unit 144　Section C

blow up, tear up, beat up

今回の学習範囲：Section C

Section B では、気持ちの up を見ました。

今回は、壊す・傷つける up です。

今回のテーマblow up / tear up / beat up

① blow up / tear up / beat up

教科書は、次のように説明しています。

blow up = explode, blow something up = destroy it with a bomb etc. / tear something up = tear it into pieces / beat somebody up = hit someone repeatedly so that they are badly hurt

つまり、blow up ＝ 爆発する、blow something up ＝ 爆弾などで破壊する。tear something up ＝ 引き裂く。beat somebody up ＝ 人を何度も殴って、ひどく傷つける。

The engine caught fire and blew up.

エンジンが火を噴き、爆発した。

The bridge was blown up during the war.

橋は、戦争中に爆破された。

I didn't read the letter. I just tore it up and threw it away.

手紙は読まなかった。引き裂いて、捨てただけだ。

A friend of mine was attacked and beaten up. He had to go to hospital.

私の友人が襲われ、ひどく殴られた。病院へ行かなければならなかった。

句動詞意味
blow up爆発する・爆破する
tear up引き裂く
beat up殴って傷つける
追加例文（教科書外）
tear upShe tore up the photo.彼女は、写真を破り捨てた。

日常会話での使用例

A: What did you do with the letter?

その手紙をどうしたの？

B: I tore it up.

破いたよ。

覚えておきたいのは、blow up / tear up / beat upは「爆発する・引き裂く・殴る」を表すということです。

句動詞意味
blow up爆発する
tear up引き裂く
beat up殴る

blow up ／ tear up ／ beat up

Unit 144　Section D

Other verbs + up

今回の学習範囲：Section D

最後は、そのほかの up の句動詞です。

今回のテーマbreak up / do up / look up / put up with / hold up / mix up

① break up / do up / look up

教科書は、次のように説明しています。

break up, split up (with somebody) = separate / do up a coat, a shoelace, buttons etc. = fasten, tie etc. / do up a building, a room etc. = repair and improve it / look something up in a dictionary/encyclopaedia etc.

つまり、break up、split up (with somebody) ＝ 別れる。do up a coat / a shoelace / buttons など ＝ 留める、結ぶ。do up a building / a room など ＝ 修繕して改装する。look something up in a dictionary / encyclopaedia など。

I'm surprised to hear that Kate and Paul have split up. They seemed very happy together.

ケイトとポールが別れたと聞いて、驚いた。とても幸せそうだったのに。

It's quite cold. Do up your coat before you go out.

かなり寒い。出かける前に、コートのボタンをとめて。

The kitchen looks great now that it has been done up.

台所は、改装されて、すてきになった。

If you don't know the meaning of a word, you can look it up (in a dictionary).

言葉の意味が分からなければ、（辞書で）調べればいい。

② put up with / hold up / mix up

教科書の説明を見てみましょう。

put up with something = tolerate a difficult situation or person / hold up a person, a plan etc. = delay / mix up people/things, get people/things mixed up = you think one is the other

つまり、put up with something ＝ 困難な状況や人を我慢する。hold up a person, a plan など ＝ 遅らせる。mix up people / things、get people / things mixed up ＝ 一方を他方と思い違える。

We live on a busy road, so we have to put up with a lot of noise from the traffic.

交通量の多い道路に住んでいるので、車の騒音をずいぶん我慢しなければならない。

Don't wait for me. I don't want to hold you up.

私を待たないで。あなたを遅らせたくない。

Plans to build a new factory have been held up because of financial problems.

新しい工場を建てる計画は、資金の問題で遅れている。

The two brothers look very similar. People often mix them up. or … People often get them mixed up.

その兄弟はよく似ている。よく、人から間違えられる。

句動詞意味
break up / split up別れる
do up留める／改装する
look up調べる
put up with我慢する
hold up遅らせる
mix up混同する
追加例文（教科書外）
put up withI can't put up with this noise any more.この騒音は、もう我慢できない。

日常会話での使用例

A: How can you live with this noise?

どうして、この騒音のなかで暮らせるの？

B: I just put up with it.

ただ、我慢しているだけだよ。

覚えておきたいのは、break up / do up / look up、put up with / hold up / mix upは、それぞれ特別な意味を持つ句動詞だということです。

句動詞意味
split up別れる
look up調べる
put up with我慢する
hold up遅らせる
mix up混同する

split up ／ look up ／ put up with ／ hold up
